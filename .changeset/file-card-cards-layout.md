🧩 **FileCard** and **UploadCard**: new — one file as a card (thumbnail or type icon, name, description lines, a ⋯ actions menu) that opens the file viewer, or with `href` (+ `download`, `target`) makes the whole card a link to a download or a page; `UploadCard` is the same row for a file uploading, with progress, Retry and Cancel. Install with `@vegastack/file-card`.

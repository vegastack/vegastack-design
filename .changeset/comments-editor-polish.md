🔧 Comments and editor polish. `CommentComposer` and the reply box are one line and 32px tall at rest, with a paperclip attach button (shown when `onImageUpload`/`onFileUpload` is set; picked files go through the editor's own upload flow) and Send inline on the bottom line as the text grows; `replyingTo`/`onCancelReply` show a "Replying to" line (× or Escape cancels and keeps the text) and the "Write a reply…" placeholder. `CommentList` with no comments shows a muted "No comments yet" line with the composer under it (no Empty illustration or "Add a comment" step). Replies are flush rows inside their comment's card (no `ms-9` indent), avatars are 28px, long names truncate, and composer buttons get 40px touch targets. Mention chips are inline-flex on the info tint (`bg-info/10`, `text-info-text`, hover `bg-info/15`; restricted stays muted) with a centred icon, and a person chip shows a 16px avatar via the new `mentionImage` prop on `MarkdownView` and `TextEdit`. `TextEditHandle` gains `uploadFiles` and `pickFiles`. The block drag handle is a 16px grip inset from the frame edge, and the drop line (the shared `dropIndicatorClasses`, SortableList included) is info blue and inset. Paste parses Markdown from the plain-text flavour when the HTML only wraps code (VS Code, a lone `pre`), turns a single fenced block into a code block, and Mod-Shift-V pastes plain text. `CodeBlock` and the editor's code block are Notion-style: no border or header bar, `bg-muted/60`, 13px mono, the language (a searchable picker while editing) and Copy on hover, lowlight syntax highlighting with alias normalisation, Tab/Shift-Tab indent and any-language fence input rules. `utilities.css` adds token-mapped `.hljs-*` colours for both themes. `AutoSaveIndicator`'s saved check is muted ink instead of green, and errors show in warning ink.

🧩 **TextEdit** ergonomics and **BlockToolbar** (new). `BlockToolbar` (`aria-label`, `reveal: "always" | "hover"`, `placement: "corner" | "inline"`), `BlockToolbarButton` (`label` + `Button` props, 28px, tooltip) and `BlockToolbarMenu` (`label`, items) are the one place a block's controls sit — top-right, four at most, the rest in ⋯; the code block (TextEdit and `CodeBlock`), the image toolbar (Replace, Caption, Alt text, Open; Download and Copy link now in ⋯) and the diagram header use it, all at 28px. `TextEdit` gains `bubbleActions` (`(context: TextEditBubbleContext) => ReactNode`), `toolbar` (`"bubble" | "dock"` — a 44px bottom bar on a coarse pointer) and `touchBlockMenu` (`"handle" | "longPress"` — no grip on touch, a long press opens the block menu sheet); the bubble also offers **Make task(s)** for selected checklist lines with `onMakeTask`, and stays inside the text column (wrapping onto a second row when narrower). `onImageUpload` / `onFileUpload` get `onProgress` (`TextEditUploadOptions`): a bar on the image placeholder, a ring on the file chip. ⌘↵ or ↓ on the last line leaves a code block or a diagram's source for the line below, with a footer hint; a new Diagram starts with one comment and draws "Nothing to draw yet" (`MermaidBlock` `emptyMessage`). The block grip keeps its 16×20 glyph with a 24×28 hit area, and the find bar floats over the text instead of pushing it down. Breaking: `codeBlockActionsClassName` is removed (use `BlockToolbar`).

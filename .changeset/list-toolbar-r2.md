⚠️ **List toolbar, round 2** — no compatibility aliases. **`ListToolbar`**: the search sits at the start (left) and the tools at the end; `tabs` render in their own row above the toolbar (they fold by themselves); the `action` prop and `ListToolbarAction` are removed — a page's main button lives at the right end of the app's top bar on every page type; `layout` is one icon button that shows, and switches to, the other layout (three layouts step in order; Display's Layout section still picks any); the collapse order is search 240→144, Layout → Display, Sort → Display, search → icon, edit and state → ⋯. **`ListToolbarPopover`**, `SortMenu`, `DisplayMenu` and `AddFilterMenu` take the `DropdownMenu`'s rhythm: a 4px inset, 28px rows at a 6px inset, 24px labels, edge-to-edge hairlines; Display's Reset is a menu row. **`FilterRow`**: facets and chips are one line that scrolls sideways and never wraps, with `+ Filter` and then `Clear` at the right end; every control on it is the toolbar's tool height (32px, 28px in a compact toolbar). **`AddFilterMenu`**: one "Filter by…" input (the people dropdown's filled field) for field names and plain language; with `ai`, "✦ Filter with AI: “…”" shows first only for a phrase (two or more words, or a word no field matches). `AiFilterInput` (+ `AiFilterInputProps`) and `AddFilterAi.placeholder` are removed. [docs](https://design.vegastack.com/docs/foundations/list-toolbar)

🧩 **TextEdit**: YouTube and Loom embeds, opt-in with `embeds={EMBED_PROVIDERS}` (without it an embed shows as a link and a pasted link stays one) — a new `embed` block (`{ provider, url }`, with a `blockId`) whose Markdown is the URL as written, alone on its line; a paragraph holding only a link to its own URL on an allowlisted host parses back to an embed, any other lone URL stays a link, and existing documents serialize unchanged. It draws a facade (16:9 card, provider glyph, "YouTube video" / "Loom video", **Play**) that requests nothing from the provider until Play, then a lazy, sandboxed frame whose `src` is rebuilt from the video id (`youtube-nocookie.com`, `t=` as `?start=`) with its own referrer policy; printed, it is the URL. A lone link pasted into an empty paragraph embeds, with an "Embedded" toast and Undo back to a link; the slash menu's **Video** link tab embeds YouTube and Loom links. New `onExternalImage(url, { signal })`: images pasted or dropped from another site leave the paste, show an upload placeholder and land as your stored copy — or as a link with "Couldn't import that image. A link was added instead." — and pasted `data:` images upload through `onImageUpload` (20 a paste, 3 at a time). **MarkdownView** renders the same facade (`MarkdownEmbed`) with the same `embeds` prop. New lib **embed-providers**: `matchEmbed`, `EMBED_PROVIDERS`, `EmbedProviders`, `EMBED_FRAME_ORIGINS` (the `frame-src` allowlist) and `EMBED_FRAME_ATTRIBUTES`. Corpus cases `extensions/embed-*`, `editor-json/embed-*`.

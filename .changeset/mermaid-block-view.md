🧩 **MermaidBlock** (new): a `mermaid` fence drawn as a diagram in the browser — `mermaid` 12.1.0 loaded lazily the first time a diagram nears the viewport, every render pinned to strict security, SVG labels and the dagre layout inside one queue, token colours for light and dark (the other scheme pre-drawn on idle, so theme switches and print are instant), an LRU of 50 SVGs, the measured height reserved on the next visit, and the last diagram that worked kept, dimmed, with a `role="status"` line when the source stops parsing. Exports `MermaidBlock`, `renderMermaid(source, { theme })`, `useMermaidSvg(source, { debounce })` and `mermaidBlockView`. **TextEdit** and **MarkdownView**: `blockViews` maps a fence's language to a renderer — `blockViews={{ mermaid: mermaidBlockView }}` makes those fences **Diagram** blocks with Preview / Code (split beside a live preview on a block at least 720px wide), Expand (full screen, pan and pinch) and a ⋯ menu (Copy source, plus the view's own actions); the mode is per viewer and never saved; ⌘/Ctrl+Enter and Escape return to the preview; the slash menu and Turn into offer **Diagram** while `blockViews.mermaid` is set. MarkdownView shows the source in the same frame on the server and before hydration. New shared internal: `block-view`.

🧩 **FieldProperty** (in `field-cell`): one field as an editable property row inside a **PropertyList**, for a row peek, a row page, or a customer's or project's custom fields. The name sits on the left. The value sits on the right, drawn exactly as the grid draws it (`FieldCellDisplay`), with no box at rest and a quiet wash on hover. A click, Enter or a typed character opens the grid cell's own editor (`FieldCellEditor`) in place: text, numbers, URLs, emails and phones inline, long text growing in place, choices on the in-cell option list, dates on the calendar, and a link on the record picker. A checkbox toggles where it is. A value that is itself a link (URL, email, phone, record chips, files) stays followable, and an Edit pencil beside it opens the editor. Read-only types, `readOnly` and `disabled` never edit and show no hover. `onSave` returns a promise: the value shows at once, a spinner follows after 300ms, and a rejection rolls back with a Retry toast, as **EditableCell** does. `conflict` shows "Someone changed this field." under the value. An empty value reads "Empty" (`emptyText`). On a phone the value goes full width under its label. **FieldCellDisplay** takes a `label` that names a checkbox. [docs](https://design.vegastack.com/docs/components/field-cell)

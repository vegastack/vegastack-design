⚠️ **List toolbar, round 3** — no compatibility aliases. **`ListToolbarPopover`** is one layout for every toolbar menu: on a phone the bottom sheet's rows sit on the title's 16px edge, 8px under it (no empty band); a `size="lg"` (576px) for a condition builder; **`ListToolbarDrillHeader`** (new) is the one ‹ back row for every drill-in (Display › Sort / Columns, + Filter › a field / Advanced filter, a date's Custom range). **`ListToolbar`**: the search grows to 320px; `search.collapsible` is removed (a table's search is the same full field as every list); the tab row keeps 12px to the toolbar row. **`FilterRow`**: `+ Filter` and `Clear` sit right after the last chip inside the scrolling line, and opening a chip's picker scrolls that chip into view; `aiNote` (+ `FilterRowAiNote`, the `aiAdded`/`undo`/`unmatched`/`dismiss` labels) is removed — `useAiFilterApplied()` toasts what an AI run added, with Undo. **`DateRangeFilter`** is the one date filter: presets add Overdue, Tomorrow, This/Last/Next week, Next 7 days and No date (`weekStartsOn`), shown as the menus' 28px rows with a tick; Custom range drills into the calendar (one month on a phone); a value's `from`/`to` are `Date | null` (open-ended ranges). **`AddFilterMenu`**: `onAdvanced` → `advanced` (the condition builder drilled into in the same, wider popover — never a dialog); `ai.onApplied(result, text)` fires after a run that added filters. **`SortBuilder` / `GroupByPicker`**: fields and directions are 28px menu rows (ghost selects), "Add sort" / "Group by" are 14px rows. **`ViewTabs`** use the same pill tabs as every page's scope tabs. **`RouteTabs`**: no pending bar under a clicked tab (it flashed). **`DataList`**: "N columns hidden" is screen-reader only. **`Inbox`**: `InboxFilters` loses the Unread toggle (`unreadOnly`, `onUnreadOnlyChange`, `unreadCount`, `unreadLabel`); `InboxItemAction` `variant: "primary"` (the row's main action) now draws `secondary`, the rest `outline` — a row action is never the filled button (also `ApprovalCard`'s Approve; the rule is in Button's docs). **`useAiFilterApplied`** takes `labels.note` (the AI disclaimer line). **`FileViewer`**'s backdrop dims and blurs like every modal (Dialog, AlertDialog, Sheet, Drawer); popovers and menus keep none. [docs](https://design.vegastack.com/docs/components/list-toolbar)

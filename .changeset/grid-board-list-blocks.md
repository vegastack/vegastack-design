🔧 **DataGrid**, **Board**, **BoardCard** and **DataList**: table blocks in pages and calmer lanes and rows — every change is opt-in except where noted. **DataGrid** `embedded` frames the grid as one block in a page (the `toolbar` — a `BlockHeader` — on top, `footer` under the rows): its height comes from its rows, at most `maxRows` (25 by default when embedded; the first rows in display order), it scrolls sideways in the fixed layout with no column cap, its column picker is off unless `columnPicker` asks, and `virtualize`/`maxHeight` do not apply. `footer` also takes a `DataGridBlockFooter` object — `{ onNewRow, newRowLabel, shown, total, countLabel }` — for "+ New row" and "25 of 117". `readOnly` turns off every write path (cell editors, paste, clear, cut, fill, undo keys, `headerTrailing`, + New row) while rows still open, sort and select. **Board** `emptyLane="compact"` draws an empty lane as its header over a 48px drop target with "+"; `emptyLane="collapse"` moves empty lanes into the Hidden columns list (choose one to bring it back; drop a card on it there; a lane a move empties stays). `noValueLane="last"` moves the lane marked `noValue` (a new `BoardColumn` field) to the end and lets it collapse on any board. `loading` (with `loadingLanes`, 4) shows lane shells only — one skeleton per load. Always on: a lane loading its first cards shows no count (never "0" over skeletons), and the edge fades carry a soft scroll shadow. **BoardCardChip** `empty` keeps a no-value chip off the card at rest (shown on card hover and focus, while its menu is open, and on touch). **DataList** `density="compact"` is now one line per row: merged values join the primary value's line, a plain primary value clamps to one line and a thumbnail steps down to 24px. A column `render`'s context carries `density`, `useDataListDensity()` reads it deeper down, and `DataListSecondary` wraps a custom cell's second line so compact leaves it out.

🧩 **AgentPanel** and **DelegatePopover** (new): agents as collaborators on a record. `AgentPanel` is the agent's rail card (`variant="card"`) or a peek's collapsible section (`variant="section"`, open unless done or stopped, its header a one-line summary): the agent's bot, name and "Agent" label, "Acting for Priya · Read & write", a ⋯ menu (View agent · Change agent · Stop · Remove, each only when its handler is passed), and a `state` of `none`, `queued`, `working`, `question`, `approval`, `failed`, `blocked`, `done` or `stopped` with that state's line and actions (Stop; one-tap answers and Reply…; Approve/Decline; Retry/Remove; Reconnect; Mark task done; Delegate again), the live progress line with elapsed time, the queued hint, and a muted "Agent since disconnected" that never turns a finished card back into Needs you. Below: Instructions with ✎ edit in place, Latest (up to three messages and changes, Show all), a Reply box (Cmd/Ctrl+Enter, a disabled reason) and History (runs with View and Undo, Undo disabled with its reason). State changes are announced politely. The same file adds `AgentSlot` (the one-line Delegate property, its "Delegate to an agent…" ghost and its muted can't-delegate reason), `AgentChip` (the pill for a peek or phone), `AgentStateBadge` (icon and word), `AgentStateRing` (amber while it needs you, red when it failed) and `AgentHoverCard` (acting for, access, state, View agent). `DelegatePopover` is the one Delegate popover for tasks and rows: search the viewer's agents (arrow keys and Enter; an agent that can't take it is disabled with its reason), optional instructions, a "When finished" choice for tasks, "Connect an agent ›" and Delegate — with a bulk `title`, the no-agents empty state and loading rows. Every string comes in through `labels`, with English defaults.

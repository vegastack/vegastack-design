🧩 **LoadMore** — the one "Load more" footer for keyset lists: an outline button that keeps its width and focus while the next batch loads, an error line with Try again, and an optional `endLabel` once the list has ended. `LoadMoreState` (`hasMore`, `onLoadMore`, `loading`, `error`) is the shape lists, board lanes and data hooks pass around.

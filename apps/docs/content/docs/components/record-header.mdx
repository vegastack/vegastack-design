## Usage

```tsx
import { RecordHeader } from "@/components/ui/record-header";

<RecordHeader
  eyebrow={<SpaceChip space={space} />}
  keyBadge={task.ref}
  title={task.title}
  onRename={(title) => updateTask({ title })}
  status={<StatusBadge status={task.status} />}
  presence={<AvatarStack people={here} max={3} />}
  actions={<TaskActionsMenu task={task} />}
  meta={<MetaLine>…</MetaLine>}
  chips={<TaskChips task={task} />}
/>;
```

## Scope

One anatomy for every record kind and both places a record opens. An eyebrow line holds where the
record lives and its key, with presence and the actions at its end; then the icon and the title —
renamed in place with `onRename` — with the status beside it; then the meta line and the chip
row. Every slot but the title is optional and leaves no gap when empty. On a full page the
breadcrumb and the actions usually live in the top bar (`AppShellHeaderActions`); inside a
`RecordPeek` they belong here, with `level={2}`.

## Accessibility

- The title is the record's one heading (`h1` on its page, `h2` in a peek). Renamed in place it
  is an `EditableCell` labelled by `titleLabel`: Enter or blur saves, Esc reverts, a failed save
  rolls back and is announced.
- The key chip, status and meta are text; icons beside them are decorative.

### How it works

`EmojiPicker` composes [`Popover`](/docs/components/popover) (trigger + floating panel), the shared
`panel-search` row — a leading glyph and a bare text field, because a bordered input inside a
bordered popup would nest two borders — and a scrollable grid of icon
[`Button`](/docs/components/button)s. That row is a
[shared internal](/docs/guides/components) this picker and `ShortcutOverlay` install; it arrives
automatically and is documented there. `SearchableSelect` draws its own search field and does not
install it.
Selecting an emoji fires `onValueChange(emoji)` with the character and (by default) closes the panel.

Above the grid sit an optional quick row (`quickEmoji`), the search and a category bar that jumps
to a section. The first section, "Recent", holds the viewer's last picks, kept in `localStorage`
(`showRecents={false}` turns it off). `size="sm"` is the compact panel.

The data is a curated set of about 260 emoji in nine categories, in the
[`emoji-data`](/docs/guides/components) lib. The picker loads it with a dynamic `import()` the
first time it opens and shows a skeleton grid meanwhile, so a page that only renders the trigger
never ships the table. `useEmojiData(enabled)` gives you the same module, for example to name an
emoji. It is not the full Unicode set; skin tones are not offered.

building a reaction bar or inserting several emoji in a row.

## Accessibility

- The trigger is a real `<button>`; <kbd>Enter</kbd> / <kbd>Space</kbd> open the popover and focus moves into the panel.
- Each emoji is a focusable `<button>` with an `aria-label` (the emoji name) and `title`, so the grid is screen-reader navigable and keyboard-operable.
- The search field is a labelled `<input type="search">`; typing filters the grid live, and a polite
  `role="status"` announces result counts or the empty state when nothing matches.
- Focus is a background tint from the tokens' `base.css`, on the trigger and every emoji button
  alike; there is no ring. The search row is a field group, so it wears the same tint while the field holds focus; its
  hairline never changes (FOC-14).
- While the data loads, the skeleton is hidden from assistive technology.
- Dismiss is built in (via `Popover`) — clicking outside the panel or pressing <kbd>Esc</kbd> closes it and returns focus to the trigger.

| Key                                                | Action                                                                 |
| -------------------------------------------------- | ---------------------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd>                | Open the picker (on the trigger) or select the focused emoji.          |
| <kbd>←</kbd> / <kbd>→</kbd>                        | Move one emoji within the grid, the quick row or the category bar.     |
| <kbd>↑</kbd> / <kbd>↓</kbd>                        | Move one row in the grid.                                              |
| <kbd>Home</kbd> / <kbd>End</kbd>                   | Jump to the first or last emoji.                                       |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Move between the search field and the grid — the grid is one tab stop. |
| <kbd>Esc</kbd>                                     | Close the picker and return focus to the trigger.                      |

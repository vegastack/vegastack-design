## Usage

```tsx
import {
  BlockToolbar,
  BlockToolbarButton,
  BlockToolbarMenu,
} from "@/components/ui/block-toolbar";

<figure className="group/block relative">
  <BlockToolbar aria-label="Image actions" reveal="hover">
    <BlockToolbarButton label="Caption" onClick={editCaption}>
      <Captions />
    </BlockToolbarButton>
    <BlockToolbarMenu label="More image actions">
      <DropdownMenuItem onClick={copyLink}>
        <Link />
        Copy link
      </DropdownMenuItem>
    </BlockToolbarMenu>
  </BlockToolbar>
  …
</figure>;
```

Every block with chrome puts its controls in the same corner at the same size: a code block's
wrap and copy, an image's replace, caption, alt text and open, a diagram's expand and actions. At
most four buttons show; whatever else the block can do goes in the ⋯ menu. Buttons are 28px ghost
icon buttons named by `label`, which is also their tooltip, and a press never takes focus from an
editor the block sits in. The toolbar never prints.

## Scope

- Owns: the corner, the 28px buttons and their tooltips, the ⋯ menu, the hover reveal.
- Does not own: what the controls do — they are the block's — or the block's own header.
- Compose with: `CopyButton` (`size="icon-sm"`) and `Toggle` (`className="size-7"`) as children
  when a control is one of those.

## Examples

### Shown on hover

`reveal="hover"` hides the toolbar until the block — an ancestor with the `group/block` class —
is hovered or holds focus, and keeps it shown while its menu is open. A coarse pointer, which has
no hover, always shows it.

## Accessibility

- The toolbar is a group named by `aria-label` ("Image actions").
- Every button is named by its `label`, shown as its tooltip on hover and focus.
- A hover-revealed toolbar shows while anything in the block holds focus, so the keyboard reaches
  it.

| Key                                       | Action                      |
| ----------------------------------------- | --------------------------- |
| <kbd>Tab</kbd>                            | Moves through the buttons   |
| <kbd>Enter</kbd> / <kbd>Space</kbd>       | Presses a button or opens ⋯ |
| <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> | Moves through the open menu |
| <kbd>Escape</kbd>                         | Closes the menu             |

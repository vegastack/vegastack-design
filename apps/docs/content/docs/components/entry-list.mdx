## Usage

```tsx
import {
  Entry,
  EntryActions,
  EntryList,
  EntryMeta,
} from "@/components/ui/entry-list";

<EntryList className="gap-1">
  <Entry>
    <span className="min-w-0">
      Task Install glazing is now Done <EntryMeta>(Asha, 2h ago)</EntryMeta>
    </span>
    <EntryActions>
      <Button variant="ghost" size="xs">
        Open
      </Button>
    </EntryActions>
  </Entry>
</EntryList>;
```

`EntryList` is for the short lists inside a sheet, a dialog or a popover — what changed, who was
asked, the edits since a date — where each entry is a line of 14px text, its details in the muted
ink (`EntryMeta`) and small actions pushed to its end (`EntryActions`). It draws no padding, border
or hover: an entry is not itself a target. For rows that are targets reach for `Item`; for records,
`DataList`. Space the entries with a gap on the list.

`span`'s.

## Accessibility

- The list is a real `ul` of `li` entries, so assistive technology announces how many there are.
- Details are text in the entry, read with it; actions are real buttons with their own names.

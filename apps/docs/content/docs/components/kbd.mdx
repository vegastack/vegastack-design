## Examples

### Composition

`Kbd` is one key. `KbdGroup` holds a sequence of them — either the keys of a single chord, or two
alternative shortcuts side by side.

<ComponentPreview name="kbdComposition" file="components/preview/kbd.tsx" />

### Group

Use the `KbdGroup` component to group keyboard keys together.

<ComponentPreview name="kbdGroup" file="components/preview/kbd.tsx" />

### Button

Use `Kbd` inside a `Button` to show the shortcut that fires the same action. Give it
`data-icon="inline-end"` so it takes the trailing icon spacing.

<ComponentPreview name="kbdButton" file="components/preview/kbd.tsx" />

### Tooltip

You can use `Kbd` inside a `TooltipContent` to show the shortcut beside the label. Inside a tooltip
the chip inverts automatically — it reads the tooltip surface through `in-data-[slot=tooltip-content]`
rather than needing a variant.

<ComponentPreview name="kbdTooltip" file="components/preview/kbd.tsx" />

### Input Group

Upstream puts the chip in an `InputGroupAddon`. That item is not in this registry yet, so use
`Input`'s own `suffix` slot, which renders the same trailing chip inside the field chrome.

<ComponentPreview name="kbdInputGroup" file="components/preview/kbd.tsx" />

### RTL

`Kbd` is a chip with symmetric padding and `KbdGroup` is a flex row, so a right-to-left document
mirrors the order of a chord without any extra work.

## Accessibility

- Renders a native `kbd` element, which is what assistive technology expects for keyboard input.
  `KbdGroup` is a `kbd` too, so a chord reads as one piece of keyboard input.
- The chip is `pointer-events-none` and `select-none`: it is a label for a shortcut, never the
  control that fires it. Put the shortcut on a real button or a key handler.
- A symbol on its own — `⌘`, `⇧`, `⏎` — is not read aloud usefully by every screen reader. When the
  shortcut is the only way to reach an action, spell it out in the surrounding sentence as well.
- Inside a tooltip the chip inverts to stay legible against the inverted surface, which keeps it
  above the AA contrast floor in both themes.

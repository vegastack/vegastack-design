## Usage

```tsx
import { CodeBlock } from "@/components/ui/code-block";

<CodeBlock language="sql" copyValue={query}>
  {query}
</CodeBlock>;
```

### MarkdownView integration

`MarkdownView` delegates every fenced code block here automatically — the language comes from
the fence info string and the copy source from the block's text, so chat transcripts and
rendered markdown get the highlighted, copyable surface with no extra wiring. `TextEdit`'s code
block wears the same surface, with a searchable language picker in place of the label.

## Anatomy

A `<figure>` on `bg-muted/60`, `rounded-lg`, with no border or header bar. On hover or focus inside
(always on a touch screen) the language's display name (`<figcaption>`, "TypeScript" for `ts`)
shows top-left and a Copy `CopyButton` (check and "Copied" after a copy) top-right when
`copyValue` is set. The body is 13px mono with relaxed leading, `px-4 py-3`, scrolling sideways. A
string child is highlighted with lowlight's common grammars (fence aliases such as `ts`, `js`, `sh`
and `yml` resolve), coloured by the token-mapped `.hljs-*` rules in `utilities.css`.

### Long lines

Code does not wrap. A line wider than the panel scrolls inside the block's own horizontal scroll
container, so a long command never widens the page around it — which is what keeps a 320px viewport
reflowing instead of scrolling sideways.

## Accessibility

- A supplied `language` becomes the visible `<figcaption>` label; the code remains real selectable text.
- The composed `CopyButton` provides its own keyboard interaction, accessible name, and polite copied-state announcement.
- Horizontal overflow scrolls inside the code panel so long lines do not force page-level overflow at 320px.

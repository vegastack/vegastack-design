## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";

<Select items={items}>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="Theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      <SelectItem value="light">Light</SelectItem>
    </SelectGroup>
  </SelectContent>
</Select>;
```

### Disabled

`disabled` on the `Select` disables the whole control; on a `SelectItem` it disables one row. A
disabled item keeps its pointer events (FRM-4), so a Tooltip can explain why it is unavailable.

## Accessibility

- Renders Base UI's Select: the trigger is a `<button role="combobox">` with `aria-expanded` and
  `aria-controls`, and the popup is a `role="listbox"` of `role="option"` rows with type-ahead,
  <kbd>↑</kbd>/<kbd>↓</kbd>, <kbd>Home</kbd>/<kbd>End</kbd> and <kbd>Esc</kbd>.
- Focus on the trigger shows the border tint on `:focus` (FOC-3) **and** the global 2px outline,
  because the trigger is a button rather than a text field (FOC-4).
- The popup portals out of the trigger's subtree, so `SelectContent` re-applies the theme scope on
  the positioner inside the portal (OVL-13) — a dark or scoped surface survives the portal.
- Items carry the hand cursor from the one global rule in `base.css` (INT-1); upstream's local
  `cursor-default` is removed.
- Give the trigger an accessible name — an `aria-label`, or a `FieldLabel`.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/select.patch`. Every hunk:

- **FOC-1, FOC-3, FOC-4, FOC-6** — the trigger's `outline-none focus-visible:border-ring
focus-visible:ring-3 focus-visible:ring-ring/50` becomes `focus:border-ring/70`: a border tint on
  `:focus` for mouse and keyboard alike, plus the global outline, which the dropped `outline-none`
  lets through.
- **FOC-5** — the invalid tint becomes `not-focus:aria-invalid:border-destructive` (and its dark
  counterpart), so focus outranks it; the `aria-invalid` halo rings are removed with the rest.
- **INT-1** — `cursor-default` is removed from `SelectItem`, so a row shows the hand cursor the one
  global rule gives every `[role="option"]`. The two scroll arrows keep theirs: `base.css` names
  them as a sanctioned non-pointer cursor.
- **FRM-4** — `data-disabled:pointer-events-none` is dropped from `SelectItem`, so a disabled row
  stays hoverable and a Tooltip can explain it.
- **OVL-13** — `SelectContent` reads `useInternalThemeScope()` and attaches it to the positioner
  inside the portal; `tooling/verify-portal-theme-scope.mjs` inventories this host.
- **DOC-2** — `cn` is imported from `@vegastack/design`.

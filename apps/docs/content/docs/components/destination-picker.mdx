## Usage

```tsx
import { DestinationPicker } from "@/components/ui/destination-picker";

<DialogBody>
  <DestinationPicker
    spaces={spaces}
    loadFolders={(space, parent) => api.folders(space, parent)}
    value={target}
    onValueChange={setTarget}
    disabledReason={(d) =>
      d.folderId === item.parentId ? "It's already here" : undefined
    }
    recents={recentPlaces}
    search={(q, signal) => api.searchFolders(q, { signal })}
  />
</DialogBody>;
```

## Scope

The body of every "Move to…" dialog. The spaces are the top of a folders-only `FolderTree` in
picker mode; each opens to its folders (loaded once through `loadFolders`), and choosing a space
means its top level. The host owns the dialog and its Move button, enabled once `value` is set.

## Examples

### Move to…

`recents` sit above the tree, `search` finds a folder anywhere (the tree comes back when the box
is cleared), and `disabledReason` keeps a destination visible while refusing it: the reason shows
on the row, under the picker, and is announced.

## Accessibility

- The tree is `FolderTree`'s picker mode: one tab stop, arrow keys move and open, Enter chooses.
- A refused choice is announced through a polite live region and stays visible as text.

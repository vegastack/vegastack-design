## Usage

```tsx
import { ChatComposer } from "@/components/ui/chat-composer";
import { ComposerMeta } from "@/components/ui/composer-meta";

<ChatComposer
  onSubmit={send}
  meta={
    <ComposerMeta
      privacy="Private · AI can make mistakes"
      privacyDetail="Only you can see this chat. AI can make mistakes; check important info."
      plan={{ on: planOn, onToggle: togglePlan, shortcut: "⇧Tab" }}
      model={<ModelEffortMenu {...menu} />}
      context={<ContextRing used={used} window={window} parts={parts} />}
    />
  }
/>;
```

[`ChatComposer`](/docs/components/chat-composer)'s `meta`: one line of small muted text under the box.
On the left a short privacy note whose full sentence shows on hover, keyboard focus or a tap on a touch screen, and is its description for a screen reader; on the right **Plan**, the
[`ModelEffortMenu`](/docs/components/model-effort-menu) and the
[`ContextRing`](/docs/components/context-ring). No outlines: each control gets a faint pill on
hover, and Plan on reads in the primary ink with a small dot. On a narrow screen the privacy note
truncates first.

## Accessibility

- Plan is a button with `aria-pressed`; a held Plan is `aria-disabled` and keeps its tooltip.
- The privacy note is focusable when it has a tooltip, so the full sentence reaches keyboard users.

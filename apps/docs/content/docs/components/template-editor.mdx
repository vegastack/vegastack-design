## Usage

```tsx
import { TemplateEditor } from "@/components/ui/template-editor";

const specs = [
  { id: "power", label: "Power", hint: "W" },
  { id: "efficacy", label: "Efficacy", hint: "lm/W" },
];

<Field>
  <FieldLabel>Marketing description</FieldLabel>
  <TemplateEditor
    value={template}
    onChange={setTemplate}
    tokens={specs}
    placeholder="Type @ to insert a spec"
  />
</Field>;
```

The value is plain text. Each placeholder is written as `{{id}}`, paragraphs are separated by a
blank line (`\n\n`) and a single `\n` is a line break inside a paragraph, so
`"Recessed {{power}} downlight\n\nFits a {{cutout}} cut-out."` is two paragraphs with two chips.
The string round-trips exactly: rendering a value and changing nothing never calls `onChange`.

## Scope

- **Plain paragraphs only** — or one line, with `singleLine`. No Markdown, bold, lists, links, toolbar or slash menu — reach for
  `TextEdit` when the text needs formatting.
- **Placeholders are atomic.** A chip shows the token's `label`, deletes with one Backspace, and is
  stored by `id`, so renaming a spec relabels every chip without touching the value.
- **Nothing is lost.** An `{{id}}` whose id is not in `tokens` still renders, as the raw id in the
  destructive style; `invalidTokenIds` marks known tokens the same way.
- **Filling the placeholders is the caller's job** — the editor only writes the template.

### Single-line formula

`singleLine` makes it one line, sized like `Input`: <kbd>Enter</kbd> and <kbd>Shift</kbd>

<kbd>Enter</kbd> insert nothing, pasted line breaks become spaces, and a `value`
holding line breaks loads with spaces instead (long text still wraps on screen).
`replacements` rewrite characters as you type — here `*` becomes `×` and `/`
becomes `÷`, so the formula reads `Power × Efficacy`; <kbd>Backspace</kbd> right
after a replacement undoes it. The value keeps the replaced characters and the `
{{ id }}` tokens (`{{ power }} × {{ efficacy }}`), and `invalidTokenIds` marks a
spec the formula cannot use. Narrow the picker by passing only the tokens that
fit; `hint` shows each one's unit.

`triggers` picks what opens the picker: `@` at the start of a word and `{{` by default, or a
single `{` (`triggers={["{"]}`), as a formula writes a field. `pickerLabel` names the picker
("Insert field"). [`FormulaInput`](/docs/components/formula-input) is this editor set up for a
table's calculated field.

## Accessibility

- The editable surface is a `role="textbox"` with `aria-multiline="true"` (`"false"` with
  `singleLine`), named by `aria-label`,
  `aria-labelledby` or an enclosing `Field`'s label; a `Field`'s description, error and invalid
  state reach it too.
- The picker is the shared `SuggestionMenu` (also TextEdit's slash and mention menus): a `listbox`
  of `option`s that look exactly like `ComboboxItem` rows, with the token's `hint` as muted trailing
  text. Focus stays in the textbox, which points at the listbox with `aria-controls` and at the
  highlighted option with `aria-activedescendant` while it is open; moving the pointer over a row
  highlights it too. With no match the list is a `status` reading “No results”.
- The focus cue is text entry's: the box's border darkens subtly over 150ms and nothing fills
  (`data-focus-cue="border"`); an invalid box keeps its destructive border. Forced-colours mode
  restores a system outline.

| Key                                   | Action                                                  |
| ------------------------------------- | ------------------------------------------------------- |
| <kbd>@</kbd> or <kbd>{"{{"}</kbd>     | Open the placeholder list                               |
| <kbd>↑</kbd> <kbd>↓</kbd>             | Move through the list                                   |
| <kbd>Enter</kbd> / <kbd>Tab</kbd>     | Insert the highlighted placeholder (with the list open) |
| <kbd>Esc</kbd>                        | Close the list, keeping what was typed (a dialog stays) |
| <kbd>Backspace</kbd> / <kbd>Del</kbd> | Delete the chip before / after the caret as one unit    |
| <kbd>Enter</kbd>                      | New paragraph (list closed; not with `singleLine`)      |
| <kbd>Shift</kbd> <kbd>Enter</kbd>     | Line break in the paragraph (not with `singleLine`)     |

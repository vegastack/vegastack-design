## Usage

```tsx
import { LogoRow } from '@/components/ui/logo-row';

<LogoRow
  label="Built with"
  items={[{ name: 'ACME' }, { name: 'NIMBUS' }, { name: 'COREBASE' }]}
/>;
```

## Linked items

Pass `href` on an item to render it as a link, restoring to full alpha on hover/focus.

<ComponentPreview name="logoRowLinked" file="components/preview/logo-row.tsx" />

## Text only — never a fake logo

`LogoRow` renders wordmarks as plain **text**, never image/SVG logo assets — and never real
third-party brand names, since that would imply an unverified partnership. Use generic or
placeholder names on marketing pages until real, cleared logos exist.

## Accessibility

- Linked items render real `<a>` elements with visible, readable text — no icon-only logos to
  label.
- The optional `label` is a normal text node, read in document order before the list.

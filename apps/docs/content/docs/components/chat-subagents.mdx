## Usage

```tsx
import { BackgroundWork, SubagentsBlock } from "@/components/ui/chat-subagents";

<SubagentsBlock
  parts={subagentParts}
  live={running}
  onOpen={openBeside}
  onRetry={retry}
/>;
```

While the turn runs the rows show at once: a status word, the short title the engine gave the
Subagent and quiet meta ("3 steps · 41s", "waiting on you", "ran out of steps · Retry"). Each row
opens its steps beside the chat (a sheet on a phone). Settled, the block is one muted sentence
("Finished 4 Subagents · 1 stopped (ran out of steps) · $0.006") that opens the same rows. The
block never spins — the turn's live line does. `BackgroundWork` is a chip while work is live or
partly failed, and a muted line once it settles.

## Accessibility

- Each row is a button named by its status word, title and meta; Retry and "waiting on you" are separate buttons.
- The settled line is a disclosure (`aria-expanded`).

## Usage

```tsx
import {
  ChatMenu,
  ChatMenuItem,
  ChatMenuSeparator,
  ChatMenuSub,
} from "@/components/ui/chat-menu";

<ChatMenu trigger="Sonnet 5.5 · Medium" side="top" align="end">
  <ChatMenuItem selected shortcut="1" onSelect={() => pick("sonnet")}>
    Sonnet 5.5
  </ChatMenuItem>
  <ChatMenuItem shortcut="2" onSelect={() => pick("opus")}>
    Opus 5.5
  </ChatMenuItem>
  <ChatMenuSeparator />
  <ChatMenuSub label="Effort" value="Medium">
    <ChatMenuItem
      selected
      hint="Recommended"
      onSelect={() => setEffort("medium")}
    >
      Medium
    </ChatMenuItem>
  </ChatMenuSub>
</ChatMenu>;
```

One column, no empty detail pane. The selected item's ✓ is `primary` and shares the right
slot with its number shortcut; while the menu is open, pressing that number picks the item. A
`ChatMenuSub` shows its current value before the chevron and opens on hover, Enter or →; its own
numbers pick within it. A muted item with a hint ("Off · ask an admin") is something this person
can't use. For a general actions menu use [`DropdownMenu`](/docs/components/dropdown-menu).

### Purposes, explainers and opening at a submenu

`description` on an item is its one-line purpose ("Everyday work"), shown as a tooltip beside the row
on hover or focus and read as the item's description — never a detail pane. `note` on a
`ChatMenuSub` is a muted line above its items ("Higher effort thinks longer…"). `open` and
`onOpenChange` on a `ChatMenuSub` let a shortcut open the menu straight at it, as
[`ModelEffortMenu`](/docs/components/model-effort-menu)'s ⌘⇧E does.

## Accessibility

- Base UI's menu roles and focus management; each shortcut is declared with `aria-keyshortcuts`.
- The selected ✓ is named "Selected", so the choice is never colour alone.

| Key                              | Action                         |
| -------------------------------- | ------------------------------ |
| <kbd>1</kbd>–<kbd>9</kbd>        | Pick the item with that number |
| <kbd>↑</kbd> / <kbd>↓</kbd>      | Move between items             |
| <kbd>→</kbd>                     | Open a submenu                 |
| <kbd>←</kbd> / <kbd>Escape</kbd> | Close it                       |
| <kbd>Enter</kbd>                 | Pick the focused item          |

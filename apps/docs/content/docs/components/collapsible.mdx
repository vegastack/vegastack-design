## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible";

<Collapsible>
  <CollapsibleTrigger>Can I use this in my project?</CollapsibleTrigger>
  <CollapsibleContent>
    Yes. Free to use for personal and commercial projects. No attribution
    required.
  </CollapsibleContent>
</Collapsible>;
```

All three parts are unstyled pass-throughs, so the trigger is whatever you render into it — most
often a `Button` through `render`.

### Composition

A trigger and the panel it reveals. The trigger carries `aria-controls` and `aria-expanded`; the
panel carries the id they name.

```text
├── CollapsibleTrigger
└── CollapsibleContent
```

### Controlled State

`open` and `onOpenChange` hand the state to the parent — which is what lets a second control, or the
trigger's own icon, read the same value.

```tsx
const [open, setOpen] = React.useState(false);

<Collapsible open={open} onOpenChange={setOpen}>
  <CollapsibleTrigger>Toggle</CollapsibleTrigger>
  <CollapsibleContent>Content</CollapsibleContent>
</Collapsible>;
```

## API Reference

`Collapsible`, `CollapsibleTrigger` and `CollapsibleContent` add no props of their own — each accepts
everything the corresponding [Base UI Collapsible](https://base-ui.com/react/components/collapsible)
part accepts (`Root`, `Trigger`, `Panel`): `open` / `defaultOpen` / `onOpenChange` and `disabled` on
the root, `keepMounted` and `hiddenUntilFound` on the panel, plus `className`, `ref` and `render`
everywhere.

## Accessibility

- Renders Base UI's Collapsible: the trigger is a button carrying `aria-expanded` and, while open,
  `aria-controls` pointing at the panel.
- <kbd>Enter</kbd> and <kbd>Space</kbd> toggle the panel. The trigger stays
  focusable while `disabled`, so a keyboard user can still reach it and hear
  that it is unavailable.
- `hiddenUntilFound` on the panel uses `hidden="until-found"`, which lets the browser's find-in-page
  reach the collapsed text and expand the panel around it.
- Focus is the global 2px `:focus-visible` outline from `base.css`. The component contributes no
  focus styling of its own — whatever you render as the trigger brings its own.
- The component renders no icon and no label. Give an icon-only trigger an accessible name.

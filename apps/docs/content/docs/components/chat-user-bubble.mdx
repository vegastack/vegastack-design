## Usage

```tsx
import { UserBubble } from "@/components/ui/chat-user-bubble";

<UserBubble text={message.text} files={files} time="14:02" onEdit={edit} />;
```

The person's Markdown renders (bold, italic, code, lists, links, mentions as chips); images show as
thumbnails above the bubble and other files as chips. A long message is clipped at about nine
lines, the last 48px fading into the bubble's colour, with "Show more" — it opens on the chat's
state motion and becomes "Show less". Copy and Edit keep the source and show on hover (always on a
touch screen). Agent replies are never clipped.

## Accessibility

- "Show more" is a button with `aria-expanded` and `aria-controls` on the message.
- Copy and Edit are named icon buttons, reachable by keyboard even while hidden on hover.

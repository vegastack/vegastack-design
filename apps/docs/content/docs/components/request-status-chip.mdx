## Usage

```tsx
import { RequestStatusChip } from "@/components/ui/request-status-chip";

<RequestStatusChip state={row.state} label={row.statusLabel} />;
```

The eight states are the request lifecycle's: Draft, Open, In progress, Awaiting approval,
Approved, Declined, Completed and Cancelled. The tone always follows `state`; `label` swaps the
words for a table's renamed Status label or the name of a stage inside In progress. The chip shows
the status only: the request's ID sits beside it in your row.

## Accessibility

- The chip is text: its words say the status, so the tone is never the only cue.
- A status family's ink sits on its own tint (A11Y-13).

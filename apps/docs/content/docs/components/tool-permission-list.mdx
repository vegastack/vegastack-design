## Usage

```tsx
import { ToolPermissionList } from "@/components/ui/tool-permission-list";

<ToolPermissionList
  title="GitHub"
  meta="Connected · company GitHub App"
  rows={rows}
  onChange={(rowId, change) => save(rowId, change)}
  onAddRule={(rowId) => openConditionEditor(rowId)}
  onEditRule={(rowId, ruleKey) => openConditionEditor(rowId, ruleKey)}
  onRemoveRule={removeRule}
  onUseInherited={useInherited}
/>;
```

One list per source of tools. A class row ("Write · 31") is the group: its answer covers its tools,
which sit under it, and changing it is `onChange("class:<class>", { answer })`. Each row's menu
offers only its `answersAllowed`, with the exact words: Allow ("Runs without asking"), Auto-check
("A quick model check decides; asks when unsure"), Ask ("Asks a person") and Block ("Never runs").
The list keeps no answers of its own: every change goes to `onChange` and the caller's rows come
back.

## Examples

### Inherited, locked and rules

An inherited answer is muted with where it comes from ("Inherited from workspace"). A locked row
shows the lock and who locked it, read-only. The rules at this layer list under their row, each
with its answer, its condition, its note, "Waiting to be published" while pending, and Edit or
Remove when editable. A row's ⋯ offers "Add a condition" and, when the row has rules here, "Use
inherited"; with only one of them it is a quiet button of its own. Picking Allow on a row with
`warningOnAllow` shows that line under it.

### An admin's view

## Accessibility

- The list is a region named by the source.
- Each answer is a labelled menu (“GitHub › Send answer: Ask”) offering only the allowed answers.
- A class group's toggle is a button with `aria-expanded` and `aria-controls`.
- The lock toggle is a pressed/unpressed button named for its tool (“Lock GitHub › Send for every agent”).
- A row's rules are a list named for its tool (“Rules for GitHub › Send”).

| Key                                 | Action                                   |
| ----------------------------------- | ---------------------------------------- |
| <kbd>Tab</kbd>                      | Move between toggles, menus and buttons  |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open a menu, fold a class, toggle a lock |
| <kbd>↑</kbd> / <kbd>↓</kbd>         | Move through a menu's answers            |
| <kbd>Esc</kbd>                      | Close the menu                           |

## Usage

```tsx
import { ToolPermissionList } from "@/components/ui/tool-permission-list";

<ToolPermissionList
  title="GitHub"
  meta="Connected · company GitHub App"
  note="New tools from GitHub follow All tools."
  scope={{ value: scope, options: SCOPES, onChange: setScope }}
  rows={rows}
  onChange={(rowId, change) => save(rowId, change)}
  onAddRule={(rowId) => openConditionEditor(rowId)}
  onEditRule={(rowId, ruleKey) => openConditionEditor(rowId, ruleKey)}
  onRemoveRule={removeRule}
  onUseInherited={useInherited}
/>;
```

One list per source of tools. An `all` row ("All tools") answers every tool of the source and is
always drawn first, above the classes, as a plain row with its own answer menu, its label lined up
with the class labels. A class row ("Write · 31") is the group: its answer covers its tools, which
sit under it, and changing it is `onChange("class:<class>", { answer })`. Each row's menu offers
only its `answersAllowed`, with the exact words: Always allow ("Runs without asking."), Needs
approval ("Asks a person each time.") and Blocked ("Never runs. The agent isn't offered it."). The
list keeps no answers of its own: every change goes to `onChange` and the caller's rows come back.

`scope` draws a segmented "Applies to" switch at the header's end ("Every agent" · "This agent"),
and `note` one muted line under the header ("New tools from GitHub follow All tools.").

## Examples

### Followed answers, the default, locks and rules

An answer that comes from elsewhere is muted with where it comes from: "From workspace", "From
your admin's lock", "From this agent's rules", "From your rules", "From Standard level". While a
row holds its own rule, its answer menu ends with "Use the default" after a separator, described
`Follows {defaultFrom}.` (`onUseInherited` removes the row's rules at this layer). A locked row
shows the lock and who locked it, read-only. The rules at this layer list under their row, each
with its answer, its condition (an unconditional rule reads its answer alone), its note, "Waiting to be published" while pending, and Edit or
Remove when editable. "Add a condition" is a quiet icon button at the row's end. Picking Always
allow on a row with `warningOnAllow` shows that line under it.

## Accessibility

- The list is a region named by the source.
- Each answer is a labelled menu (“GitHub › Send answer: Needs approval”) offering only the allowed
  answers, then “Use the default” while the row holds its own rule.
- The scope switch is a group named “Applies to”; each option is a pressed/unpressed button.
- A class group's toggle is a button with `aria-expanded` and `aria-controls`.
- The lock toggle is a pressed/unpressed button named for its tool (“Lock GitHub › Send for every agent”).
- A row's rules are a list named for its tool (“Rules for GitHub › Send”).

| Key                                 | Action                                   |
| ----------------------------------- | ---------------------------------------- |
| <kbd>Tab</kbd>                      | Move between toggles, menus and buttons  |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open a menu, fold a class, toggle a lock |
| <kbd>↑</kbd> / <kbd>↓</kbd>         | Move through a menu's answers            |
| <kbd>Esc</kbd>                      | Close the menu                           |

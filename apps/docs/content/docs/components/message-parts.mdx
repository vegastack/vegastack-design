## Usage

```tsx
import { Citation } from "@/components/ui/cited-list";
import { Message, MessageContent } from "@/components/ui/message";
import {
  MessageActions,
  MessageDisclaimer,
  MessageSources,
  MessageStep,
  MessageSteps,
} from "@/components/ui/message-parts";

<Message>
  <MessageContent>
    <MessageSteps summary="2 steps · Searched meetings">
      <MessageStep label="Searched meetings" meta="2 results" />
      <MessageStep label="Read Range review 28 Oct" />
    </MessageSteps>
    <p>You agreed to keep 4000 K for the IP65 range.</p>
    <MessageSources>
      <Citation href="/meetings/28">Range review 28 Oct</Citation>
    </MessageSources>
    <MessageDisclaimer>Generated by AI · can make mistakes</MessageDisclaimer>
    <MessageActions>{/* Copy, Retry */}</MessageActions>
  </MessageContent>
</Message>;
```

Compose these inside [`MessageContent`](/docs/components/message), next to the text. Two things a
chat needs are upstream's already, so there is no part for them: a person's message is
[`Bubble`](/docs/components/bubble) with `align="end"`, and a message still streaming is `aria-busy`
on `Message`, which keeps a screen reader from reading it word by word.

### Status while it works

`MessageStatus` is the one line saying what the agent is doing now. Replace its text as the agent
moves on and remove it when the answer's text starts.

## Accessibility

- `MessageStatus` and `MessageNotice` are `role="status"`; `status="error"` is `role="alert"`.
- A plan item's state is read out from `stateLabels`, since the icon alone shows it.
- `MessageActions` keeps its buttons in the Tab order while hidden: focus reveals them.

| Key                                 | Action                                       |
| ----------------------------------- | -------------------------------------------- |
| <kbd>Tab</kbd>                      | Move through the steps line and the actions  |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open the steps, press an action, fold or not |

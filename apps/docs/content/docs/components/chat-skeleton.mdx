## Usage

```tsx
import { ChatSkeleton, ScrollToLatest } from "@/components/ui/chat-skeleton";

{
  loading ? <ChatSkeleton /> : thread;
}
<ScrollToLatest
  visible={awayFromBottom}
  hasNew={unread}
  onClick={scrollToEnd}
/>;
```

`ChatSkeleton` sketches each turn — the person's bubble, the agent's author line, three lines of
answer — and waits 150ms before it fades in, so a fast load never flashes it. `ScrollToLatest` is a
32px round button on the popover surface with a small shadow; it fades and rises 8px into place
when the reader is more than about 80px from the bottom, and a primary dot says new words arrived.

## Accessibility

- The skeleton is one `status` named "Loading the chat".
- The scroll button's name adds "new messages" when the dot shows; hidden, it leaves the tab order.

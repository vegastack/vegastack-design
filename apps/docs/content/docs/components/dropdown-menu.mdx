## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";

<DropdownMenu>
  <DropdownMenuTrigger render={<Button variant="outline" />}>
    Open
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuGroup>
      <DropdownMenuLabel>My Account</DropdownMenuLabel>
      <DropdownMenuItem>Profile</DropdownMenuItem>
      <DropdownMenuItem>Billing</DropdownMenuItem>
    </DropdownMenuGroup>
    <DropdownMenuSeparator />
    <DropdownMenuGroup>
      <DropdownMenuItem>Team</DropdownMenuItem>
      <DropdownMenuItem>Subscription</DropdownMenuItem>
    </DropdownMenuGroup>
  </DropdownMenuContent>
</DropdownMenu>;
```

### Destructive

`variant="destructive"` sets `data-variant="destructive"` on the row, which tints the label, the
icon and the focus wash from the `destructive` token; the focused label reads in the
`destructive-text` ink so it clears AA on the wash. Reserve it for the irreversible action, and
never for more than one row in a group.

## Accessibility

- Renders Base UI's Menu: the trigger is a button with `aria-haspopup="menu"` and
  `aria-expanded`; the popup is a `role="menu"` of `menuitem`, `menuitemcheckbox` and
  `menuitemradio` rows with type-ahead, <kbd>↑</kbd>/<kbd>↓</kbd>, <kbd>Home</kbd>/<kbd>End</kbd>,
  <kbd>→</kbd>/<kbd>←</kbd> for submenus and <kbd>Esc</kbd> to close.
- Closing returns focus to the trigger, and a submenu closing returns it to its sub trigger.
- The popup portals out of the trigger's subtree, so `DropdownMenuContent` re-applies the theme
  scope on the positioner inside the portal and `DropdownMenuPortal` re-applies it on a
  `display: contents` wrapper (OVL-13) — a dark or scoped surface survives the portal.
- Rows carry the hand cursor from the one global rule in `base.css` (INT-1); upstream's local
  `cursor-default` is removed.
- A disabled row keeps its pointer events (FRM-4), so a Tooltip can explain why it is unavailable.
- Give an icon-only trigger an `aria-label`.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/dropdown-menu.patch`. Every hunk:

- **OVL-13** — two hosts, because upstream has two. `DropdownMenuContent` opens its own
  `Menu.Portal`, so it reads `useInternalThemeScope()` and attaches it to the Positioner inside
  it; the exported pass-through `DropdownMenuPortal` wraps its children in a `display: contents`
  element carrying the same class, so the escape hatch is scoped too.
- **OVL-14** — `DropdownMenuContent` forwards an optional `container` to its `Menu.Portal`, and
  `DropdownMenuSubContent` inherits it by being one. Upstream forwards none, and a portal defaults
  to `document.body`, which the Fullscreen API paints the fullscreen element over; a fullscreen
  player's settings menu rendered invisibly behind it. Leaving `container` unset is upstream's own
  default, so nothing else moves.
- **INT-1** — `cursor-default` is removed from the item, the submenu trigger, the checkbox item
  and the radio item, so a menu row shows the hand cursor the one global rule in `base.css` gives
  every `[role^="menuitem"]`.
- **FRM-4** — `data-disabled:pointer-events-none` is dropped from the item, the checkbox item and
  the radio item, so a disabled row stays hoverable and a Tooltip can explain why.
- **BRD-1** — `DropdownMenuContent` and `DropdownMenuSubContent` draw a real 1px `border border-border` instead of upstream's
  `ring-1 ring-foreground/10` box-shadow outline. A border survives forced colours and matches
  [Elevation](/docs/foundations/elevation); nothing else about the surface moves.
- **A11Y-13** — a focused destructive `DropdownMenuItem` reads `focus:text-destructive-text` on its
  `bg-destructive/10` wash. Upstream inks it with the fill (`focus:text-destructive`), which
  measures 3.99:1 on its own tint in light, under the AA floor; the resting ink and the icon
  ink stay upstream's.
- **DOC-2** — `import { cn } from "cn"` becomes `@vegastack/design`; our npm layer owns `cn`.
- **DOC-1** — prettier reflow plus the `registry-stamp.mjs` provenance header; no decision of
  their own.

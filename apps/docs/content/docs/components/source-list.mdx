## Usage

```tsx
import { SourceList, sourceCitations } from "@/components/ui/source-list";

<MarkdownView citation={sourceCitations(sources)}>{answer}</MarkdownView>
<SourceList sources={sources} />;
```

Only web pages are sources. The answer's `[[n]]` markers become numbered pills whose card is page
n's `SourceCard`; under the answer, "Sources · 3 ›" opens one 28px row per page: its number, its
site's icon, its title, the site and ↗. The person's own things — a Doc, a Meet, a pull request —
are [`ResourcePill`](/docs/components/resource-pill)s in the text and never appear here.

Site icons come from the host. In dark mode each sits on a light tile, so a dark mark stays
visible; a page with no icon shows a globe.

## Anatomy

- `SourceList` — the "Sources · n ›" fold under the answer and its numbered rows.
- `SourceCard` — one page as the card a `[[n]]` pill opens; `sourceCitations` builds MarkdownView's
  `citation` answer from the same list.
- `SiteIcon` — a site's 16px icon, on a light tile in dark mode, or a globe.

## Accessibility

- The closed line is a disclosure button; the open list is an ordered list named "Sources".
- Each row is one link: its title, then "(opens in new tab)" for screen readers.
- A citation pill is named "Source n: <title>".

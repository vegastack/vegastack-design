## Usage

```tsx
import { RegionSelect } from "@/components/ui/region-select";

const [state, setState] = React.useState("");

<RegionSelect country="US" value={state} onValueChange={setState} />;
```

`RegionSelect` is controlled: pass the selected subdivision `code` as `value` and update it from
`onValueChange`. The `country` prop (an ISO-3166-1 alpha-2 code) decides which subdivisions are
offered — and whether the searchable dropdown or the free-text fallback is shown.

It is a single composite: a thin, data-fed composition of our [Combobox](/docs/components/combobox)
(the "Select-style" pattern — the search input lives inside the popup, not on the always-visible
trigger) for the combobox path, or `Input` for the fallback path. A leading `MapPin` icon marks the
field as a location input in both modes.

## Examples

### Countries

The embedded `REGIONS_BY_COUNTRY` dataset covers 45 countries and 1,187 subdivisions: US states,
Canadian provinces, Australian states/territories, Indian states/UTs, UK regions, and high-volume
billing/shipping markets across the Americas, Europe, Africa, the Middle East, and Asia-Pacific. Each
supported country renders a searchable combobox with live filtering; countries outside the dataset fall
back to free text.

### Toggle to clear

Re-selecting the **already-selected** state clears the field — `onValueChange` fires with an empty
string (`""`) and the trigger returns to its placeholder. This lets a user reset the value without a
separate "clear" affordance.

## Accessibility

- The trigger exposes `role="combobox"` with `aria-expanded`/`aria-haspopup="dialog"`; opening
  reveals a listbox of options with live, type-to-filter search inside the popup.
- Full keyboard support is handled by the underlying Combobox: type to filter, <kbd>↑</kbd> /
  <kbd>↓</kbd> to move the highlight, <kbd>Enter</kbd> to select, and
  <kbd>Esc</kbd> to dismiss — focus returns to the trigger on close.
- The free-text fallback is a native `<input>`; associate a label via `id` for both modes.
- Focus re-colors the trigger/search border with the `ring` token (`border-ring/(--alpha-tint-border)`) — never `outline: none`.

| Key                                 | Action                                      |
| ----------------------------------- | ------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open the popover from the trigger.          |
| <kbd>↑</kbd> / <kbd>↓</kbd>         | Move the highlight between matching states. |
| <kbd>Enter</kbd>                    | Select the highlighted state and close.     |
| <kbd>Esc</kbd>                      | Close without changing the selection.       |

## Examples

### Variants

Use the `variant` prop to change the variant of the badge. Upstream ships six; the four semantic
status families (COL-12) add `success`, `warning` and `info` beside `destructive`, written in
upstream's own tinted shape.

### With Icon

You can render an icon inside the badge. Use `data-icon="inline-start"` to render the icon on the
leading edge and `data-icon="inline-end"` to render it on the trailing edge.

<ComponentPreview name="badgeWithIcon" file="components/preview/badge.tsx" />

### With Spinner

You can render a spinner inside the badge. Give the spinner the same `data-icon` attribute so it
takes the icon spacing.

<ComponentPreview name="badgeWithSpinner" file="components/preview/badge.tsx" />

### Link

Use the `render` prop to render a link as a badge. The badge is a `span` by default, so the anchor
brought in through `render` is what carries the link role.

<ComponentPreview name="badgeLink" file="components/preview/badge.tsx" />

### Custom Colors

You can retint a badge by passing classes through `className`. Upstream's example reaches for the
raw Tailwind palette; use semantic tokens instead, so the override follows the theme into dark mode
and survives a retheme.

## Accessibility

- Renders a `span` — a badge is a label, not a control, and it is not focusable or clickable on its
  own. Pass `render` to make it an anchor or a button when it has to be operable.
- The tint never carries the meaning on its own (A11Y-8): every status badge keeps its word, and an
  icon beside it is decorative rather than load-bearing.
- Each tinted status variant takes the family's `-text` ink over its `/10` fill (A11Y-13), which
  clears the AA contrast floor in both themes.
- The component carries no focus ring of its own. When `render` makes it operable, the global
  `:focus-visible` outline in `base.css` applies (FOC-1, FOC-6).

## Deviations

Upstream's file plus `packages/ui/upstream/patches/badge.patch`. Every hunk:

- **FOC-1, FOC-6** — the `focus-visible:border-ring focus-visible:ring-[3px] focus-visible:ring-ring/50`
  glow and the `aria-invalid` rings are removed; `base.css` owns focus outright.
- **FOC-5** — the invalid border becomes `not-focus:aria-invalid:border-destructive`, so a focused
  badge shows the focus cue rather than the red tint.
- **COL-12** — `success`, `warning` and `info` variants, in upstream's own `destructive` shape.
- **A11Y-13** — each tinted status variant takes the family's `-text` ink; `bg-<family>/10` under
  `text-<family>` measures between 3.98:1 and 4.35:1, under the AA floor A11Y-1 enforces.
- **A11Y-8** — a badge is a labelled chip: the tint never carries the meaning alone.
- **DOC-2** — `cn` is imported from `@vegastack/design`.

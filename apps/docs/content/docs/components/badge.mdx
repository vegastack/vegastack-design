### Variants

`subtle` (tinted background, the default), `solid` (full-color background with
on-color text), `minimal` (borderless text only), and `outline` (hairline border,
no fill — the neutral/hued tag chip).

### Colors

Color is a semantic token (`default`, `success`, `warning`, `destructive`,
`info`) — never an arbitrary hex. Each color maps to design-system tokens across every
variant: `subtle` (soft tint), `solid` (full fill), and `minimal` (colored text only).

### Sizes

`sm`, `default`, and `lg` — the dot and icon scale with the badge.

### States

Add a leading `dot` indicator, compose an icon as the first child, or set `loading` to show a
spinner and `aria-busy`. `loading` takes precedence over both `dot` and a leading icon — the
`dot` is ignored while loading.

<ComponentPreview name="badgeStates" file="components/preview/badge.tsx" />

On the `solid` variant the `dot` switches to `bg-current`, inheriting the on-color foreground so
it stays legible against the filled background.

<ComponentPreview name="badgeSolidDot" file="components/preview/badge.tsx" />

### Motion

Pass `animateIn` to pop the badge in (`motion-pop-in`) when its own appearance is the signal — a
status that just flipped, a label freshly applied. It's **off by default**: a badge rendered as
part of a static list (a table column, a filter chip row) must not pop every time its parent
re-renders or mounts.

## Accessibility

- Renders a non-interactive `<span>` by default — a badge is a label, not a control.
- The `dot` and `loading` spinner are decorative (`aria-hidden`); the badge text carries the meaning,
  so never rely on color or the dot alone to convey status.
- `loading` sets `aria-busy="true"` while content is updating.
- The loading spinner pairs `animate-spin` with `motion-reduce:animate-none`.
- Use `render` to compose with a link when a badge needs to navigate, keeping the surrounding text as
  the accessible name.

## Tag chips — bordered & outline

The Attio-teardown chip formula: `bordered` draws the matching-hue hairline on the subtle
tint (crisper edges on white); `variant="outline"` is the fill-less neutral/hued tag. Compose
a `+N` overflow as a neutral outline badge — or reach for `TagGroup`, which does it for you.

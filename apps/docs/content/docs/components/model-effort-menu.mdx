## Usage

```tsx
import { ModelEffortMenu } from "@/components/ui/model-effort-menu";

<ModelEffortMenu
  models={[
    {
      id: "sonnet",
      label: "Sonnet 5.5",
      description: "Everyday work",
      available: true,
    },
    {
      id: "opus",
      label: "Opus 5.5",
      description: "Hard problems",
      available: true,
    },
    {
      id: "haiku",
      label: "Haiku 5.5",
      description: "Quick answers",
      available: true,
    },
  ]}
  moreModels={[{ id: "gpt", label: "GPT-6", available: false }]}
  modelId={modelId}
  onModel={setModel}
  efforts={["low", "medium", "high", "max"]}
  recommended="medium"
  effort={effort}
  onEffort={setEffort}
  shortcuts
/>;
```

The model and its effort, "Sonnet 5.5 Medium ▾", in the composer's actions row
(`ChatComposerActionsEnd`, see [`ChatComposer`](/docs/components/chat-composer)), just before Send. It opens one [`ChatMenu`](/docs/components/chat-menu) about 240px wide: the models,
each with a primary ✓ or its number in one right slot and its purpose as a tooltip — never a detail
pane; then **Effort Medium ›**, whose submenu opens with a one-line explainer and lists only the
levels the chosen model supports (`efforts`), "Recommended" on its default and a usage warning, the
only amber, on Max; then **More models ›**, where models this person can't use are muted with
"Off · ask an admin". Effort lasts for the chat; a new chat starts from the agent's setting.

## Accessibility

- The trigger is named "Model: Sonnet 5.5, effort Medium"; the menu has Base UI's roles and focus
  management, and each number shortcut is declared with `aria-keyshortcuts`.
- A model's purpose is its item's description, so a screen reader hears it without the tooltip.

| Key                                  | Action                               |
| ------------------------------------ | ------------------------------------ |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>I</kbd> | Open the menu (with `shortcuts`)     |
| <kbd>⌘</kbd><kbd>⇧</kbd><kbd>E</kbd> | Open it at Effort (with `shortcuts`) |
| <kbd>1</kbd>–<kbd>9</kbd>            | Pick that model                      |
| <kbd>→</kbd>                         | Open Effort or More models           |
| <kbd>Escape</kbd>                    | Close                                |

On Windows and Linux, Ctrl stands for ⌘.

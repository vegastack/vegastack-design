## Usage

```tsx
import { ChatRequestCard } from "@/components/ui/chat-request-card";

<ChatRequestCard
  agent={{ name: "William" }}
  data={request}
  onAnswer={(choiceId, note) => answer(request.interactionId, choiceId, note)}
/>;
```

The buttons are exactly `data.offer.choices`, the options the server says it will accept: `once`
is the primary button, every `always:*` choice sits in one "Always allow" menu with its scope,
`never` is a quiet text button with the server's words ("Never allow this"), and `decline` is a
quiet text button that opens a note to the agent. When Always can't be offered,
`offer.noAlways.words` says why under the buttons. While `onAnswer` runs the buttons hold; once
the request is answered, refused, withdrawn or expired the card becomes a `RequestLine`.

`data.quote` is the exact text the step would send, such as a message, or an email's To, Subject
and body. It's quoted under the subject with its line breaks kept, so whoever answers sees what
they allow. A long quote scrolls inside its block instead of pushing the buttons away.

### Several at once

Subagents asking together become one card with the choices every ask offers
(`offer.bundle.choices`): Allow all once, Always allow these (a menu when there are several
scopes), Never allow these, Decline, or Choose each to answer row by row. `onAnswerAll` gets the
chosen bundle choice's id.

## Accessibility

| Key      | Does                                                  |
| -------- | ----------------------------------------------------- |
| `Tab`    | Moves through the choices                             |
| `Enter`  | Picks the focused choice; in the note field, declines |
| `1`–`9`  | In the Always menu, picks that scope                  |
| `Escape` | Closes the Always menu, or leaves the note field      |

- The card is `aria-busy` while an answer is on its way; nothing on it spins.
- A settled line's glyph is decorative; its words say what happened.

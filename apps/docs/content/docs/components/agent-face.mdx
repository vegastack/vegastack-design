## Usage

```tsx
import { AgentFace } from "@/components/ui/agent-face";

<AgentFace
  face={{ v: 1, preset: "squish", palette: "violet" }}
  size={64}
  state="thinking"
  motion
  label="Scout, agent, thinking"
/>;
```

Agents are faces, not hexagons (BRD-13). Every agent is one of 18 preset characters (shape, eyes
and mouth, designed together) in one of 9 palettes built from the accent theme colours. Avatars in
rows, chips and stacks don't use this directly: [`PersonAvatar`](/docs/components/person-hover-card)
draws an agent's face from `person.face`. Use `AgentFace` on its own for a face picker, an agent's
header or an onboarding moment.

### Palettes

Blue, Violet, Pink, Orange, Green and Teal take the accent theme colours: the light tone, the theme
colour's dark-mode text value and its light fill. Ink stands in for Black; Mist and Glass are the
neutrals. Each palette has a companion that colours a Cairn's top stone and a Stack's lower layers.

### States

Motion means busy, the cue's colour says who acts next (the agent's colour: it is busy; amber:
you; blue: something new for you; red: it is stuck; grey: it isn't running), and grey means it
can't act. From 40px each state has a cue on the head's shoulder: thought bubbles while it thinks, orbiting
dots while it works, a typing pill while it writes, amber ticks when it needs you, sparkles when it
replied, a red alert when it failed, z's when it is scheduled and a pause sign when it is paused.
The Dot badges only the states that need a person: amber, blue and red. A state change blinks and
squashes once.

| State     | Eyes and mouth                                         | Body                               | Cue             |
| --------- | ------------------------------------------------------ | ---------------------------------- | --------------- |
| Idle      | Open, blinking, glancing; a resting smile              | Slow breath                        | None            |
| Thinking  | Look up toward the cue, lids lowered; a sideways "hmm" | Head tilts; a light travels inside | Thought bubbles |
| Working   | Narrowed, scanning; pressed mouth                      | Steady bob, a sheen sweeps across  | Orbiting dots   |
| Writing   | Look down along the line; the mouth talks              | Squashes in rhythm                 | Typing pill     |
| Needs you | Wide, brows raised; a hopeful smile                    | Hops, warm glow                    | Amber ticks     |
| Replied   | Smiling eyes                                           | Sways, a small hop now and then    | Sparkles        |
| Failed    | Worried brows, looking down; a small frown             | Tilts and stops, colour drains     | Red alert       |
| Scheduled | Closed                                                 | Slow deep breath, light dims       | z's             |
| Paused    | A flat line                                            | Still, all grey                    | Pause sign      |

## Accessibility

- A named face is one image (`role="img"`) with its `label`, such as "Scout, agent, thinking";
  `label=""` hides it when the name and state are written beside it.
- A state is never told by colour alone: each cue has its own shape, and every surface also writes
  the state's word.
- It moves only with `motion`, and never under reduced motion: every animation starts and ends on
  the still pose (MOT-15).

## Usage

```tsx
import { MembersStack } from "@/components/ui/members-stack";

<MembersStack people={members} total={23} />;
```

One component draws who has access to (or is in) a place, in every spot that shows it: the page
bar's members slot (`ShellTopBarMembers`), a space or record header, the Share button and a list
row's Members cell. Faces are 24px, overlapped by 6px, each with a 2px ring in the colour of the
surface beneath. At most three faces show; the rest are a "+N" pill of the same 24px height
(11px semibold tabular figures on the muted fill), overlapped the same way, so it is never larger
than a face. Past 99 it reads "99+".

## Examples

### Every combination

| Who               | Drawn as                                   |
| ----------------- | ------------------------------------------ |
| Only you          | A lock and "Only you", with no button      |
| You and one other | Both faces                                 |
| Two or three      | Every face                                 |
| Four or more      | Three faces and "+N"                       |
| A whole space     | The space's tile and "Everyone in General" |
| A team            | The team's tile and "Sales · 8"            |
| Nobody (a draft)  | Nothing                                    |

`audience` picks the form (`people`, `only-you`, `everyone`, `team`); `group` is the space,
workspace or team drawn as its tile.

### Order

People active now come first, with a green dot on their face (`active`). Then the order you pass:
the most recent editors, then everyone else by name. You (`you`) are never the first face unless
you are alone. `orderMembers` applies the rule, if you need it elsewhere.

### In a list row

`count` adds the number after the faces, 8px on ("23 members"; pass a function to word it). The
stack stops its click from opening the row, so its popover opens in place.

### Partial lists and a footer

When only the first people are loaded, pass `total`: "+N", the count and the list's "and N more"
count from it. `footer` ends the members popover with the host's action, such as "Manage access"
or "Manage members". The popover is the same everywhere: a click on any stack opens it.

### Viewers

`variant="viewers"` is the page bar's compact stack of who has seen a record: 22px faces overlapped
by 8px, at most three, then "+N". Someone viewing now (`active`) leads, ringed with a thin 1.5px ring
in their own hue instead of a dot. A click opens the popover grouped "Viewing now", then "Viewed",
each with when they last looked (`viewedAt`, "2h ago"), and ends in the `footer` ("Manage access").
`audience` and `count` don't apply.

## Accessibility

- The stack is one button named `"{label}: {names}"` (up to ten, then "and N more"), or
  `"{label}: Everyone in General"`; the same names show in its tooltip on hover and focus.
- The click opens the full list in a popover, so keyboard and touch users reach every person.
- The active dot is decorative: say who is here in text where it matters.
- "Only you" is plain text, not a button: there is no one else to list.

| Key                                 | Action                   |
| ----------------------------------- | ------------------------ |
| <kbd>Tab</kbd>                      | Move to the stack        |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open the members popover |
| <kbd>Esc</kbd>                      | Close the popover        |

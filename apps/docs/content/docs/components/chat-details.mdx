## Usage

```tsx
import {
  ChatDetails,
  ChatDetailsRow,
  ChatDetailsSection,
} from "@/components/ui/chat-details";

<ChatDetails>
  <ChatDetailsSection title="Outputs" count={outputs.length}>
    {outputs.map((file) => (
      <ChatDetailsRow
        key={file.id}
        icon={<FileIcon />}
        title={file.name}
        meta={file.when}
        onOpen={open}
      />
    ))}
  </ChatDetailsSection>
</ChatDetails>;
```

Beside the chat on screens 1280px and wider (a sheet on a phone): Context, Outputs, Subagents and
background work, Connectors. Each section is a small title with its count, rows of an icon, a name
and muted meta, and "Show N more" past its limit. A Subagent opened from the thread shows its steps
here under `ChatDetailsBack`.

## Accessibility

- The panel is an `aside` named "Chat details"; each section is a region named by its title.
- Rows that open something are buttons or links; "Show more" says how many it adds.

## Usage

```tsx
import { ContextPanel } from "@/components/ui/context-panel";

<ContextPanel
  used={25_900}
  window={200_000}
  parts={[
    { id: "instructions", label: "Instructions and tools", tokens: 15_700 },
    { id: "memory", label: "Memory", tokens: 2_100 },
    { id: "conversation", label: "Conversation", tokens: 6_900 },
    { id: "tools", label: "Tool results", tokens: 1_200 },
  ]}
  onSummarize={summarize}
/>;
```

The body of [`ContextRing`](/docs/components/context-ring)'s panel, and of a Context section in a
chat's side panel or a phone sheet. "26% used" with the tokens against the window, one segmented
bar, then a legend — a swatch, the label, its tokens and its share in two tabular columns — that
always adds up to the window: measured tokens the parts don't name list as Other, and Free ends it.
Then where older messages get summarised and, given `onSummarize`, Summarize now, with nothing after
it.

## Accessibility

- The legend is a description list: each label is a term, its tokens and share its details.
- The bar and swatches are decorative; every number is also in words.

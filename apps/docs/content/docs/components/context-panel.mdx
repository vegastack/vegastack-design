## Usage

```tsx
import { ContextPanel } from "@/components/ui/context-panel";

<ContextPanel
  used={25_900}
  window={200_000}
  parts={[
    { id: "instructions", label: "Instructions and tools", tokens: 15_700 },
    { id: "memory", label: "Memory", tokens: 2_100 },
    { id: "conversation", label: "Conversation", tokens: 6_900 },
    { id: "tools", label: "Tool results", tokens: 1_200 },
  ]}
  onSummarize={summarize}
/>;
```

The body of [`ContextRing`](/docs/components/context-ring)'s panel, and of a Context section in a
chat's side panel or a phone sheet. "26% used" with the tokens against the window, one segmented
bar, then a legend — a swatch, the label, its tokens and its share in two tabular columns — that
always adds up to the window: measured tokens the parts don't name list as Other, and Free ends it.
Then where the conversation auto-compacts ("Auto-compacts at 90%") and, given `onSummarize`,
Continue in a new chat, with nothing after it.

## Examples

### What the parts don't name

When `used` is more than the parts add up to, the rest shows as Other, so the rows still sum to the
window.

With `used={null}` the panel says it is measured after the first answer and Continue in a new chat is held.

### In a side panel

`variant="panel"` is the compact form for a record side panel's Details: one line, "9% · 37.5k /
400k", whose tooltip says where the conversation auto-compacts; the bar; then each part as a row —
swatch, label, tokens — with its share of the window in a tooltip, and Free muted last. It has no
title and no button: put the action in the section header (`RecordPanelAction`).

## Accessibility

- The legend is a description list: each label is a term, its tokens and share its details.
- The bar and swatches are decorative; every number is also in words.

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";

<Accordion defaultValue={["item-1"]}>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA design pattern.
    </AccordionContent>
  </AccordionItem>
</Accordion>;
```

`value` and `defaultValue` are arrays, even when only one section can be open — the single-open rule
is the default, and `multiple` lifts it.

### Composition

An `AccordionItem` pairs a trigger with the panel it reveals, and the `value` on the item is what
`defaultValue` and `value` on the root name.

```text
Accordion
├── AccordionItem
│   ├── AccordionTrigger
│   └── AccordionContent
└── AccordionItem
    ├── AccordionTrigger
    └── AccordionContent
```

## API Reference

`Accordion`, `AccordionItem`, `AccordionTrigger` and `AccordionContent` add no props of their own —
each accepts everything the corresponding [Base UI Accordion](https://base-ui.com/react/components/accordion)
part accepts (`Root`, `Item`, `Trigger`, `Panel`): `value` / `defaultValue` / `onValueChange`,
`multiple`, `disabled`, `keepMounted` and `hiddenUntilFound` on the root, `value` and `disabled` on
an item, plus `className`, `ref` and `render` everywhere.

## Accessibility

- Renders Base UI's Accordion: each trigger is a button inside a heading, carrying `aria-expanded`
  and `aria-controls`, and the panel it names is a labelled region.
- <kbd>Tab</kbd> moves between triggers, <kbd>Enter</kbd> and <kbd>Space</kbd>
  toggle the focused section. Base UI follows the 2024 APG update that removed
  roving focus from the pattern, so every trigger is its own tab stop.
- A disabled item's trigger is `aria-disabled`, not natively `disabled`, and keeps its pointer
  events (FRM-4) — it stays reachable and hoverable so the reason can be explained in place.
- Focus is the global 2px `:focus-visible` outline from `base.css`; there is no ring glow on a
  trigger, and nothing suppresses the outline.
- The chevrons are decoration: they are swapped by an `aria-expanded` variant and never carry the
  state on their own.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/accordion.patch`. Every hunk:

- **FOC-1, FOC-6** — `outline-none focus-visible:border-ring focus-visible:ring-3
focus-visible:ring-ring/50 focus-visible:after:border-ring` goes from `AccordionTrigger`.
  `base.css` owns the one 2px `:focus-visible` outline and `outline-none` would suppress it.
- **FRM-4** — `aria-disabled:pointer-events-none` is dropped, so a disabled section header stays
  hoverable and a Tooltip can explain why it is unavailable. The opacity half stays.
- **DOC-2** — `import { cn } from "cn"` becomes `@vegastack/design`; our npm layer owns `cn`.
- **DOC-1** — prettier reflow plus the `registry-stamp.mjs` provenance header the three-copy model
  needs; no decision of its own.

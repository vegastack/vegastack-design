## Usage

```tsx
import { Timeline } from "@/components/ui/timeline";
import {
  HEALTH_LABEL,
  HealthIndicator,
} from "@/components/ui/health-indicator";

<Timeline
  today={workspaceToday}
  rows={initiatives.map((i) => ({
    id: i.id,
    label: i.title,
    sublabel: i.code,
    start: i.startDate,
    end: i.targetDate,
    status: i.status,
    leading: <HealthIndicator health={i.health} labelHidden />,
    leadingLabel: HEALTH_LABEL[i.health],
    markers: i.milestones,
  }))}
  onOpen={openPeek}
  loadMore={{ hasMore, loading, onLoadMore: fetchNextPage }}
/>;
```

Each row is a sticky label (an optional leading glyph, the name and a sublabel), then a bar from
`start` to `end` with its milestones as diamonds. The bar's colour says the status: active is the
solid ink, planned an outline, paused and completed step back, canceled fades. Health is never a
fill: put a `HealthIndicator` with `labelHidden` in `leading` and its words in `leadingLabel`.
Dates are ISO calendar dates (`2026-03-14`), read without a time zone. Pass `today` from the server
(the workspace's date) so the server and the browser draw today in the same place.

## Accessibility

- Each row is a button named with its whole story: "Self-serve onboarding, INI-1, Oct 1, 2026 to Jan
  31, 2027, Active, At risk. Milestones: Beta, Nov 2, 2026, done; …". Without `onOpen` it is a named
  group.
- The rows are one Tab stop. ←/→ still scroll the calendar sideways.
- The bars, gridlines and today line are decoration; the names carry every date.
- A milestone's hover chip can be hovered and hides on <kbd>Escape</kbd>; its words are in the
  row's name too.
- `labels` replaces every word it draws or speaks, including the date range and month headings.

| Key                                 | Action                     |
| ----------------------------------- | -------------------------- |
| <kbd>Tab</kbd>                      | Today, zoom, then the rows |
| <kbd>↑</kbd> / <kbd>↓</kbd>         | Previous or next row       |
| <kbd>Home</kbd> / <kbd>End</kbd>    | First or last row          |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open the row (`onOpen`)    |

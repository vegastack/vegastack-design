## Usage

```tsx
import { EmptyIllustration } from "@/components/ui/empty-illustration";

<Empty>
  <EmptyMedia>
    <EmptyIllustration name="tasks" />
  </EmptyMedia>
  <EmptyHeader>
    <EmptyTitle>No tasks yet</EmptyTitle>
  </EmptyHeader>
</Empty>;
```

Each drawing is a 120×90 line illustration in `currentColor`: the subject at full strength, the
ground at 40%. It takes `text-muted-foreground` by default, so it follows light and dark with no
second asset; recolour it with any text token.

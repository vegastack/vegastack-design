## Examples

### useDirection

`useDirection` returns the direction the nearest provider resolved, so a component can branch on it
without reading the DOM.

```tsx
import { useDirection } from "@/components/ui/direction";

function MyComponent() {
  const direction = useDirection();
  return <div>Current direction: {direction}</div>;
}
```

## Accessibility

- The provider renders no element and takes no focus; it only supplies context.
- Set `dir` on the document (or on the subtree) as well — `DirectionProvider` tells components which
  way to lay out, while `dir` is what the browser and assistive tech read for text rendering and
  caret movement.
- Every component in this system is written in logical properties (`ps-*`, `pe-*`, `start-*`,
  `end-*`), so a right-to-left subtree mirrors without any per-component work.

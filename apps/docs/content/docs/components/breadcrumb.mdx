## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb";

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink render={<a href="/" />}>Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink render={<a href="/components" />}>
        Components
      </BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

## Examples

### Composition

`Breadcrumb` is a `nav` labelled `breadcrumb`; `BreadcrumbList` is the `ol` inside it. Every segment
is a `BreadcrumbItem`, separators sit between items as their own `li`, and the last segment is a
`BreadcrumbPage` rather than a link.

```text
Breadcrumb
└── BreadcrumbList
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    ├── BreadcrumbSeparator
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    ├── BreadcrumbSeparator
    └── BreadcrumbItem
        └── BreadcrumbPage
```

Pass children to `BreadcrumbSeparator` to replace the default chevron. The separator is

### Dropdown

Compose `BreadcrumbItem` with a `DropdownMenu` when a segment has siblings the reader can switch to.

### Collapsed

`BreadcrumbEllipsis` stands in for the segments a long trail hides. It is `role="presentation"` and
`aria-hidden` — decoration, not a control — so when the hidden segments must stay reachable, wrap it
in a real trigger, as the example at the top of this page does with a `Button size="icon-sm"` and a
`DropdownMenu`.

### Link component

`render` on `BreadcrumbLink` replaces the element it renders, which is how a routing library's link
gets the breadcrumb's styling and its `data-slot`. In a Next.js app that is
`render={<Link href="/docs" />}`; this page has no router, so the render target below is a plain
anchor.

### RTL

Wrap the subtree in `DirectionProvider direction="rtl"` so Base UI resolves logical sides, and set
`dir` on the elements that portal out of it. The default separator carries `rtl:rotate-180`, so the
chevron points the way the text reads; a dropdown inside the trail aligns to `end` instead of
`start`.

## Accessibility

- `Breadcrumb` is a `nav` with `aria-label="breadcrumb"` wrapping an ordered list, which is the APG
  breadcrumb pattern: assistive technology reads the trail as a landmark and the segments in order.
- `BreadcrumbPage` is the current page. It carries `aria-current="page"` and `aria-disabled`, so it
  is announced as the destination the reader is already on rather than as a link they can follow.
- `BreadcrumbSeparator` and `BreadcrumbEllipsis` are both `role="presentation"` and `aria-hidden` —
  neither is a control and neither adds words to the trail. A collapsed trail that must stay
  navigable puts the ellipsis inside a real trigger with its own accessible name.
- Focus is the global 2px `:focus-visible` outline from `base.css`; nothing in the trail paints a
  ring glow.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/breadcrumb.patch`. Every hunk:

- **A11Y-2 — audited, no hunk.** Nothing in upstream's breadcrumb paints a focus glow, sets a cursor
  or disables pointer events: the link is plain text chrome and the ellipsis is
  `role="presentation" aria-hidden`, so A11Y-2 has no control to grow — upstream's own Collapsed
  example wraps the ellipsis in a `Button size="icon-sm"`, which is already 32px.
  `breadcrumb.test.tsx` asserts that shape so a future upstream that makes the ellipsis itself the
  control fails here.
- **DOC-2** — `import { cn } from "cn"` becomes `@vegastack/design`; our npm layer owns `cn`.
- **DOC-1** — prettier reflow plus the `registry-stamp.mjs` provenance header the three-copy model
  needs; no decision of its own.

## Examples

### Composition

Use modes={["icon"]} or modes={["emoji"]} for one mode without tabs. Both modes use line tabs. Standard grids have eight columns; compact grids have seven. Recents occupy at most two rows. Use closeOnSelect={false} when editing an identity, and pass onRemove only where removal is supported. Explicit hue, including null, wins over the remembered preference. Give preferenceKey an account/workspace-scoped namespace. Opening never commits a preference. The catalogue has 160 distinct outline icons; labels, pinned upstream tags and reviewed aliases power local ranked search.

## Accessibility

<StatesTested name="icon-picker" />

Search is labelled, cells use roving keyboard navigation across visual rows, and result counts use the shared announcer. Escape closes the nested colour panel before the parent. Keyboard focus uses the global DS tint; selection uses a persistent cell border.

## Usage

```tsx
import { MemoryGroup } from "@/components/ui/memory-group";

<MemoryGroup data={turn.memory} onUndo={forget} onEdit={openNote} />;
```

One group per turn: "Remembered 3 things · Personal memory ⌄", then each note with Undo · Edit
where the person can still do them. The mark is muted and the group has no card, because a saved
note is something that happened, not something to act on.

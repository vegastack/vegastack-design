## Usage

```tsx
import { ChatTaskList } from "@/components/ui/chat-task-list";

<ChatTaskList data={part.data} onOpenItem={openSubagents} onWhy={explain} />;
```

When a turn has a task list it **is** the turn's progress, so the steps line folds under it. A
hairline box with no fill; the header is a count and a time, never a spinner ("1 of 5 · 1:20",
"Done · 1 step · 3 skipped", "Stopped at 3 of 5 · Google refused the update"). A task is ✓ only when its calls
succeeded (the server checks); a refused or failed one is ⊘ with its reason inside the row, never
struck through. It stays mounted when the turn ends and folds on the chat motion. The data is the
chat contract's `data-tasklist` payload. The older `TaskList` stays until the app moves over.

## Accessibility

- The header is a button with `aria-expanded`; it reads "Task list, 1 of 5".
- Each glyph carries its state as its name ("Done", "In progress", "Skipped").

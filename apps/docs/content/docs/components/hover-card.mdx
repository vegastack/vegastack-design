## Usage

```tsx
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,

    The React Framework – created and maintained by @vercel.
  </HoverCardContent>
</HoverCard>;
```

### Trigger Delays

`delay` and `closeDelay` on `HoverCardTrigger` set how long the pointer must rest before the card
opens, and how long it lingers after the pointer leaves. Base UI's defaults are 600ms and 300ms; the
close delay is what lets the pointer travel from the trigger into the card without dismissing it.

  name="hoverCardTriggerDelays"

### Positioning

`side` and `align` on `HoverCardContent` choose the edge the card opens from and where along that
edge it sits; `sideOffset` and `alignOffset` move it from there. Collision avoidance flips the card
when the requested side has no room, and the resolved placement is readable as `data-side` and
`data-align`.

### RTL

Wrap the subtree in `DirectionProvider direction="rtl"` so Base UI resolves the logical sides.
`side="inline-start"` and `side="inline-end"` swap with the reading direction; `left`, `right`, `top`
and `bottom` stay where they are named. Pass `dir` to `HoverCardContent` as well — the card portals
out of the `dir` subtree and would otherwise render its text left-to-right.

## API Reference

<ApiTable path="lib/api-props.ts" name="HoverCardContentProps" />

`HoverCard` and `HoverCardTrigger` add no props of their own — each accepts everything the Base UI
part accepts, including the trigger's `delay` and `closeDelay`.

## Accessibility

- Renders Base UI's Preview Card. The trigger is a link, the card opens on hover and on keyboard
  focus, and <kbd>Esc</kbd> closes it.
- A hover card is an enhancement for sighted pointer users, not a delivery mechanism. Never put
  content in one that exists nowhere else, and never put a control in one that has no equivalent
  outside it.
- The card portals out of the trigger's subtree, so `HoverCardContent` re-applies the theme scope on
  the positioner inside the portal (OVL-13) — a dark or scoped surface survives the portal.
- Focus is the global 2px `:focus-visible` outline from `base.css`; there is no ring glow on the
  trigger or on the card.
- Keep `closeDelay` non-zero so a pointer can cross the gap between the trigger and the card.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/hover-card.patch`. Every hunk:

- **OVL-13** — `HoverCardContent` reads `useInternalThemeScope()` and attaches it to the Positioner
  INSIDE the portal. `tooling/verify-portal-theme-scope.mjs` inventories this host.
- **DOC-2** — `import { cn } from "cn"` becomes `@vegastack/design`; our npm layer owns `cn`.
- **DOC-1** — prettier reflow plus the `registry-stamp.mjs` provenance header the three-copy model
  needs; no decision of its own.

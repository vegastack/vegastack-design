## Usage

```tsx
import { NotificationBell } from "@/components/ui/notification-bell";

<NotificationBell count={unread} onClick={openPanel} />;
```

`NotificationBell` is **presentational** — it never fetches. Your application owns the unread `count`
(from its own query, websocket, etc.) and the `onClick` that opens the notifications surface. The
component just renders a bell [`Button`](/docs/components/button) at an icon size with the count
badge overlaid at the top inline-end edge.

## Examples

### Counts and indicators

The badge appears only when `count > 0`, shows the number (capped to `99+`), or a minimal dot when
`dot` is set. The count is a solid destructive pill and the dot a solid info-blue circle, both anchored inside the button's top inline-end corner with a background ring, so they stay in bounds when pressed. `count={0}` renders the bare bell with no badge.

### Shared unread dot

`NotificationDot` is the one unread dot: the 8px solid circle the bell draws in `dot` mode, exported
for unread rows in a list, an inbox or a nav item. Its default `intent` is the solid info blue, for
"unread"; `intent="destructive"` is for something that needs attention. The dot is `aria-hidden`, so
the row it marks must say "unread" in its own accessible name.

### Sizes & variants

`NotificationBell` extends [`Button`](/docs/components/button), so every Button prop — `size`
(`icon-xs` / `icon-sm` / `icon` / `icon-lg`), `variant`, `disabled`, `loading`, `render`, `onClick` —
forwards straight through to the underlying button. Two are managed for you: `children` (the bell
icon) and `aria-label` (the count-folded accessible name). `className` is the one exception to
"straight through" — it lands on the wrapper `<span>` that positions the badge, not on the button,
so reach for it to place the bell and for `render` to restyle it.

## Accessibility

- The unread count is folded into the accessible name automatically — screen readers hear
  "Notifications, 3 unread". Pass the base name via `aria-label` (defaults to `"Notifications"`); do
  **not** append the count yourself.
- The visual count badge is `aria-hidden` and `pointer-events-none`, so it never double-announces or
  intercepts the click.
- `NotificationDot` is decorative everywhere it is used. A row or control that shows it carries
  "unread" in its own accessible name, the way the bell folds its count in.
- Renders a native `<button type="button">` (upstream's `Button`, `size="icon"`); keyboard
  <kbd>Enter</kbd> / <kbd>Space</kbd> activate it, and `:focus-visible` shows
  the neutral 2px outline ring (`outline-ring`, the global focus style) — the
  bell adds no focus ring of its own.

| Key              | Action                        |
| ---------------- | ----------------------------- |
| <kbd>Enter</kbd> | Activate the bell             |
| <kbd>Space</kbd> | Activate the bell             |
| <kbd>Tab</kbd>   | Move focus to / from the bell |

## Do / Don't

<DoDont
  do="Pass the unread count from your app's own data and let the component announce it."
  dont="Fetch inside the bell or hand-write the count into aria-label — it's appended for you."

<DoDont

## Usage

```tsx
import { QuestionCard } from "@/components/ui/chat-question-card";

<QuestionCard
  data={questions}
  onSubmit={(answers) => answer(questions.interactionId, answers)}
  onSkip={() => skip(questions.interactionId)}
/>;
```

The whole question shows at once: "‹ 1 of 4 ›" and a close that skips, the question as the title,
then full-width options with a muted description and no radio circles. The picked option takes the
selected fill and a primary ✓. "Other" opens a text field. "Next →" becomes "Submit" on the last
question. Answers are option ids (ids joined by ", " for a question that takes several) or the
person's own words; answered or skipped, the card becomes a `QuestionLine`.

## Accessibility

| Key           | Does                                                   |
| ------------- | ------------------------------------------------------ |
| `1`–`9`       | Picks that option (Other is the number after the last) |
| `Enter`       | Next question, or Submit on the last                   |
| `Shift+Enter` | A new line in the Other field                          |
| `Tab`         | Moves through the pager, close, options and Next       |

- Options are `role="radio"` in a `radiogroup` named by the question (`checkbox` when several can
  be picked); the ✓ is decorative.
- Next stays disabled until the question has an answer.

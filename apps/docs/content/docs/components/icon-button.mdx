## Installation

```npm
npx shadcn@latest add @vegastack/icon-button
```

## Usage

```tsx
import { IconButton } from "@/components/ui/icon-button";
import { Plus } from "lucide-react";

<IconButton aria-label="Add item">
  <Plus />
</IconButton>;
```

`IconButton` is a thin wrapper over [`Button`](/docs/components/button): it forces a square `icon-*`
size and **requires** `aria-label`, since the icon carries no visible text.

the tab order; `loading` shows a spinner, sets `aria-busy`, and stays focusable.

## Accessibility

- An accessible name is **mandatory** — pass `aria-label`. The build fails to type-check without one,
  so an unlabeled icon button can never ship.
- Renders a native `<button type="button">`; keyboard <kbd>Enter</kbd> / <kbd>Space</kbd> activate it.
- `:focus-visible` shows a 2px ring (`outline-ring`) — never `outline: none`.
- `loading` sets `aria-busy="true"` and disables interaction; `disabled` removes it from the tab order.

| Key              | Action                          |
| ---------------- | ------------------------------- |
| <kbd>Enter</kbd> | Activate the button             |
| <kbd>Space</kbd> | Activate the button             |
| <kbd>Tab</kbd>   | Move focus to / from the button |

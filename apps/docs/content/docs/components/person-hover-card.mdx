## Usage

```tsx
import { AvatarStack } from "@/components/ui/person-hover-card";

<AvatarStack people={participants} label="Participants" />;
```

`AvatarStack` stacks up to `max` (5) avatars in an [Avatar](/docs/components/avatar) group; the
rest go behind a "+N" that opens them as rows. Hovering or focusing an avatar — tapping it on touch
— opens its `PersonHoverCard`: a compact card with a 32px avatar and, stacked beside it, the name and a smaller muted email (always shown when known). Someone without
an account (a free-text participant such as "Northwind FM leads") has no email: their avatar shows
initials and the card just the name.

## Accessibility

- The stack is a `group` named by `label`; each avatar is a button named by the person, and "+N"
  is named "N more".
- The hover card opens on hover and on keyboard focus, and a tap toggles it on touch; it closes on
  <kbd>Esc</kbd> and when focus leaves.

| Key                                 | Action                            |
| ----------------------------------- | --------------------------------- |
| <kbd>Tab</kbd>                      | Move between people and "+N"      |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open a person's card, or the rest |
| <kbd>Esc</kbd>                      | Close the card or the list        |

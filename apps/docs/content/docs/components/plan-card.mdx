## Usage

```tsx
import { PlanCard } from "@/components/ui/plan-card";

<PlanCard
  plan={plan}
  state={state}
  answeredBy={answeredBy}
  busy={pending}
  onAccept={() => answer({ kind: "accept" })}
  onAcceptAndAllow={() => answer({ kind: "accept", allow: true })}
  onRequestChanges={(request) => answer({ kind: "changes", ...request })}
  onReject={() => answer({ kind: "reject" })}
/>;
```

The plan is data (`PlanSpec`), the same words the web, Slack and the phone draw. The host computes
the risk and what the agent will still ask about, and owns the answer: it passes `busy` while the
answer travels and the new `state` once it lands. Accept and allow these in this chat is offered only
when `onAcceptAndAllow` is passed. For a single action an agent asks to take, use
[`RequestCard`](/docs/components/request-card); for the live checklist once work starts, a task list.

The agent's face is `plan.agent`: `avatar` is an image URL, and an agent without one passes its own
glyph and colour as `mark` and `hue` (the same fields as a `Person`; `mark` wins over `avatar`).

### States

`busy` spins the pressed answer and turns the others off. Someone who can't answer sees the plan
and who it waits for. Once answered, the card closes to one line in the same words on every
channel, with the plan one click away under Show plan. `error` sits under the card.

## Accessibility

- The card is a region named by the plan's title, and every answer is described by it, so two plans
  in one chat never share a name.
- Steps are an ordered list. Each step's number, its change ("New: ", "Changed: ") and its effect are
  read in words; the dots and icons are decorative.
- Each step's comment button is named "Comment on step 3"; it opens the change note with that step's
  own note focused. Cancel returns focus to Request changes.
- The settled line is announced through one polite live region when it changes on screen, never on
  first paint.

| Key              | Action                                           |
| ---------------- | ------------------------------------------------ |
| <kbd>Tab</kbd>   | Move through the steps' comments and the answers |
| <kbd>Enter</kbd> | Run the focused answer, or open a fold           |

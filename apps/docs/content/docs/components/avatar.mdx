### Sizes

Use the `size` prop to change the avatar diameter: `sm` is 24px, `default` is 32px and `lg` is
40px. Fallback initials use `text-xs` at every size so they remain visually secondary to the person
or entity the avatar represents.

<ComponentPreview name="avatarSizes" file="components/preview/avatar.tsx" />

### Dropdown

An avatar is a common dropdown trigger. Render the trigger as a `Button` and put the `Avatar`
inside it, so the control — not the image — owns the focus and the accessible name.

mirrors the group's overlap without any extra work.

## Accessibility

- `AvatarImage` renders a native `<img>`. Give it an `alt` naming the person; use `alt=""` when the
  avatar sits beside their name and would only repeat it.
- `AvatarFallback` paints when the image has not loaded or has failed. Initials are text, so they
  are read out; an icon fallback is decorative and needs a name on whatever wraps it.
- `AvatarBadge` is a decorative dot. A status it encodes — online, verified — must also exist as
  text somewhere a screen reader can reach.
- An avatar is not a control. When it acts as one, wrap it in a `Button` and name the button.

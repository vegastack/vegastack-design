## Usage

```tsx
import {
  RunUsageChip,
  RunUsagePanel,
  RunUsageTable,
} from "@/components/ui/run-usage";

<RunUsageChip
  summary={{
    steps: 3,
    contextTokens: 62000,
    contextWindow: 100000,
    cachedRatio: 0.92,
  }}
/>;
<RunUsagePanel
  summary={summary}
  models={models}
  calls={calls}
  asOf="Data as of 14:02"
/>;
<RunUsageTable calls={calls} />;
```

Every number is the host's. Money is optional in every part: leave `cost` out and no money shows,
so a reader who may see tokens but not dollars gets the same parts. A number with
`basis: "estimated"` reads "~". For the context gauge in the composer, use
the composer's context ring.

## Accessibility

- The panel is a region named by its heading ("Run usage"); its totals are description lists, so
  each number is read with its label.
- The table has a caption, column headers and a row header on the total. When it is wider than its
  column it scrolls inside a region named by the caption, which takes focus only while it scrolls.
- An estimated number shows "~" and is read as "about".
- Loading sets `aria-busy` and carries a status, "Loading usage"; the placeholders are hidden.

| Key                                          | Action                                   |
| -------------------------------------------- | ---------------------------------------- |
| <kbd>Tab</kbd>                               | Move to the table's scroll region, Retry |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowRight</kbd> | Scroll the focused table sideways        |

## Usage

```tsx
import { NotificationDot } from "@/components/ui/notification-dot";

<ItemTitle>
  Design review <span className="sr-only">, unread</span>
  <NotificationDot />
</ItemTitle>;
```

`NotificationDot` marks something unread: a row in a list, an inbox item, a nav or rail item. Its
default `intent` is the solid info blue, for "unread"; `intent="destructive"` is for something that
needs attention. A count belongs in a [`Badge`](/docs/components/badge), not a dot.

## Accessibility

- The dot is `aria-hidden`: the row or control it marks says "unread" in its own accessible name.
- It is solid, never a tint, so it meets the 3:1 non-text contrast floor at 8px.

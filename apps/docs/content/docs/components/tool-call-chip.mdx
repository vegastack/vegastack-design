## Usage

```tsx
import { ToolCallChip } from "@/components/ui/tool-call-chip";

<ToolCallChip label="SQL query executed" meta="3 rows in 495ms">
  <Database aria-hidden />
</ToolCallChip>;
```

### It is a Badge

The chip IS [`Badge`](/docs/components/badge) in its `outline` variant — the height, the radius, the
border and the icon rule all come from there, so a tool call and any other chip in the same
transcript are one object rather than two chip recipes. What this component adds is the label/meta
split, a truncation posture a badge does not need (a tool label runs long), and the hover and
pressed steps the interactive form needs, since upstream's outline badge paints a hover for anchors
only.

### Chat family

Sits alongside `Marker` (status lines), `Attachment` (files/artifacts), and `CodeBlock`
(results) — the four pieces that turn a `Message` stream into an agent transcript, laid out by
[`Message`](/docs/components/message).

### States

Compose the leading slot per state: a `Spinner` while the tool runs (label only, no meta yet),
the tool's icon once finished (label + result meta). The chip itself never animates — arrival
into a transcript can opt into `motion-enter-up` at the call site.

### Interactive chips

Pass `render={<button />}` when activating the chip reveals the call's detail (arguments,
raw result). The accessible name is built from the visible text, so it needs no `aria-label`: the
label and the meta are flex children, so the browser separates their contributions itself and the
button is named `Search files 1.2s`.

## Accessibility

- The visible label names the tool action; `meta` supplements it with a result summary.
- Leading glyphs stay decorative because the text carries state and meaning.
- When composed as a button the accessible name comes from the visible text — label then meta,
  separated by the browser's own accname handling of flex children rather than by an `aria-label`.
  The visible label therefore stays a verbatim substring of the name, so speech input still works
  (WCAG 2.2 SC 2.5.3).

| Key                                 | Action                                                 |
| ----------------------------------- | ------------------------------------------------------ |
| <kbd>Tab</kbd>                      | Move to an interactive chip; static chips are skipped. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate a chip composed as a button.                  |

## Usage

```tsx
import { FilePreview } from "@/components/ui/file-preview";

<FilePreview
  url="/api/files/f1/content"
  mediaType="text/markdown"
  filename="open-tasks.md"
  size={1180}
  onOpen={() => openViewer(file)}
/>;
```

A file the agent made shows where it was made, on the chat's card surface: its type's icon, its
name and its size (or a PDF's pages), with Download and Open. Markdown is rendered with its
formatting and fades out after a dozen lines; a CSV shows its first five rows; a PDF its first
page; an image itself. A click on the preview, the name or Open opens the viewer — pair it with
[`FileViewer`](/docs/components/file-viewer) in `mode="side"`. Pass the file's own URL on the
app's origin: the preview reads only the first 32 KB of a text file, with one `Range` request.

## Accessibility

- The file's name is a button that opens it; Download is a link and Open a button, each named
  with the file.
- The preview is a picture of the file: it is inert, so its links and cells are not tab stops,
  and a click on it opens the viewer.
- A PDF's thumbnail is an image named "<file>, page 1".

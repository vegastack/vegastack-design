## Usage

```tsx
import { StatusGlyph } from "@/components/ui/status-glyph";

<p className="flex items-center gap-2 text-sm">
  <StatusGlyph status="done" /> Found 12 makers
</p>;
```

Agent UI speaks one quiet status language (COL-25). Every check — done, selected, approved,
allowed, remembered, uploaded — is `primary`, never green (near-black in light, near-white in dark). Not started, skipped and failed are
muted, and failed always comes with words that say why. Only ⚠ takes a status ink, as a glyph.
Nothing here is ever a coloured fill. For a record's workflow status use
[`StatusIcon`](/docs/components/status-icon); for the live loop use
[`TextSpinner`](/docs/components/text-spinner).

## Accessibility

- The glyph is an image named with its state ("Done", "Needs you"), so colour is never the only
  cue. Pass `label={null}` when the words beside it already say the state.
- Running is drawn still: a turn's one moving thing is its live line.

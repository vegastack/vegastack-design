## Usage

```tsx
import { TextSpinner } from "@/components/ui/text-spinner";

<p className="flex items-center gap-2 text-sm text-muted-foreground">
  <TextSpinner label="" /> Searching the web · 12s
</p>;
```

A chat turn has one moving thing: its live line, led by this spinner. It is one frame wide and
monospace, so the words and the timer beside it never move. It is CSS only (the frames step on the
`motion-frames` utility), so it renders on the server and never re-renders. A running task or
Subagent row is a still ◐ ([`StatusGlyph`](/docs/components/status-glyph)), and page or section
loading stays [`Spinner`](/docs/components/spinner).

## Accessibility

- The glyph is hidden from assistive technology. The label (`Working` by default) is visually hidden
  text; pass `label=""` when the words beside the spinner already say what is happening.
- Under reduced motion the frames are replaced by a still `…` and the loader tokens read 0ms.

## Usage

```tsx
import { TextSpinner } from "@/components/ui/text-spinner";

<p className="flex items-center gap-2 text-sm text-muted-foreground">
  <TextSpinner label="" /> Searching the web · 12s
</p>;
```

A chat turn has one moving thing: its live line, led by this spinner. It is the bolt of the
VegaStack V drawn in 13 dots, as tall as capital letters and set in a fixed slot sized in `em`, so
it scales with the text beside it and the words and the timer never move. It is CSS only (the
`motion-strike` and `motion-pulse` utilities), so it renders on the server and never re-renders. A
running task or Subagent row is a still ◐ ([`StatusGlyph`](/docs/components/status-glyph)), and
page or section loading stays [`Spinner`](/docs/components/spinner).

## Examples

### Variants

`working` is Strike: the bolt fills top to bottom, holds and clears, 80ms a frame. It is real
work: the live line while a step runs, Send while it sends. `waiting` is Pulse: the whole bolt
fades through six slower frames (300ms each). It comes before the first step and while the turn is
paused or the connection comes back: "Thinking", "Reconnecting", a composer notice.

## Accessibility

- The bolt is hidden from assistive technology. The label (`Working` by default) is visually hidden
  text; pass `label=""` when the words beside the spinner already say what is happening.
- Under reduced motion the bolt stands still at full ink: both animations end on the full bolt and
  the loader tokens read 0ms.

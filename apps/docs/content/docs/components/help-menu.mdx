## Usage

```tsx
"use client";

import Link from "next/link";
import { CircleHelp } from "lucide-react";
import { Button } from "@/components/ui/button";
import { GlobalBarTrailing } from "@/components/ui/global-bar";
import { HelpMenu } from "@/components/ui/help-menu";
import { NotificationDot } from "@/components/ui/notification-dot";

export function BarEnd({ unread, openShortcuts }: Props) {
  return (
    <GlobalBarTrailing>
      <HelpMenu
        trigger={
          <Button
            variant="ghost"
            size="icon-sm"
            aria-label={unread ? "Help (new updates)" : "Help"}
            className="relative"
          >
            <CircleHelp />
            {unread ? (
              <NotificationDot className="absolute top-0.5 end-0.5" />
            ) : null}
          </Button>
        }
        whatsNewUnread={unread}
        version="v1.8.21"
        linkRender={<Link href="" />}
        links={{
          whatsNew: { href: "/docs/whats-new" },
          docs: { href: "/docs" },
          shortcuts: { onSelect: openShortcuts },
          support: { href: "mailto:support@example.com", external: true },
        }}
      />
    </GlobalBarTrailing>
  );
}
```

Learning the product is one job — what changed, how something works, which keys do what, who to
ask — so it gets one button, at the end of the global bar. A dot on "Docs" does not say
"something changed"; here What's new carries the dot, and so does the Help button itself until it is
read.

## Scope

- Owns: the four entries in a fixed order, their icons and default labels, the What's new dot,
  the shortcut hint and the version line.
- Does not own: the trigger — the global bar's Help button you pass, with its icon, name and dot — routing
  (link entries render through `linkRender`), the unread state, which the host computes, or the
  shortcuts overlay, which an action entry opens (`ShortcutOverlay`).
- Compose with: [`GlobalBar`](/docs/components/global-bar)'s `GlobalBarTrailing`; extra `DropdownMenuItem`s go
  in as children, after Contact support.

## Examples

Every entry is optional and is either a link (`href`, rendered through `linkRender`, `external`
for a new tab) or an action (`onSelect`). Omit an entry and it is not shown. `whatsNewUnread`
puts the dot on What's new and adds "(new updates)" to its name; give the trigger the same `dot`.

## Accessibility

- The trigger is a menu button named by its label; while there is something new its name is
  "Help (new updates)", and What's new says the same — the dot itself is decorative.
- The version line is a menu label, not an item, so the arrow keys skip it.

| Key                                 | Action                         |
| ----------------------------------- | ------------------------------ |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Opens the menu                 |
| <kbd>↑</kbd> / <kbd>↓</kbd>         | Moves between the entries      |
| <kbd>Escape</kbd>                   | Closes the menu, focus returns |

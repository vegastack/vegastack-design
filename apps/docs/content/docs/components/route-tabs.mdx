## Usage

```tsx
"use client"; // app/connections/connections-tabs.tsx — it reads the path

import Link from "next/link";
import { usePathname } from "next/navigation";
import {
  RouteTabs,
  RouteTabsPanel,
  RouteTabsProvider,
} from "@/components/ui/route-tabs";

export function ConnectionsFrame({ children }: { children: React.ReactNode }) {
  const pathname = usePathname();
  return (
    <RouteTabsProvider>
      <RouteTabs
        label="Connections"
        currentHref={pathname}
        linkRender={<Link href="" scroll={false} />}
        tabs={[
          { href: "/connections", label: "Your connections" },
          { href: "/connections/everyone", label: "Everyone", count: 12 },
          { href: "/connections/activity", label: "Activity" },
        ]}
      />
      <RouteTabsPanel>{children}</RouteTabsPanel>
    </RouteTabsProvider>
  );
}
```

When each tab is its own URL, the tabs are navigation, not a `Tabs` widget: a `nav` of links that
look like the pill tabs. Put them in the section's layout so a switch swaps only the page below.
A clicked tab is current at once and carries a thin pending bar until the router's path moves, and
the page below dims meanwhile — so a slow page never leaves the previous tab looking chosen with
its old content (or its empty state) on screen.

## Scope

- Owns: the strip's look (Tabs' own recipes), the current-tab match (`href` or an `also` path),
  the optimistic current tab and its pending bar, counts, the sideways scroll that keeps the
  current tab in view, and the dimmed panel.
- Does not own: routing — links render through `linkRender`, the host passes `currentHref` (and,
  if it knows better, `pendingHref`).
- Compose with: `PageHeader`'s tabs slot, or a section layout; `RouteTabsProvider` joins the tabs
  and the panel when they sit apart.

### Page tabs

the new page arrives (the demo waits 1.2s). A count follows the label in the muted ink; an `also`
path — a record's own page under the tab — keeps the tab current.

## Accessibility

- The strip is a `nav` landmark named by `label`; the current tab's link carries
  `aria-current="page"`, and a tab's own `aria-label` replaces its visible name when that is not
  enough ("Tasks, 3 open").
- While a page loads, the nav and the panel are `aria-busy`; the pending bar is decorative.
- Modified clicks (⌘, Ctrl, Shift, Alt) open the link as the browser would and start nothing.

| Key              | Action                       |
| ---------------- | ---------------------------- |
| <kbd>Tab</kbd>   | Moves between the tab links  |
| <kbd>Enter</kbd> | Opens the focused tab's page |

## Usage

```tsx
import { LevelMeter } from "@/components/ui/level-meter";

const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
<LevelMeter stream={stream} active={!paused} />;
```

The meter reads the stream through an `AnalyserNode`, maps `floor` dBFS…0 dBFS onto its segments,
rises at once and falls slowly so a short peak stays readable. It never stops the stream's tracks —
the recorder owns them. The top two segments are the warning zone and the last one is clipping.

## Accessibility

- The root is `role="meter"`, named "Input level" by default, with `aria-valuenow` as a whole
  percentage of lit segments — it changes only when a segment does, not every frame.
- The segments are `aria-hidden`; colour is never the only signal, the count of lit segments is.
- The meter keeps moving under reduced motion: it is information, and it has no transitions.

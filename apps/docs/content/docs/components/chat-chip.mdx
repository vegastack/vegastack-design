## Usage

```tsx
import { ChatChip } from "@/components/ui/chat-chip";

<ChatChip
  icon={<TextSpinner label="" />}
  label="3 Subagents running"
  onClick={openPanel}
/>;
```

Live or partly failed background work is a chip; settled work becomes a muted line. With `onClick`
or `href` it gains a trailing chevron. `tone="attention"` lifts the label to the body ink for work
that needs a look; it never adds a red, amber or green fill (COL-25). For tags and filters use
[`Chip`](/docs/components/chip).

## Accessibility

- A chip with `onClick` is a button and one with `href` a link, named by its label and meta.
- A live chip's spinner is decorative; the label says what is running.

## Usage

```tsx
import {
  AgentQuestionAnswers,
  AgentQuestionForm,
} from "@/components/ui/agent-question-form";

<AgentQuestionForm
  questions={questions}
  onSubmit={async (answers) => {
    const sent = await answerAgent(answers);
    return sent ? null : "Couldn't send your answers. Try again.";
  }}
/>;
```

`onSubmit` gets one answer per question, in order: `{ selected, other?, notes? }`, where `selected`
holds the chosen options' labels. Resolve with an error to show it under the form, which stays
editable; resolve with `null` once sent, and the form stays disabled. Afterwards, show what was
answered with `AgentQuestionAnswers`.

## Scope

- The first option is the recommended one and carries the badge. Order the options so it is. When
  no option is better than another, `recommended={false}` drops the badge.
- Every option shows its description in full. Nothing hides behind a tooltip.
- The person can always answer in their own words (Other), and add a note to any question.
- Every word is a prop in `labels`, with an English default.

## Accessibility

- The compact form is a group named by its question; each option is a button whose name includes
  its description.
- The full form is a `Questionnaire`: each question is a fieldset named by its text, its options
  are radios or checkboxes, and a multi-select question says "Choose any". The step chips are a
  navigation list, the current one marked `aria-current="step"`.
- Focus moves to the question when the step changes. A failed submit shows its message as an alert.
- The preview is a focusable box, so it can be scrolled from the keyboard.

| Key                         | Action                                    |
| --------------------------- | ----------------------------------------- |
| <kbd>1</kbd>–<kbd>5</kbd>   | Pick an option (the last number is Other) |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move between options                      |
| <kbd>Enter</kbd>            | Next, once the question is answered       |
| <kbd>←</kbd> / <kbd>→</kbd> | Previous or next question                 |

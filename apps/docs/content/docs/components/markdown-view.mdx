## Usage

```tsx
import { MarkdownView } from "@/components/ui/markdown-view";

<MarkdownView>{`# Hello\n\nThis is **markdown**.`}</MarkdownView>;
```

Pass the markdown as `children` (a string) or via the `content` prop when the
source comes from a data field:

```tsx
<MarkdownView content={task.description} />
```

`MarkdownView` tokenizes with [`marked`](https://marked.js.org)'s lexer
(CommonMark + GitHub-flavored markdown: tables, strikethrough, task lists,
autolinks — the same parser `TextEdit`'s Markdown format uses) and rebuilds the
tokens as React elements — never `dangerouslySetInnerHTML` — so any raw HTML in
the source renders as inert text. It is server-safe (no `'use client'`), light
enough for a page's first bundle (one ~13 KB parser), and renders nothing for
empty/whitespace input.

Relative image paths render normally. Absolute and protocol-relative remote
images are blocked by default so untrusted Markdown cannot create tracking
requests. When a trusted media host is required, allow its exact origin; allowed
remote images send no referrer:

`["*"]` allows every HTTP(S) origin, for content whose author is trusted to embed images —
`TextEdit`'s read view passes it, matching the editor, which shows any image.

```tsx
<MarkdownView allowedImageOrigins={["https://media.example.com"]}>
  {"![Product preview](https://media.example.com/preview.png)"}
</MarkdownView>
```

### Default

Headings, paragraphs, inline code, links, lists, and blockquotes — styled by the
shared `prose` recipe from `@vegastack/design`, worn as one class on the root (no
`@tailwindcss/typography` dependency). [`TextEdit`](/docs/components/text-edit)
wears the same string, so rendered markdown and edited rich text are the same
typography rather than two that agree by review.

### Links

External links (those starting with `http(s)://`) open in a new tab with
`target="_blank"` and `rel="noreferrer noopener"`; relative/internal links stay
in the same tab. The link color (`text-info-text`) and underline are identical in
both cases.

### Full element set

A consolidated sample exercising every styled element — all six heading levels, ordered,

Markdown usually starts its outline at `#`. When it renders under the page's own headings — a
card titled with an `h2` — pass `headingOffset` to move every heading down that many levels, capped
at `h6`: `headingOffset` of `2` renders `#` as an `h3`, so the outline never skips back up. Each
heading takes the prose style of the level it lands on.

```tsx
<MarkdownView headingOffset={2}>{notes}</MarkdownView>
```

### HTML source

`format="html"` renders HTML instead of markdown — `TextEdit`'s `format="html"` output, which is
how `TextEdit` shows a saved document before it is first edited. The HTML is rebuilt through a tag
and attribute allowlist (the elements rich text uses: headings, paragraphs, marks, lists and task
lists, quotes, code, tables, links, images), never injected: scripts, styles, event handlers and
unsafe URLs are dropped, and the same link, image, code-block and task-list rules apply.

### Mentions, files, callouts and toggles

The constructs `TextEdit`'s Markdown carries beyond GFM render here too, still server-safe:

- **Mentions** — `[@Asha Rao](mention://user/u1)` renders as a `MentionChip` on the info tint: an icon
  for its kind (person, page, file, task) and the name; `mentionImage(id)` gives a person chip a
  16px avatar instead of the icon. `mentionHref(kind, id)` makes a chip a link (return
  `null` for none); a person is never a link, and an id starting with `restricted:` renders a
  muted chip that never links (the target is one the reader may not open).
- **File chips** — a link whose href starts with `fileLinkPrefix` (default `/api/files/`) renders
  as a chip with an icon for the file's type; `""` turns file chips off.
- **Callouts** — GitHub's alert syntax, `> [!NOTE]`, `> [!TIP]` and `> [!WARNING]`, renders as a
  `role="note"` box in the tone's ink.
- **Toggles** — `<details><summary>Title</summary>`, a blank line, the body, a blank line and
  `</details>` render as a native disclosure, collapsed. Any other raw HTML still renders as text.
- **Heading ids** — `headingIds` gives every heading the id `TextEdit`'s `onOutlineChange`
  reports (its words, hyphenated; `-1`, `-2`… for a repeat), so an outline links into either.
  `headingIds(texts)` is exported for servers building the same ids.

<ComponentPreview
  name="markdownViewLibrary"
  file="components/preview/markdown-view.tsx"
/>

```tsx
<MarkdownView
  headingIds
  mentionHref={(kind, id) => (kind === "page" ? `/library/${id}` : null)}
```

`parseMentionLink(source)` reads a mention at the start of a string and `mentionMarkdown(kind, id,
label)` writes one exactly as `TextEdit` does (the label escapes `\`, `[` and `]`).

### Citations

A summary cites its sources with `[[n]]` markers (n = 1–999). With `citation`, each marker whose
`n` the function answers for renders as a small superscript `n`: a button named by `label` that
opens `content` (a quote, who said it, when) on hover, keyboard focus or a long press, and calls
`onSelect` on a click or tap — play the recording from there. Without `onSelect`, a tap opens
`content`. A marker the function returns `null` for, and every marker without the prop, stays
literal text, and so does one inside a code span, fenced code or link text. The marker is a
client component, so pass `citation` from one.

<ComponentPreview
  name="markdownViewCitations"
  file="components/preview/markdown-view.tsx"
/>

```tsx
<MarkdownView
  citation={(n) =>
    sources[n] && {
      label: `Source ${n}`,
      content: sources[n].quote,
      onSelect: () => player.seek(sources[n].start),
    }
  }
>
  {summary}
</MarkdownView>
```

## Accessibility

- Markdown maps to **semantic HTML** — `# ` → `<h1>`, `- ` → `<ul><li>`, `> ` →
  `<blockquote>`, ` ``` ` → `<pre><code>` — so the document structure is exposed
  to assistive technology and heading navigation works.
- **XSS-safe by construction:** every element is rebuilt as a React element —
  never `dangerouslySetInnerHTML` — and raw HTML in markdown renders as text, so
  `<script>`, `<img onerror>`, and inline event handlers in untrusted input render
  as plain text rather than executing. `format="html"` keeps only allowlisted
  tags and attributes.
- A callout is a `role="note"` named by its tone ("Note", "Tip", "Warning"); its icon is
  decorative. A toggle is a native `<details>`/`<summary>`: <kbd>Enter</kbd> or <kbd>Space</kbd>
  on the summary opens and closes it.
- A mention chip that links is an ordinary link; one that does not (a person, a restricted
  target) is plain text with an icon.
- Links open in a new tab with `rel="noreferrer noopener"` (no reverse
  tabnabbing); unsafe URL protocols (e.g. `javascript:`) are dropped.
- Remote images are blocked unless their exact HTTP(S) origin appears in
  `allowedImageOrigins`; allowed remote images use `referrerPolicy="no-referrer"`.
- Body text inherits the page text color (`text-foreground`); links use
  `text-info-text` with an underline, keeping a visible, color-independent affordance.

| Key              | Action                                               |
| ---------------- | ---------------------------------------------------- |
| <kbd>Tab</kbd>   | Move focus through rendered links in document order. |
| <kbd>Enter</kbd> | Follow the focused link.                             |

A citation marker is a button named by its `label` ("Source 3"); keyboard focus opens its source
without moving focus, and <kbd>Enter</kbd> selects it.

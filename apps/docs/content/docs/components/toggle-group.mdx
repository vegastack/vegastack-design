## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group";

<ToggleGroup defaultValue={["a"]}>
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>;
```

## Anatomy

`ToggleGroup` is a compound component. Compose the items inside the root:

<Anatomy name="toggle-group" />

```text
ToggleGroup
├── ToggleGroupItem
└── ToggleGroupItem
```

- `ToggleGroup` — the `role="group"` container (`data-slot="toggle-group"`). Owns the selection
  (`value`, `defaultValue`, `onValueChange`, `multiple`), the shared `variant` and `size` it passes
  to every item through context, and the `spacing` and `orientation` that shape the row.
- `ToggleGroupItem` — one native toggle button (`data-slot="toggle-group-item"`), identified by its
  `value` and styled by `toggleVariants` from the `toggle` item. It reads `variant`, `size` and
  `spacing` from the group rather than taking them per item.

## Accessibility

- The root renders `role="group"`; each item is a native `<button>` carrying `aria-pressed`, so the
  selection is announced per item rather than as a list position.
- <kbd>Tab</kbd> moves into the group and <kbd>Enter</kbd> or <kbd>Space</kbd>
  flips the focused item. Base UI loops arrow-key focus inside the group.
- Icon-only items have no visible text — give each one an `aria-label`, as every example here does.
- The group itself has no implicit name. Point `aria-label` or `aria-labelledby` at the visible
  label when one exists, as the Custom example does.
- Items keep the `toggle` recipe's focus behaviour: the global 2px `:focus-visible` outline from
  `base.css`, raised over its neighbours by `focus:z-10` so a joined group never clips it.

| Key                                 | Action                                |
| ----------------------------------- | ------------------------------------- |
| <kbd>Tab</kbd>                      | Move focus into and out of the group. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Toggle the focused item.              |

## Do / Don't

<DoDont
  do="Use a single-select group for an immediate view or scope switch over the same content (Mine | Team, Grid | List), and keep one item pressed by ignoring an empty value in onValueChange. Set variant and size once on the group."
  dont="Use a toggle group for a form value (a Radio Group), for swapping page regions (Tabs), or for moving between URLs (links)."

## Deviations

- **DOC-2** — `cn` is imported from `@vegastack/design`. Nothing else differs: the recipe, the

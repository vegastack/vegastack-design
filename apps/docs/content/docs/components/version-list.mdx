## Usage

The selected version retains its selection tint after hover or keyboard focus moves.

```tsx
import { VersionList } from "@/components/ui/version-list";

<VersionList
  versions={versions}
  currentId={versions[0]?.id}
  selectedId={selected}
  onSelect={setSelected}
  namedOnly={namedOnly}
  onNamedOnlyChange={setNamedOnly}
  loadMore={{ hasMore, onLoadMore: fetchMore, loading: fetching }}
/>;
```

Each row shows when the version's text was saved and who wrote it; a named version leads with its
name. `kind` says how it came to be, as a badge (`VERSION_KIND_LABELS`):

| `kind`             | Badge                   | When                                                                    |
| ------------------ | ----------------------- | ----------------------------------------------------------------------- |
| `auto`             | —                       | A checkpoint while people edit: the row shows its time                  |
| `safety`           | Before a large deletion | The text just before a large deletion                                   |
| `restore`          | Before a restore        | The text just before a restore — what Undo returns to                   |
| `import`           | Before an import        | The text before an import or replace ("Before live editing" when named) |
| `agent_checkpoint` | Before an agent's edits | The text before an agent's first edit                                   |
| `named`            | —                       | A version someone named: the row leads with the name                    |
| `approved`         | Approved                | A signed-off copy                                                       |

A row with a `name` ("Before restoring 26 Sep", "Before live editing") shows no kind badge — the name
says it — except an approved copy. `label` replaces a row's badge ("Before Claude's edits"), and
`currentId` is "Current". Names are unique per document (case-insensitive), so two rows never read
the same; the host enforces it when a version is named.

An author's `badge` ("Inactive") follows their name. A version the system kept with no person
behind it (a page's text from before live editing) has `author: null`: the row names no one, never
a placeholder person. Pair it with a
[`TextEdit`](/docs/components/text-edit#version-diff) `diff` view — the formatted diff of the selected
version, "Compared with" its baseline — or [`DiffView`](/docs/components/diff-view) for plain text.

## Accessibility

- The rows are a `listbox` labelled "Version history", each an `option` with `aria-selected`; the
  list is one tab stop and the selection follows the arrow keys.
- "Named only" is a `switch` labelled by its text.

| Key                              | Action                             |
| -------------------------------- | ---------------------------------- |
| <kbd>↑</kbd> / <kbd>↓</kbd>      | Select the previous / next version |
| <kbd>Home</kbd> / <kbd>End</kbd> | Select the newest / oldest shown   |
| <kbd>Tab</kbd>                   | Leave the list                     |

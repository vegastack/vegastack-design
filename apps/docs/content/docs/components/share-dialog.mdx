## Usage

```tsx
import { ShareDialog } from "@/components/ui/share-dialog";

<ShareDialog
  trigger={<Button variant="outline">Share</Button>}
  levels={LEVELS}
  people={entries}
  search={searchDirectory}
  onInvite={invite}
  onLevelChange={setLevel}
  onRemove={removeAccess}
  generalAccess={general}
  onGeneralAccessChange={setGeneral}
  publicLink={publicLink}
  onCreatePublicLink={publish}
  onStopPublicLink={unpublish}
  linkUrl={itemUrl}
/>;
```

`ShareDialog` is data-agnostic: every row, level and link comes in through props and every change
goes out through a callback, so one dialog serves tasks, meetings and pages. It is a
[`ResponsiveDialog`](/docs/components/responsive-dialog) — a `md` (512px) Dialog from 768px up and a
bottom sheet below it — titled "Share", with two line tabs. **Share** holds the invite row
([`PeoplePicker`](/docs/components/people-picker) with one
[`PermissionMenu`](/docs/components/permission-menu) level for the batch), People with access and
Space access, with **Copy link** for the item's own link in the footer. **Publish** holds a
"Publish to the web" switch, off by default — the only control that calls `onCreatePublicLink`;
copying never publishes. Both panels share one grid cell, so switching tabs never resizes the
dialog. Every string is in `labels`.

The [`share-01`](/docs/blocks/share-01) block is this dialog wired to sample state, with a page to
try it on.

## Scope

| Need                                                 | Use                                                                                   |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Share one record, page or meeting                    | `ShareDialog`                                                                         |
| A page of a space's or team's members                | `DataList` with [`PeoplePicker`](/docs/components/people-picker) and `PermissionMenu` |
| Show who can open an item, without changing it       | [`AccessChip`](/docs/components/access-chip)                                          |
| Pick the access level for one person outside a share | [`PermissionMenu`](/docs/components/permission-menu)                                  |

## Examples

### Permissions

`canManage` gates inviting, changing levels and space access. `canPublish` gates the Publish tab's
controls — the switch, Reset, Expires and Stop publishing — and follows `canManage` when unset. A
viewer who cannot publish sees the public link to copy while it is on, and "Not published"
otherwise.

`hints` places a help node — usually an [`InfoHint`](/docs/components/info-hint) — right after the

## Accessibility

- The dialog is named by its "Share" title; the tabs are a `tablist` and only the active panel is
  in the tab order.
- Every level menu is named for its row ("Anand Iyer's access: Can view"); a built-in row is locked,
  still a tab stop, with its reason in a tooltip.
- Turning publishing off, by the switch or Stop publishing, asks for confirmation in an
  `AlertDialog` first.

| Key                                          | Action                                      |
| -------------------------------------------- | ------------------------------------------- |
| <kbd>Tab</kbd>                               | Moves through the active tab's controls     |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowRight</kbd> | Moves between the Share and Publish tabs    |
| <kbd>Enter</kbd>                             | Chooses a person in the invite search       |
| <kbd>Space</kbd>                             | Toggles Publish to the web or Notify people |
| <kbd>Escape</kbd>                            | Closes the open menu, then the dialog       |

## Usage

```tsx
import { Field, FieldLabel } from "@/components/ui/field";
import { PasswordInput } from "@/components/ui/password-input";

<Field>
  <FieldLabel htmlFor="password">Password</FieldLabel>
  <PasswordInput
    id="password"
    name="password"
    autoComplete="current-password"
  />
</Field>;
```

`PasswordInput` composes [`InputGroup`](/docs/components/input-group) with one icon button that
switches the field between `password` and `text`. `className` styles the group root; the `ref` and
every native input attribute — `id`, `name`, `autoComplete`, `aria-invalid` — target the inner
`HTMLInputElement`.

## Accessibility

- Name the field with a `FieldLabel`, `aria-label`, or `aria-labelledby`.
- The toggle is a `type="button"` icon button, so it never submits the form. It is named
  `Show password` or `Hide password` and reports its state with `aria-pressed`; override the
  names with `showLabel` and `hideLabel`.
- <kbd>Tab</kbd> moves from the input to the toggle; <kbd>Enter</kbd> or
  <kbd>Space</kbd>
  toggles it.

## Usage

```tsx
import { PasswordInput } from "@/components/ui/password-input";

<PasswordInput aria-label="Password" autoComplete="current-password" />;
```

`PasswordInput` wraps [`Input`](/docs/components/input) with a trailing eye
toggle that flips the field between `type="password"` and `type="text"`.
Visibility is local component state, so the field works uncontrolled out of the
box — every other native attribute (`value`/`defaultValue`, `onChange`, `name`,
`required`, `disabled`, `autoComplete`, …) passes straight through, and the ref
forwards to the underlying `<input>`.

### Revealing the value

The eye toggle flips the field between `type="password"` and `type="text"`,
swapping the lucide `Eye` icon for `EyeOff` and setting `aria-pressed="true"`
while revealed. Visibility is local component state, so the example below is
interactive — click the eye to reveal. Override the toggle's accessible label

### Requirements

Pass a `requirements` array of `{ label, met }` to render a live checklist below
the field — ideal for signup and password-reset flows. Each row shows a success
check when met and a muted cross when unmet, so the state never depends on color
alone. The input references the list with `aria-describedby`, each row includes
hidden `Met:` / `Not met:` state text, and a polite live summary announces how
many requirements are currently satisfied. Drive `met` from your own validation
and the list re-renders as the user types.

## Accessibility

- Renders a native `<input>` — always associate a visible `<label>` (wrap it or
  use `htmlFor`/`id`); use `aria-label` only when a visible label is impossible.
- The toggle is a real `<button type="button">` with an `aria-label` (override
  via `toggleAriaLabel`) and `aria-pressed` reflecting the reveal state.
- The toggle remains keyboard reachable; <kbd>Tab</kbd> moves from the field to
  the reveal button, and <kbd>Enter</kbd> / <kbd>Space</kbd> toggles visibility.
- On `:focus-visible` the field re-colors its border with the `ring` token
  (`focus:border-ring/(--alpha-tint-border)`, inherited from [`Input`](/docs/components/input)) and
  the reveal toggle brightens to `text-foreground` — a visible focus treatment
  on both, never `outline: none`.
- Requirement rows pair an icon with text, hidden met/unmet state text, and a
  live summary, so met/unmet is conveyed without relying on color alone.

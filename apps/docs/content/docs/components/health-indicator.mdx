## Usage

```tsx
import { HealthIndicator } from "@/components/ui/health-indicator";

<HealthIndicator health={initiative.health} />;
```

On track is a check in primary, never green; at risk takes the warning ink and off track the
destructive ink, each with its own symbol; no update is grey. The hue is a glyph, never a fill, and
the words are always there unless the row already carries them.

## Accessibility

- The words say the health, so colour is never the only cue, and each health has its own symbol.
- With `labelHidden` the glyph is an image named by the words.

## Usage

```tsx
import { ResourcePill } from "@/components/ui/resource-pill";

<ResourcePill
  data={{
    kind: "doc",
    url: "https://docs.google.com/document/d/1x",
    title: "Q3 pricing",
  }}
/>;
```

A Doc, Sheet or Slides deck, a Drive file, a Meet, a calendar event, a pull request or issue, a
Slack message or an email the agent touched reads as the thing itself: its type's icon and its
real title, opening it (another site in a new tab). It is an
[`InlineChip`](/docs/components/inline-chip), so it sits on the text's line at the text's size,
and hovering it says what it is. In an answer, pass `linkResource` to
[`MarkdownView`](/docs/components/markdown-view): a link to a known thing becomes its pill, with
its real title whatever the link's words were.

## Accessibility

- The pill is a link named `<title>, <what it is>`, with "(opens in new tab)" for another site.
- The type icon is decorative; the name says what it is.

## Accessibility

- Renders a native `<label>`. Pair it with a control through `htmlFor` and the control's `id`, or
  nest the control inside it; clicking the label then focuses or toggles the control.
- A disabled control dims its label two ways: `peer-disabled:` for a sibling control, and
  `group-data-[disabled=true]:` for a wrapper that marks the whole group disabled.
- `select-none` stops a double-click on the label from selecting its text instead of hitting the
  control.
- A label is not a substitute for an accessible name on an icon-only control — give that control its
  own `aria-label`.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/label.patch`. Every hunk:

- **API-16** — the `"use client"` directive is removed. `Label` renders a native element and touches
  no React hook, so it is server-safe; the directive belongs at the lowest interactive leaf, not on
  a presentational element.
- **DOC-2** — `cn` is imported from `@vegastack/design`, and the file carries the registry
  provenance header.

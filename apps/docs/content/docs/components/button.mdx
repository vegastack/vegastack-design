## Usage

```tsx
import { Button } from "@/components/ui/button";

<Button>Save changes</Button>;
```

To render a Button as a link, compose the anchor through `render` and pass `nativeButton={false}`
— Base UI expects a native `<button>` by default and warns when `render` swaps in anything else:

```tsx
import Link from "next/link";

<Button nativeButton={false} render={<Link href="/docs" />}>
  Explore the docs
</Button>;
```

### Marketing CTA

`cta` is the ONE sanctioned use of the `--brand` phosphor accent as a button (audit
17-brand-direction §Color & surface) — an accent-outline treatment, sharp corners
(`rounded-(--radius-sharp)`), and a mono-uppercase label (the brand voice layer). Reserve it for
marketing surfaces, typically inside a [`MarketingSurface`](/docs/components/marketing-surface).
Compose a trailing icon (e.g. `lucide-react`'s `ChevronRight`) as a **child** — the variant is
style-only and never bakes one in.

### Variant × size matrix

The same variant reads differently at each size — padding, height, and text-size shift together
(`xs` drops to `text-xs`, `lg` grows the hit target). The grid pairs `default` / `outline` /
`destructive` against `xs` / `default` / `lg` so the interplay is visible at a glance.

### Lit finish

The Wave-2 `finish="lit"` prop adds the `--shadow-lit` top-light + warm ambient pair to the
**primary** action only — the one sanctioned exception to flat-by-default. On every other
variant `finish` is a deliberate no-op, so a stray prop can never un-flatten a surface.

## Accessibility

- Renders a native `<button type="button">` by default; keyboard <kbd>Enter</kbd> / <kbd>Space</kbd> activate it.
- On `:focus-visible` every variant keeps the design system's global 2px focus ring (`outline-ring`) — `Button` sets no `outline: none` of its own, so the single global focus rule applies. The `outline` and `glass` variants additionally re-color their border with the `ring` token (`focus-visible:border-ring/(--alpha-tint-border)`).
- `loading` sets `aria-busy="true"`, prevents interaction, and remains focusable through Base UI `focusableWhenDisabled`.
- `render` is for action elements. Do not render links through `Button`; style anchors with `buttonVariants({ variant, size })` when navigation should look like a button.
- Icon-only buttons must use `size="icon-*"` with an `aria-label`.

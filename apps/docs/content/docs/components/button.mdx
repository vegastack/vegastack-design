## Examples

### Cursor

Tailwind v4 switched from `cursor: pointer` to `cursor: default` for buttons. VegaStack keeps the
hand cursor for every clickable control, globally, from `base.css` (INT-1) — shadcn's own
`--pointer` rule over a wider selector list — so no component sets a cursor of its own and a
disabled button keeps the same cursor it had.

### As Link

Use the `buttonVariants` helper to make a link look like a button. Do **not** render an anchor
through `Button`: Base UI's Button always applies `role="button"`, which overrides the link role.

### Loading

`loading` is ours (API-5). It shows a spinner over the label, sets `aria-busy`, and blocks
activation while keeping the label's box at `opacity: 0` — so the button's width does not move and
its accessible name survives (A11Y-12).

## Accessibility

- Renders a native `<button>` through Base UI's Button; <kbd>Enter</kbd> and <kbd>Space</kbd>
  activate it.
- On `:focus-visible` the global 2px outline in `base.css` applies (FOC-1). The component carries no
  focus ring, no `ring-3` glow and no `outline-none` of its own (FOC-6).
- `disabled` renders `aria-disabled` rather than the native attribute, so the control keeps its
  pointer events and a Tooltip can explain why it is unavailable (FRM-4). Base UI still suppresses
  activation.
- `loading` sets `aria-busy="true"` and keeps the label in the accessibility tree (A11Y-12).
- An icon-only button (`size="icon"` and the three other icon tiers) has no visible text — give it
  an `aria-label`.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/button.patch`. Every hunk:

- **FOC-1, FOC-6** — the `focus-visible:border-ring focus-visible:ring-3 focus-visible:ring-ring/50`
  glow and the `outline-none` that suppressed the global outline are removed.
- **FOC-5** — the invalid tint becomes `not-focus:aria-invalid:border-destructive`, so focus outranks
  it; the `aria-invalid` glow rings go with FOC-6.
- **FRM-4** — `disabled:pointer-events-none` is dropped and `focusableWhenDisabled` defaults to true,
  so a disabled button stays hoverable and focusable.
- **API-5, A11Y-12** — the `loading` prop, the out-of-flow spinner and the `opacity-0` label.
- **A11Y-13** — the `destructive` variant's tint takes `text-destructive-text`; upstream's
  `text-destructive` on its own `/10` measures 3.98:1 in light, under the AA floor A11Y-1 enforces.
- **DOC-2** — `cn` is imported from `@vegastack/design`.

### RTL

The placeholder is direction-agnostic; sizing comes from the utilities you pass, and the
surrounding flex or grid flips with the document.

<ComponentPreview name="skeletonRtl" file="components/preview/skeleton.tsx" />

### Lines of text

`SkeletonText` sketches a few lines while text loads: `text` — 16px bars of varied widths 12px
apart — or `rows` — full-width 20px bars 8px apart, for a list. It is hidden from assistive
technology; name the loading region around it.

```tsx
<div role="status" aria-label="Loading">
  <SkeletonText lines={3} />
</div>
```

## Accessibility

- A skeleton is decorative: it carries no role, no text and no accessible name, so screen readers
  skip it rather than announcing a wall of empty boxes.
- Announce the loading state once, on the region that owns it — `aria-busy="true"` on the container,
  or a live region for a longer wait — rather than on each placeholder.
- The pulse is `animate-pulse`, and the global reduced-motion reset in `base.css` stops it for
  anyone who asks for less motion. The placeholder stays visible.
- The fill is `bg-muted`, which is a surface rather than text, so it carries no contrast obligation
  of its own.

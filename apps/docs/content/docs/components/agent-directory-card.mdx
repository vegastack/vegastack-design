## Usage

```tsx
import { AgentDirectoryCard } from "@/components/ui/agent-directory-card";

<AgentDirectoryCard
  name="Expense checker"
  href="/agents/expense-checker"
  linkRender={<Link href="/agents/expense-checker" />}
  avatar={<PersonAvatar person={agent} size="lg" />}
  job="Checks expense claims against the travel policy and flags what needs a receipt."
  examples={["Check this week's claims", "Which claims lack a receipt?"]}
  onExample={startChat}
  place="Workspace · Finance team"
  verified={{ by: "Asha", at: "12 Nov", version: 4 }}
  chat={{ href: chatHref }}
  people={<MembersStack people={maintainers} label="Maintainers" />}
  actions={<AgentMenu />}
/>;
```

The card reads as one family with the app's other directories (Browse spaces, Settings › Teams):
the agent's avatar as the tile, its name as the card's one link, the place it lives as the muted
line, its job in up to two lines, then the people and the action. Chat is the card's main action,
a secondary button; the examples, the verified mark and the ⋯ sit above the link, so nothing
interactive nests inside it.

## Examples

### Status

`live` draws no badge. `draft` shows an outline "Draft"; `paused` shows "Paused" and mutes the
card. `AgentDirectoryCardSkeleton` holds a card's shape while the directory loads.

<ComponentPreview
  name="agentDirectoryCardStates"

/>

### Verified

`verified` adds a check after the name with its words in a tooltip: "Verified by Asha · v4 · 12
Nov". When the agent changed after it was verified (`changedSince`), the check turns muted and the
words end "changed since".

### Apps

Up to four app icons show, then "+n"; their names are read as one label ("Uses Gmail, Slack…").

### In a list

`layout="row"` is the list form: avatar, name with its tags, place and job on one muted line, the
apps and maintainers (hidden on a phone), Chat and the ⋯.

## Accessibility

- The name is the card's only link; the whole card is its hit area, and its focus tints the card.
- Chat is named "Chat with" and the agent's name; each example is its own button.
- The verified mark is a named image and a keyboard stop for its tooltip.
- The apps read as one label.

| Key              | Action                          |
| ---------------- | ------------------------------- |
| <kbd>Tab</kbd>   | Name, examples, Chat, then ⋯    |
| <kbd>Enter</kbd> | Open the agent, or start a chat |

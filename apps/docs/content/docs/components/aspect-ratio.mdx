## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio";

<AspectRatio ratio={16 / 9}>
  <img
    src="/photo.jpg"
    alt="Photo"
    className="absolute inset-0 size-full object-cover"
  />
</AspectRatio>;
```

## Accessibility

- `AspectRatio` renders a plain `<div>` and contributes nothing to the accessibility tree — it is
  geometry, not semantics.
- The accessible name belongs to the child. Give a meaningful image an `alt`, and a decorative one
  `alt=""` so a screen reader skips it.
- The element is `position: relative`, so a filling child is positioned with `absolute inset-0`
  rather than being stretched by the wrapper — nothing is clipped out of the reading order.

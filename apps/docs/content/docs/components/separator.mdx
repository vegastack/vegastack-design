## Accessibility

- Base UI's Separator renders `role="separator"` with `aria-orientation`, so assistive technology
  announces the division rather than inferring it from a border.
- It is never focusable and never a control: a separator that also does something is a button or a
  resize handle, not this component.
- A separator that merely decorates a layout should be hidden from assistive technology with
  `aria-hidden` on the element that owns the decoration, so the rule is not announced twice.
- Colour alone never carries the meaning of a division — the content on each side must stand on its
  own.

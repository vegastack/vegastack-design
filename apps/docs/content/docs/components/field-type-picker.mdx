## Usage

```tsx
import { FieldTypePicker } from "@/components/ui/field-type-picker";

<PopoverContent className="p-0">
  <FieldTypePicker types={fieldTypes} onSelect={(type) => addField(type)} />
</PopoverContent>;
```

## Scope

Choosing a field's type: "+ Add field" on a table, a form builder, the Type row of a field's
settings. The app passes its types with their icons and groups; the picker searches names,
descriptions and `keywords`.

## Examples

### Add a field

Ungrouped types come first, then the groups in `groupOrder`. The current type is checked; a type
with a `disabledReason` shows why and can't be chosen.

### A second step

A type with `next` opens a second step instead of being chosen — "Link to" asking which kind of
record. `renderStep(type, { back, setTitle })` draws it under a back header
(`data-slot="field-type-picker-step-header"`, the type's icon and label, retitled with `setTitle`);
the step reports its own final choice.

```tsx
<FieldTypePicker
  types={[
    ...types,
    { id: "link", label: "Link to", icon: <Link2 />, next: true },
  ]}
  onSelect={addField}
  renderStep={(type, { back }) => (
    <LinkKindStep onBack={back} onPick={addLink} />
  )}
/>
```

## Accessibility

- A combobox search over a grouped listbox: ↑/↓ move, Enter chooses, Esc closes the host popover.
- Icons are decorative; each type is named by its label.

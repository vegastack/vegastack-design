## Usage

```tsx
import {
  AgentChip,
  AgentPanel,
  AgentSlot,
  AgentStateRing,
} from "@/components/ui/agent-panel";

<AgentPanel
  agent={{ name: "Claude Code", for: "Priya", provider: "claude.ai" }}
  state="working"
  startedAt={run.startedAt}
  progress={run.lastNote}
  instructions={delegation.instructions}
  onInstructionsChange={canSteer ? saveInstructions : undefined}
  latest={events}
  showLatest={!pageHasActivity}
  onReply={canSteer ? reply : undefined}
  runs={runs.map((run) => ({
    ...run,
    onView: () => openRun(run),
    onUndo: () => undo(run),
  }))}
  runsLayout={pageHasActivity ? "line" : "list"}
  onOpenAgent={openAgent}
  onChangeAgent={canSteer ? openDelegate : undefined}
  onStop={canSteer ? stop : undefined}
  onRemove={canRemove ? remove : undefined}
/>;
```

The panel is presentational: the host owns the delegation and passes its state, its data and the
callbacks. **The callbacks decide what shows**: pass `onReply`, `onInstructionsChange` and `onStop`
only to the person who delegated, `onRemove` to them and to admins, and `onReconnect` to the
agent's owner. `state="none"` renders nothing — the Delegate slot carries the empty state.

The card's header is the agent itself — its avatar, its name (which gets the room and truncates
last) and one muted line, "For Priya · claude.ai" (`for` and `provider`) — with no "Agent" title or
label. Under it sits **one status block**: the state's icon and word with its short facts, then one
sentence and at most one action, all in the word's inset. The other actions live in the ⋯ menu.
On a record page that has its own Activity feed, pass `showLatest={false}` so the card doesn't
repeat it, and `runsLayout="line"` for one compact Runs line ("Runs · 3 changes · 2h ago · View ·
Undo"); a peek, which has no feed, keeps both. A run's `summary` says what it changed ("1 change ·
Status, Lines · 12:11"); it is cut short before the count or the buttons are.

Each state reads the props it needs: `queued` (the host's `queuedHint` words once it has waited a
while — the design system holds no provider's vocabulary), `working`
(`startedAt`, `progress`), `question` (`question`, `choices`, `onAnswer`), `approval` (`approval`,
`onApprove`, `onDecline`), `failed` (`error`, `onRetry`), `blocked` (`blockedReason`,
`onReconnect`), `done` (`finishedAt`, `durationSeconds`, `summary`, `onMarkDone`) and `stopped`
(`stoppedBy`, `finishedAt`, `changeCount`, `onDelegateAgain`). A finished, failed or stopped card
whose agent was disconnected since takes `disconnected` and adds it to its sentence (with Reconnect
when `onReconnect` is set and the state has no other action) — it never turns back into Needs you.
`reasonHelp` (a Learn more link) follows a paused, failed or blocked card's reason, outside a
failure's quotes. `questionWait` tells a viewer who may not answer the question whom it waits on
("Waiting on Priya to answer."), unquoted, after the question's words or alone when they aren't shown.

`instructionsMaxLength` and `replyMaxLength` limit the instructions editor and the reply box without cutting them: each counts from 80% of the limit and, past it, shows its `…MaxLengthMessage` while Save or Send waits.

## Scope

Placement follows one rule: **the rail card on a record page** (`variant="card"`, directly under
Properties — above it while it needs you, `data-attention`), **the section in a peek**
(`variant="section"`), **the pill in a peek's pill row and a phone's facts row** (`AgentChip`),
**the one-line Delegate property** (`AgentSlot`) and **the state mark or ring in lists and boards**
(`AgentStateBadge`, `AgentStateRing`). `AgentHoverCard` puts the agent's facts behind its avatar or
name anywhere it appears. Choosing an agent is the `DelegatePopover`; an agent's edit to a document
is the `AgentEditBanner`. Every string comes in through `labels` and `stateLabels`, with the English
defaults shown here.

### States

The same card in every state: Queued with Stop, and with the host's hint after a while (and a long
name that truncates); Needs you with the question, one-tap answers and Reply…; Needs approval with
Approve and Decline; Failed with Retry; Can't start (blocked: its sign-in expired) with Reconnect for the owner — no tint; only a question or an approval sits on the warning tint; Done with its date,
run time, closing message and Mark task done; Stopped with what stays and Delegate again — and a
done card whose agent has since been disconnected, with Reconnect. A run's Undo shows disabled with its reason when the run can't be undone.

The rest of the states, each with one sentence and at most one action: Quiet (working, with no
update for a while: "No update for 30 min." from `lastUpdateAt`) with Stop; Not started (it waited
past the host's promise, in amber, with the host's `queuedHint`) with Stop; Paused with its
`pausedReason` and Resume (`onResume`); Needs approval decided elsewhere, with Review
(`onReview`) instead of Approve and Decline; Can't start because it can't see the record, with
Give access (`onGiveAccess`) for a viewer who can share; and No action needed (done, with nothing
to do) with its closing message. Only a question, an approval, a block and a failure ring the
avatar (`AgentStateRing`) and lift the card (`data-attention`); a quiet spell or a late start is
its amber icon alone.

### Section

In a peek the panel is a collapsible section whose header is the one-line summary and the state's
quick action. It opens unless the work is over. Stop sits on the header, so it stays in reach while collapsed.

### Slot, chip, badge and ring

`AgentSlot` is the Delegate property's value on one line — the agent's name truncates, its state
word never does — with the ghost "Delegate to an agent…" when empty and the muted reason when the
viewer can't delegate. `AgentChip` is the same as a pill; `AgentStateBadge` the state as icon and
word; `AgentStateRing` rings an agent's avatar amber while it needs you and red when it failed,
and with `glyph` badges the state's icon on the avatar's corner where no word sits beside it (a
grid's narrow name cell), so the state is never told by colour alone.
Hover the agent for `AgentHoverCard`, its lanyard: a 40px hexagon, its name with its kind
(`kindLabel`: "Custom", "Connected app", "Built in") in place of the "Agent" label, whose it is
(`owner`: "Priya Raman's agent", in place of "For Priya · claude.ai · Read & write"), what it does (`description`, two lines), any
`badges`, its state, its `lastAction` (the latest progress line, clamped to two lines), Open agent
(a link with `href`, through `linkRender` for a router link) and the technical facts in a muted
`footer`. Focus opens the card and Enter steps into it, so Open agent is reachable by keyboard — the card leads with the agent, not its plumbing. `AgentCard` is that card's body on
its own — hand it to a `PersonHoverCardProvider` so the agent's name in comments and activity opens
the same card.

## Accessibility

- A change of state while the panel is on screen is announced politely ("Claude Code: Needs
  you"); the state it mounts with is not. Relative times tick silently.
- The state is always an icon **and** a word; colour is never the only cue. The ring's state is
  said to screen readers unless the word is already beside it (`srLabel={false}`).
- The ⋯ menu is named for the agent ("More actions for Claude Code") and lists only the actions
  the viewer has. The agent's bot is decoration; the words name it.
- A run that can't be undone keeps a focusable, disabled Undo whose reason is its tooltip and its
  accessible description.
- The section's header is a heading holding the disclosure button, with `aria-expanded`.

| Key                                 | Action                                                         |
| ----------------------------------- | -------------------------------------------------------------- |
| <kbd>Tab</kbd>                      | Move through the menu, the state's actions, ✎, Reply and runs. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate a button, or open and close the section.              |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd>  | Send a reply, or save edited instructions (⌘ on a Mac).        |
| <kbd>Esc</kbd>                      | Cancel editing the instructions.                               |

## Usage

```tsx
import { AvatarPicker } from "@/components/ui/avatar-picker";

<AvatarPicker
  person={{ name: me.name, image: me.image, hue: me.color }}
  busy={saving}
  maxSize={10 * 1024 * 1024}
  onSelect={(file) => uploadPhoto(file)}
  onRemove={() => removePhoto()}
/>;
```

`AvatarPicker` is where someone sets their own photo, and the avatar is the control: their
`PersonAvatar` (the photo, else their initials on their colour) in a round button named "Upload
photo", or "Change photo" once there is one. Hover or keyboard focus lays a soft scrim with a pencil
over the circle, and a click opens the file browser (on a phone, the browser offers the camera and
the gallery). A device without hover shows a small pencil badge on the circle's edge instead, so the
photo is never covered. "Remove" is a small ghost button beside the circle while there is a photo.
A file of the wrong type or over `maxSize` is refused on the line beside the circle and announced —
an iPhone HEIC photo is told to export it as JPEG.

It only acquires the file: `onSelect` hands the app the one accepted `File`, and the app resizes
and uploads it, holds `busy` meanwhile, then passes the new `person.image` back.

### Busy

While `busy`, the scrim stays up with a spinner at the pencil's size, the circle and Remove are
disabled and the circle is `aria-busy`. The chosen file shows at once under the spinner as a local
preview; when `busy` ends the circle shows `person.image` again, so pass the new URL by then.

## Accessibility

- The circle is a real button named "Upload photo" or "Change photo"; "Remove" is a second button.
  The file input behind them is hidden and never takes focus.
- Keyboard focus shows the same scrim and pencil as hover — the circle's focus cue, with no ring.
- One polite live region announces every refused file and every `error`, exactly once each, with the
  same words shown beside the circle; the circle is described by that line while it shows.
- While `busy` the circle is disabled and `aria-busy`.

| Key                                 | Action                                     |
| ----------------------------------- | ------------------------------------------ |
| <kbd>Tab</kbd>                      | Move between the circle and Remove         |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open the file browser, or remove the photo |

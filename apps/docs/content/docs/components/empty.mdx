## Usage

```tsx
import { Empty, EmptyContent, EmptyDescription, EmptyMedia, EmptyTitle } from '@/components/ui/empty';
import { Inbox } from 'lucide-react';

<Empty bordered>
  <EmptyHeader>
    <EmptyMedia>
      <Inbox />
    </EmptyMedia>
    <EmptyTitle>No messages</EmptyTitle>
    <EmptyDescription>Your inbox is empty.</EmptyDescription>
  </EmptyHeader>
</Empty>;
```

## Anatomy

`Empty` is a compound component. Compose the parts inside the root:

```tsx
<Empty bordered size="default" surface="transparent">
  <EmptyHeader>
    <EmptyMedia intent="default">{/* lucide icon */}</EmptyMedia>
    <EmptyTitle>Title</EmptyTitle>
    <EmptyDescription>Supporting description text.</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>{/* action buttons */}</EmptyContent>
</Empty>;
```

- `Empty` — the centered container (`data-slot="empty"`). Owns `size`, `bordered`, and `surface`.
- `EmptyMedia` — a tinted circular chip around a `lucide-react` icon (`data-slot="empty-media"`, decorative `aria-hidden`). Owns the `intent` tint.
- `EmptyTitle` — the primary heading (`<h3>`, `data-slot="empty-title"`).
- `EmptyDescription` — supporting body text (`<p>`, `data-slot="empty-description"`).
- `EmptyContent` — a centered row of call-to-action controls (`data-slot="empty-content"`).

## Sizes

`size` controls vertical density only — `sm` (`py-8`) for empties inside cards, `default` (`py-12`)
standalone, and `lg` (`py-16`) for full-page zero-data screens.

## Surfaces

`surface` switches the background — `transparent` (the default) inherits the parent surface and is
usually paired with `bordered` for a drop-zone outline, while `card` paints a filled `bg-card`
panel that reads as a self-contained block on any background.

<ComponentPreview name="emptyDemoSurfaces" file="components/preview/empty.tsx" />

## Border

`bordered` is `false` by default — a borderless empty blends into the surrounding layout. Set
`bordered` to draw the classic dashed "drop zone" outline.

## Without an icon

`EmptyMedia` and `EmptyContent` are both optional. A title-and-description-only empty is
a common compact form — for example, a "no filters applied" hint.

## Intents

`EmptyMedia` takes an `intent` that tints the chip — neutral `default`, `info`, or
`destructive` — each mapping to semantic status tokens (`bg-X-subtle text-X-text`). Use
`destructive` for error/failure empties, `info` for search/filter empties, and `default` for plain
zero-data states.

## Accessibility

- The title renders as a real `<h3>` heading so assistive technology can navigate to it.
- The icon chip is decorative (`aria-hidden`) — meaning is carried by the title and description text, never by the icon or color alone.
- Action controls inside `EmptyContent` are real buttons/links with their own accessible names and `:focus-visible` rings.
- The container is non-interactive; keyboard focus order flows through the action controls only.

| Key | Action |
| --- | --- |
| <kbd>Tab</kbd> | Move focus to the first action control (when actions are present). |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activate the focused action control. |

## Usage

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty";

<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <Icon />
    </EmptyMedia>
    <EmptyTitle>No data</EmptyTitle>
    <EmptyDescription>No data found</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button>Add data</Button>
  </EmptyContent>
</Empty>;
```

<ComponentPreview name="empty" file="components/preview/empty.tsx" />

Which empty state a surface needs — nothing yet, no matches, couldn't load, blocked — and its default
copy is set by the [empty-state tiers](/docs/foundations/empty-states). A search or filter that
matched nothing is "No matches" with a "Clear filters" action, and a failed load is `role="alert"`
with "Try again".

## Accessibility

- Every part renders a plain `<div>`, so the empty state adds no landmark and no implicit heading.
  Where the placeholder replaces a named region, give the surrounding container the heading.
- `EmptyTitle` is styled text by default, not a heading element. When the empty state stands in
  for a section, pass `render={<h2 />}` (or the level the outline needs) so the title is the real
  heading (API-22).
- `EmptyMedia` is decorative: the icon inside it carries no accessible name, and the title plus
  the description are what a screen reader announces.
- `EmptyContent` holds real controls — a `Button`, an `Input`, a link — and each keeps its own
  focus outline from `base.css`; the placeholder never suppresses one.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/empty.patch`. Every hunk:

- **TYP-15** — the title's `tracking-tight` is dropped: the title is `text-sm`, in the copy tier,
  which the theme holds at zero tracking.
- **API-22** — `EmptyTitle` renders through Base UI's `useRender`, so it takes `render` and the
  heading level is set on the part. The default `div`, the `data-slot` and the classes are
  upstream's.
- **API-16** — `"use client"` is added: `useRender` calls `React.useRef` internally, so the module
  needs the client boundary to import in a Server Component.
- **DOC-2** — `cn` is imported from `@vegastack/design`.

## Usage

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty";

<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <Icon />
    </EmptyMedia>
    <EmptyTitle>No data</EmptyTitle>
    <EmptyDescription>No data found</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button>Add data</Button>
  </EmptyContent>
</Empty>;
```

## Accessibility

- Every part renders a plain `<div>`, so the empty state adds no landmark and no implicit heading.
  Where the placeholder replaces a named region, give the surrounding container the heading.
- `EmptyTitle` is styled text, not a heading element, and the part takes no `render` prop. When the
  empty state stands in for a section that already had a heading level, put the real heading in the
  surrounding container rather than relying on the title.
- `EmptyMedia` is decorative: the icon inside it carries no accessible name, and the title plus
  the description are what a screen reader announces.
- `EmptyContent` holds real controls — a `Button`, an `Input`, a link — and each keeps its own
  focus outline from `base.css`; the placeholder never suppresses one.

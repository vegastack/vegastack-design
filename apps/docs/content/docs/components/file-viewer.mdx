## Install

<InstallSteps name="file-viewer" />

The item installs `pdfjs-dist` (`^6.3.289`). It is imported only when a PDF is shown, so an app
that never passes `pdfSrc` never downloads pdf.js. The worker is served from your own origin: the
PDF part creates it with `new Worker(new URL("pdfjs-dist/build/pdf.worker.min.mjs", import.meta.url), { type: "module" })`,
which Next.js and Vite emit as a same-origin asset. Markdown and HTML previews load
[`MarkdownView`](/docs/components/markdown-view) the same way — lazily, the first time one shows.

## Usage

```tsx
import { FileViewer, type FileViewerItem } from "@/components/ui/file-viewer";

const [index, setIndex] = React.useState<number | null>(null);

<FileViewer
  items={files}
  index={index}
  onIndexChange={setIndex}
  onOpenChange={(open) => !open && setIndex(null)}
/>;
```

Each item carries resolved URLs — the viewer fetches nothing it is not handed:

```ts
const item: FileViewerItem = {
  id: file.id,
  name: file.name,
  contentType: file.contentType,
  size: file.size,
  thumb: { src: file.url480, srcSet: file.srcset, blur: file.blur },
  src: file.url1920, // full-size image; falls back to thumb.src
  srcSet: file.srcsetFull, // falls back to thumb.srcSet
  pdfSrc: file.inlineUrl, // PDFs: inline disposition, range requests
  downloadHref: file.downloadUrl,
  refreshSrc: () => renewUrl(file.id), // video/audio: an expired signed URL
  peaks: file.peaks, // audio: a stored waveform
};
```

For video, audio, text, CSV and Markdown, `src` is the file's inline URL. Text-like files are read
with `Range: bytes=0-1048575`, so a cross-origin store must allow the `Range` request header and
expose `Content-Range` (a single-range request is CORS-safelisted in current browsers).

## Scope

| Behaviour                       | Where it lives                                                                                                        |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Which file is open, and closing | Host — `index` is controlled; `onOpenChange(false)` means set it to null                                              |
| Signing or resolving URLs       | Host — pass `src`, `srcSet`, `pdfSrc` and `downloadHref` ready to use                                                 |
| Video and audio playback        | [`VideoPlayer`](/docs/components/video-player) / [`AudioPlayer`](/docs/components/audio-player), mounted on the stage |
| Parsing Office files            | Host — `loadPreview` returns a table, HTML, text or a card; the parser stays an app dependency                        |
| Posters, peaks, Office pictures | Host, at upload — `probeVideo`, `probeAudio`, `extractPptxThumbnail` from the `media-probe` lib                       |
| The tiles that open it          | [`Attachment`](/docs/components/attachment), a thumbnail grid, any button                                             |

## Examples

### Image gallery

Images open fit to the screen. The item's `thumb.blur` (or the thumb itself) fills the image's
box, blurred, and the full image fades in over it; `srcSet` with `sizes="100vw"` lets the browser
pick the largest variant the screen needs, and the neighbouring images are preloaded so paging is
instant. Double-click or double-tap zooms to 2.5× at the pointer, a pinch or ⌘/Ctrl + scroll
zooms freely, a drag pans while zoomed, and <kbd>+</kbd> / <kbd>−</kbd> / <kbd>0</kbd> zoom in,
out and back to fit. ←/→ or the side buttons page (the buttons show on a mouse or trackpad); on a
phone a swipe left or right pages and a swipe down closes.

### PDF

A PDF with a `pdfSrc` renders with pdf.js, loaded the first time a PDF is shown. It loads with
range requests (64 KB chunks, no background fetch), so a large file opens at page 1 without
downloading the rest. Pages render into canvases at the screen's pixel ratio, fit to the width
up to a reader's page width (920px) — on a wide screen the page sits centred on the dark stage,
on a phone it fills the width — in a vertical scroller; only the current page and two either
side hold a canvas. The toolbar zooms out, in and back to fit width, and shows "Page 2 of 3". While the document loads, the
item's thumb (a PDF's preview image) or a spinner shows; if it cannot load, the file card below
takes its place.

### Video and audio

A `video/*` or `audio/*` item with a `src` plays on the stage in the system's own
[`VideoPlayer`](/docs/components/video-player) / [`AudioPlayer`](/docs/components/audio-player) —
never autoplaying. The player pauses when you page away or close the viewer; <kbd>←</kbd>/<kbd>→</kbd>
still page unless focus is inside the player, where they seek. The video letterboxes (a portrait
clip is never cropped) with `thumb.src` as its poster; one the browser cannot play shows "Can’t play
this video here" with Download. The item's `refreshSrc` renews an expired signed URL and resumes
where playback stopped; an audio item with stored `peaks` plays in the waveform player.

### Text and code

A text or code file with a `src` (`.txt`, `.log`, `.json`, `.yaml`, `.xml`, source files) shows
its first megabyte, monospaced and wrapped, in a sheet you can scroll and focus. A longer file ends
at its last whole line and says "Showing the first 1 MB. Download the file to see all of it." There
is no syntax highlighting.

### CSV

A `.csv` or `.tsv` is a table. A small built-in parser (`parseCsv`, exported) reads quoted fields
with commas, line breaks and `""` escapes, CRLF rows and a byte-order mark, and sniffs `,`, `;` or a
tab. The first row is the header, which stays in view while you scroll; at most 500 rows show,
with "Showing first 500 rows" under the table.

### App-parsed previews

`loadPreview` is called for every file that is not an image, PDF, video or audio, with an
`AbortSignal` that fires when the user pages away. Return a `FileViewerPreview` — `text`, a
`table` (the first row is the header; `totalRows` makes the note "Showing first 500 of 12,400
rows"), `markdown`, `html` (rebuilt through `MarkdownView`'s allowlist, never injected) or a `card`
with a picture and facts ("12 slides") — or `null` to keep the built-in reading. A spinner shows
while it runs; a rejection falls back to the built-in reading. So SheetJS for spreadsheets or
mammoth for Word files stay the app's dependencies, lazily imported by the app.

```tsx
<FileViewer
  items={files}
  loadPreview={async (item, { signal }) => {
    if (item.name.endsWith(".xlsx")) {
      const { firstSheet } = await import("@/lib/office-preview");
      return { kind: "table", ...(await firstSheet(item.src!, { signal })) };
    }
    return null;
  }}
  {...viewer}
/>
```

### Upload-time helpers

The `media-probe` lib reads, in the browser and with no dependency, what is worth storing beside
the original so nothing has to be downloaded again to show it:

```ts
import {
  extractPptxThumbnail,
  probeAudio,
  probeVideo,
} from "@/lib/media-probe";

const { duration, width, height, poster } = await probeVideo(file); // a JPEG ~1s in
const { duration, peaks } = await probeAudio(file); // ≤ 200 peaks; none over 50 MB
const thumbnail = await extractPptxThumbnail(file); // docProps/thumbnail.jpeg, or null
```

`probeVideo` rejects when the browser cannot decode the file — upload it without a poster then.
`extractPptxThumbnail` reads only the zip's central directory and that one entry, and works for
any Office file saved with a preview picture.

### From attachment tiles

`AttachmentTrigger` renders a `<button>` that covers the tile, so an `onClick` that sets the index
is all it takes — no `render` link. Focus returns to the tile that opened the viewer when it
closes.

```tsx
<AttachmentGroup>
  {files.map((file, i) => (
    <Attachment key={file.id} orientation="vertical">
      <AttachmentMedia variant="image">
        <img src={file.thumb?.src} alt="" />
      </AttachmentMedia>
      <AttachmentContent>
        <AttachmentTitle>{file.name}</AttachmentTitle>
      </AttachmentContent>
      <AttachmentTrigger
        aria-label={`Open ${file.name}`}
        onClick={() => setIndex(i)}
      />
    </Attachment>
  ))}
</AttachmentGroup>
```

### FileViewerItem

| Field          | Type                                                              | Notes                                                                                                                                                                                                                                   |
| -------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | `string`                                                          | Stable id; zoom and scroll reset when it changes.                                                                                                                                                                                       |
| `name`         | `string`                                                          | The dialog's title and the image's alt text.                                                                                                                                                                                            |
| `contentType`  | `string \| null`                                                  | `image/*` → image, `application/pdf` → PDF, `video/*` / `audio/*` → player, text/code, CSV and Markdown → their previews, anything else → `loadPreview` or the file card; a missing or generic type falls back to the name's extension. |
| `size`         | `number \| null`                                                  | Bytes, shown on the file card.                                                                                                                                                                                                          |
| `thumb`        | `{ src: string; srcSet?: string; blur?: string \| null } \| null` | The blurred placeholder, a PDF's loading frame, a video's poster and a file card's picture.                                                                                                                                             |
| `src`          | `string \| null`                                                  | Full-size image (falls back to `thumb.src`); the video/audio URL; or a text, CSV or Markdown file's URL, read with a range request.                                                                                                     |
| `srcSet`       | `string \| null`                                                  | Full-size srcset; falls back to `thumb.srcSet`.                                                                                                                                                                                         |
| `pdfSrc`       | `string \| null`                                                  | Inline-disposition, range-capable PDF URL.                                                                                                                                                                                              |
| `downloadHref` | `string`                                                          | The Download link's URL.                                                                                                                                                                                                                |
| `refreshSrc`   | `() => Promise<string>`                                           | Renews an expired video or audio URL; the player resumes where it stopped.                                                                                                                                                              |
| `peaks`        | `readonly number[] \| null`                                       | An audio file's stored waveform; the audio plays in the waveform player.                                                                                                                                                                |

### FileViewerPreview

| `kind`     | Fields                                                                              | Shows                                                             |
| ---------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `text`     | `text: string`, `truncated?: boolean`                                               | Monospaced, wrapped text in a scrollable sheet.                   |
| `table`    | `rows: readonly (readonly string[])[]`, `totalRows?: number`, `truncated?: boolean` | A table; the first row is the header; at most 500 data rows show. |
| `markdown` | `markdown: string`, `truncated?: boolean`                                           | Rendered through `MarkdownView`.                                  |
| `html`     | `html: string`                                                                      | Rebuilt through `MarkdownView format="html"`'s allowlist.         |
| `card`     | `thumb?: string \| null`, `facts?: readonly string[]`                               | The file card with that picture and the facts after the size.     |

### parseCsv

`parseCsv(text, { delimiter?, maxRows? })` returns `{ rows: string[][]; truncated: boolean }`: RFC
4180 quoting, CRLF or LF, a leading byte-order mark dropped, blank lines skipped, the delimiter
sniffed from the first line unless given, and `truncated` when rows remained past `maxRows`.

## Accessibility

- A modal dialog named by the file name; everything behind it is inert. Focus moves to the
  viewer itself when it opens (no control looks pressed; Tab reaches them) and returns to the
  element that opened it when it closes.
- Paging announces the destination through a polite live region — "Image 3 of 12", "PDF 4 of
  12", "Video 5 of 12", "Audio 6 of 12", "Text 7 of 12", "Table 8 of 12", "Document 9 of 12",
  "File 10 of 12". Opening does not announce: the dialog's name already says which file.
- A text, Markdown or HTML preview is a region named `{name} preview` that takes focus, so it
  scrolls from the keyboard; a table's region takes focus only while it overflows, and its header
  cells are column headers.
- The icon buttons are named (`Download {name}`, "Close", "Previous file", "Next file", "Zoom
  in", "Zoom out", "Fit to width"); on a touch screen they grow to 44px.
- Each rendered PDF page is an image named `{name}, page N`.
- Motion (the zoom easing, the fade) collapses under reduced motion.

| Key                         | Action                              |
| --------------------------- | ----------------------------------- |
| <kbd>←</kbd> / <kbd>→</kbd> | Previous / next file.               |
| <kbd>+</kbd> / <kbd>−</kbd> | Zoom the image or PDF in / out.     |
| <kbd>0</kbd>                | Back to fit (fit width for a PDF).  |
| <kbd>Esc</kbd>              | Close and return focus.             |
| <kbd>Tab</kbd>              | Move between the viewer's controls. |

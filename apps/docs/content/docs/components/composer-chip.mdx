## Usage

```tsx
import { ComposerChip } from "@/components/ui/composer-chip";

<ComposerChip
  icon={<ListChecks />}
  pressed={plan}
  onPressedChange={setPlan}
  tooltip="Plan first: it changes nothing until you accept"
>
  Plan
</ComposerChip>;
```

One look, three forms. With `pressed` or `defaultPressed` it is a toggle: a quiet outline when off,
the primary tint when on. With `menu` it is a picker's trigger with a chevron, and it spreads every
prop onto its button so a menu can render it (`render={<ComposerChip menu … />}`). With `readOnly` it
shows the same words with no control, for a reader who may not change them. Pass the chips to
`ChatComposer`'s toolbar. For what travels with the message, use the composer's own chips.

## Accessibility

- The toggle is a button with `aria-pressed`. The menu trigger takes the menu's own attributes; give
  it a name that says the choice, "Model: Haiku 5.5".
- Read-only is plain text: it takes no focus.
- `tooltip` opens on hover and on keyboard focus.

| Key              | Action                            |
| ---------------- | --------------------------------- |
| <kbd>Tab</kbd>   | Move to the chip                  |
| <kbd>Space</kbd> | Flip the toggle, or open the menu |

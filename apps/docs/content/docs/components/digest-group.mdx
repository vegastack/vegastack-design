## Usage

```tsx
import { DigestGroup } from "@/components/ui/digest-group";

<DigestGroup
  title="Overdue"
  count={87}
  urgent
  groupAction={{ label: "Update all…", onClick: openBulkUpdate }}
  footer={{ hasMore, remaining: 75, loading, onLoadMore }}
>
  {tasks.map((task) => (
    <Item key={task.id} size="sm">
      …
    </Item>
  ))}
</DigestGroup>;
```

The group is composed: you build each row from `Item` and `ItemActions` with that row's own
authorized actions, and the group draws the header, the one group action and the footer. It holds
no rows or actions of its own.

## Examples

### Header

`urgent` adds a warning glyph before the title. `headerExtra` holds more after the count, such as a
blocker chip and its line.

### Footer

The footer is controlled. While `hasMore`, it reads "Show 75 more" (`remaining`) or "Show more";
`loading` holds the button with its spinner. Without `footer`, there is none.

## Accessibility

- The group is a region named by its title and count; its rows are a list named the same way.
- The urgent glyph is named "Needs attention".
- The footer button reports `aria-busy` while it loads.

| Key                                 | Action                     |
| ----------------------------------- | -------------------------- |
| <kbd>Tab</kbd>                      | Group action, rows, footer |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Run the focused action     |

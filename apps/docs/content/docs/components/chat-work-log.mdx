## Usage

```tsx
import { LiveLine, WorkLog, WorkSummary } from "@/components/ui/chat-work-log";

{
  live ? (
    <LiveLine
      words="Searching the web"
      startedAt={turn.startedAt}
      open={open}
      onToggle={toggle}
    />
  ) : (
    <WorkSummary summary={turn.summary} open={open} onToggle={toggle} />
  );
}
<WorkLog parts={message.parts} detail={detail} open={open} />;
```

`LiveLine` is the turn's one moving thing: the braille spinner, the current step in words and a
timer in tabular figures with its width reserved. After 45 seconds with no event it adds what the
turn waits on, with Stop and Keep waiting. `WorkSummary` replaces it in place, the same 28px. Rows
in `WorkLog` read as a muted verb, the subject in the body ink and muted meta and duration; thinking
shows as 13px muted notes clamped to two lines. No row has an icon or a spinner; "Running" is a
word. `MessageParts` composes all of this; reach for these parts directly in a Subagent's steps.

## Accessibility

- `LiveLine` (with `onToggle`) and `WorkSummary` are buttons with `aria-expanded` for the log.
- The live words are announced politely; the timer is hidden from screen readers.
- A long note is a button that opens it in full.

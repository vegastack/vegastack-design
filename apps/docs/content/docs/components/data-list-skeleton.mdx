## Usage

```tsx
import { DataListSkeleton } from "@/components/ui/data-list-skeleton";

// app/(app)/tasks/loading.tsx
export default function Loading() {
  return (
    <DataListSkeleton
      columns={columns}
      rows={6}
      selectable
      toolbar={{ tools: 3 }}
    />
  );
}
```

A route's loading page or a Suspense fallback for a `DataList` page. It draws the `ListToolbar`
row (a search and its tool buttons, 32px), then the table's header and 40px rows — the first
column fills, the others drop under `md` as the list merges them — or, with `view="grid"`, the
grid's `MediaCard lg` cards in the grid's own columns. It imports only `Table` and `Skeleton`, so
the page's loading state never pulls in the list, its toolbar or its menus.

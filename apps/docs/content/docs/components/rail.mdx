## Usage

```tsx
import { Rail, RailBottom, RailItem } from "@/components/ui/rail";

<Shell
  rail={
    <Rail>
      <RailItem icon={<Home />} label="Home" render={<Link href="/" />} active />
      <RailItem
        icon={<Inbox />}
        label="Inbox"
        badge={unread}
        render={<Link href="/inbox" />}
      />
      <RailBottom>
        <RailItem
          icon={<Settings2 />}
          label="Settings"
          render={<Link href="/settings" />}
        />
      </RailBottom>
    </Rail>
  }
  …
/>;
```

The rail holds the app's modules and nothing else, about seven of them, with Settings in the
bottom group, with the workspace's tile and the person's avatar as its two ends. Search and Help live in the [global bar](/docs/components/global-bar).
There is no More menu: a rail that needs one has too many modules.

## Examples

### Counts and dots

`badge` puts a count on the icon (`RailBadge`): a 14px chip of 10px tabular numerals on the icon's
top-right corner, overlapping the icon by only 4px so the icon keeps its shape even at "99+". It is
the one text below 12px in the system (TYP-18's exception), and it is the same chip the phone
bottom bar uses. `dot` marks something new that has no count; pass the words it means.

### Animated icons

An item can carry the same icon animated. The static `icon` paints with the page; the animated
one, a DS animated icon wrapped in `lazyAnimatedIcon` so its module and Motion stay out of the
first bundle, loads once the browser is idle, takes the static icon's place at the same 18px, and
plays when the item is hovered or becomes current. With reduced motion it stays still.

```tsx
"use client";
import { lazyAnimatedIcon } from "@/components/ui/rail";
export const HomeIconLazy = lazyAnimatedIcon(() =>
  import("@/components/ui/icons/home").then((m) => m.HomeIcon),
);

// in the rail (a server component is fine):
<RailItem
  icon={<Home />}
  animatedIcon={<HomeIconLazy />}
  label="Home"
  href="/"
/>;
```

### The rail's two ends

The rail's fixed ends (LAY-26) are the workspace and the person. `RailTop` holds the workspace's
36px logo tile, with a short rule under it, above the modules; the tile is the workspace menu's
trigger. Under Settings in `RailBottom`, `RailTile shape="avatar"` is the person's round 32px
avatar, the account menu's trigger. Both sit on the rail's centre line, with a ring in the canvas
and a hairline that darkens on hover.

```tsx
<Rail>
  <RailTop>
    <WorkspaceMenu trigger={<RailTile label="Workspace: Acme. Switch workspace">A</RailTile>} />
  </RailTop>
  <RailItem icon={<Home />} label="Home" href="/" active />
  <RailBottom>
    <RailItem icon={<Settings2 />} label="Settings" href="/settings" />
    <AccountMenu trigger={<RailTile shape="avatar" label="Ada Lovelace, account"><Avatar … /></RailTile>} />
  </RailBottom>
</Rail>
```

## Accessibility

- The rail is a navigation landmark named "Modules"; the current module carries
  `aria-current="page"`.
- A count is part of the item's name ("Inbox, 99+"), and a dot's words are read after the label;
  the chip itself is hidden from screen readers.
- Every icon sits on the rail's centre line, the same axis as the global bar's first control.

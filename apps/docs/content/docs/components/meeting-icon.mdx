## Usage

```tsx
import { MeetingIcon } from "@/components/ui/meeting-icon";

<MeetingIcon status={meeting.status} speakerCount={meeting.speakerCount} />;
```

One rule everywhere a meeting has an icon, mixed lists included: a single person for one speaker,
a group for two or more (or while nobody knows yet), and the loading `Spinner` while the meeting
records, uploads or is processed. `meetingIconKind` returns the same answer as data for places
that pick a glyph themselves.

## Examples

### Recording controls

`RECORDING_ACTIONS` holds each control's words — "Start recording", "Pause recording", "Resume
recording", "Stop recording" — with a Title Case `menuLabel` for macOS menus only.
`RecordingActionIcon` draws its glyph: the record dot in the destructive ink for Start, then
pause, play and stop. The microphone is only ever voice input.

## Accessibility

- Beside a meeting's title the icon is decorative (`aria-hidden`); pass `label` where it stands
  alone.
- The live spinner never announces itself in a list: the meeting's status words say it.

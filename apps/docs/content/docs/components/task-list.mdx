## Usage

```tsx
import { TaskList } from "@/components/ui/task-list";

<TaskList
  startedAt={run.startedAt}
  items={[
    { text: "Find my open tasks", status: "completed", ms: 4000 },
    {
      text: "Create the PDF",
      status: "in_progress",
      doing: "Creating the PDF",
    },
    { text: "Reply with the file", status: "pending" },
  ]}
/>;
```

Pass the whole list each time the agent rewrites it; the list decides what shows. The header names
the live item ("Creating the PDF…") with the count and a live timer. For what the agent did step by
step, use [`MessageActivity`](/docs/components/message-parts); for a plan waiting for an answer, use
a request card.

## Examples

### Long lists

Five or fewer rows never fold. A longer list keeps the live item on top: finished items fold into
"✓ N done", the next two to do follow the live item, and the rest fold into "+N more". Opening
either fold shows every row, with Show less to fold them back. Closed while working, the header
reads "Step 3 of 9 · Create the PDF".

### States

`done` closes the list a second after it finishes, to "Done · 4 of 4 steps". `stopped` keeps it open
and marks the item that didn't finish with an amber ⚠ and the words "didn't finish"; the items not
reached say "not done". A `waiting` item
shows the "Waiting for you" badge and its action, and the header says so. Skipped items are struck
through. Neither a skipped, unfinished nor waiting item ever folds. `note` adds a muted line under
the list.

## Accessibility

- The header is a disclosure button; the rows are a list named "Task list". Each item is read with
  its state first ("In progress: Create the PDF"), since the icon is what shows it.
- One polite live region says when the live item changes ("Step 3 of 9: Create the PDF"), at most
  once every 3 seconds, and the end once. Nothing is announced when the list first appears.
- A tick pops and a row entering the window rises only on a live change; with reduced motion both
  are instant.
- Colour is never the only cue: the ⚠ row says "didn't finish", and no row is ever tinted.

| Key              | Action                                 |
| ---------------- | -------------------------------------- |
| <kbd>Tab</kbd>   | Move to the header, the folds, actions |
| <kbd>Enter</kbd> | Open or close the list, open a fold    |
| <kbd>Space</kbd> | Same as <kbd>Enter</kbd>               |

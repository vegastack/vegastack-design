## Usage

```tsx
import { SortMenu, sortSummary } from "@/components/ui/sort-menu";

<ListToolbar
  sort={{
    content: (
      <SortMenu
        fields={[
          { key: "due", label: "Due date", type: "date" },
          { key: "title", label: "Title" },
        ]}
        value={sort}
        defaultValue={{ key: "due", direction: "asc" }}
        onValueChange={setSort}
      />
    ),
    isDefault: sort.key === "due" && sort.direction === "asc",
    summary: sortSummary(fields, sort),
  }}
/>;
```

A list that sorts by one key shows exactly that: which field, then which direction, each a group of
options with a check on the chosen one. There are no drag handles, selects or "Add sort" — an
affordance a one-key list can never use is not shown. The directions read in the field's own words:
dates "Oldest first / Newest first", text "A → Z / Z → A", numbers "Low → high / High → low", a
fixed order (priority, status) "First to last / Last to first". "Reset" sits in the header while the
order differs from `defaultValue`. A column header click writes the same value.

A field the list can sort only one way sets `fixedDirection`: its direction shows in muted words
beside its name ("Last updated Newest first"), picking it sets that direction, and the direction
group hides while it is chosen, so the menu never offers an order the server cannot give.
`fixedDirection: "none"` is a manual order ("Custom order"): no direction words at all.

`sortSummary(fields, value)` returns one line ("Due date, oldest first") for the Sort row Display
shows once the toolbar has folded Sort into it.

For several keys at once (a table), use `SortBuilder` from
[`filter-bar-managed`](/docs/components/filter-bar-managed).

## Accessibility

- The fields are a `radiogroup` labelled by its "Sort by" heading; the directions are a second
  `radiogroup` named "Direction". The chosen option is `aria-checked`.
- Each option is 32px tall from the surface's 8px inset.

| Key                       | Action                        |
| ------------------------- | ----------------------------- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move within a group and pick  |
| <kbd>Tab</kbd>            | Move between Reset and groups |

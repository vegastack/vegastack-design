## Usage

```tsx
import { InfoHint } from "@/components/ui/info-hint";

<h2 className="flex items-center gap-1">
  Spaces
  <InfoHint label="About spaces" href="https://help.example.com/spaces">
    A space groups the people and records that work together.
  </InfoHint>
</h2>;
```

`InfoHint` composes a ghost `icon-xs` [`Button`](/docs/components/button) with a muted info icon and
a [`Popover`](/docs/components/popover). The children are the explanation — one sentence. `href`
adds a link under it that opens in a new tab; `linkLabel` names it (default "Learn more").

## Scope

| Need                                       | Use                                   |
| ------------------------------------------ | ------------------------------------- |
| One sentence explaining a heading or label | `InfoHint`                            |
| The name of an icon-only control           | [`Tooltip`](/docs/components/tooltip) |
| Help text a person needs to fill a field   | `FieldDescription`, always visible    |
| Rich content, forms or several actions     | [`Popover`](/docs/components/popover) |

### In a dialog

The hint never takes focus on its own, but `DialogContent` focuses the first focusable element when
it opens — a hint in the title would be first. Point the dialog's `initialFocus` at the first field.

```tsx
const nameRef = useRef<HTMLInputElement>(null);

<DialogContent initialFocus={nameRef}>
  <DialogTitle className="flex items-center gap-1">
    New space
    <InfoHint label="About spaces">
      A space groups the people and records that work together.
    </InfoHint>
  </DialogTitle>
  <Input ref={nameRef} />
</DialogContent>;
```

## Accessibility

- `label` is required and names the trigger; write it as "About &lt;topic&gt;".
- The trigger is a real button, so it opens on click, tap, <kbd>Enter</kbd> or <kbd>Space</kbd>, and
  reports `aria-expanded`.

| Key               | Action                                              |
| ----------------- | --------------------------------------------------- |
| <kbd>Enter</kbd>  | Opens or closes the popover                         |
| <kbd>Space</kbd>  | Opens or closes the popover                         |
| <kbd>Tab</kbd>    | Moves into the popover's link, when there is one    |
| <kbd>Escape</kbd> | Closes the popover and returns focus to the trigger |

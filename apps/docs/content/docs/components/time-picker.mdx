## Usage

```tsx
import { TimePicker } from "@/components/ui/time-picker";

function Example() {
  const [time, setTime] = React.useState<string | null>("09:30");
  return (
    <TimePicker aria-label="Start time" value={time} onValueChange={setTime} />
  );
}
```

The value is `HH:MM` on a 24-hour clock (`"09:30"`, `"21:00"`), the same string a native
`<input type="time">` holds, or `null` for none. The field shows it in the locale's clock — "9:30 AM"
in `en-US`, "09:30" in `en-GB` — or the one `hourCycle` names.

Type a time or open the list. "9", "930", "9:30", "9.30", "9:30 pm", "9p" and "21:30" all read as
you would expect; the list narrows to the times the text can still become, and the parsed time is
always its first option, so <kbd>Enter</kbd> takes exactly what was typed, between steps too
("9:37"). Leaving the field commits it. Text that is not a time marks the field invalid while it is
focused and goes back to the last value when you leave; <kbd>Esc</kbd> goes back at once. Emptying
the field reports `null`.

It is our `Combobox` (an `InputGroup` input with a clock and a list popup), so it takes the same
border, focus, invalid and disabled styling as every text field, and inside a `Field` its label,
description and error wire up the same way.

## Scope

A time of day on its own — an opening hour, a reminder time. For a date with a time, use
[`DateTimePicker`](/docs/components/date-time-picker), which pairs this field with the
`DatePicker` and handles the time zone. It is not a duration or a time range.

## Accessibility

- The input is an editable `combobox` with a `listbox` of times (Base UI's APG pattern): the list
  is announced as it narrows, and each option is named by its face ("9:30 AM").
- The clock is decoration (hidden from assistive tech). Name the field with a `FieldLabel` or
  `aria-label`.
- Typed text that is not a time sets `aria-invalid` until it is fixed or the field is left, so the
  invalid state is never colour alone.
- Disabled is the native disabled input; nothing opens.

| Key                         | Action                                                                  |
| --------------------------- | ----------------------------------------------------------------------- |
| Type                        | Edit the time; the list narrows and its first option is the typed time. |
| <kbd>↓</kbd> / <kbd>↑</kbd> | Open the list, then move through the times.                             |
| <kbd>Enter</kbd>            | Take the highlighted time, or the typed one, and close.                 |
| <kbd>Tab</kbd>              | Commit what was typed and move on.                                      |
| <kbd>Esc</kbd>              | Close the list and go back to the last value.                           |

## Do / Don't

## Usage

```tsx
import { ChatCard, ChatGroup, ChatRow } from "@/components/ui/chat-card";

<ChatCard
  title="Send this email?"
  meta="Gmail · sm@vegastack.com"
  actions={<Button size="sm">Allow once</Button>}
>
  Weekly supplier summary to the sales team.
</ChatCard>;
```

A card appears only for something a person acts on or opens: a waiting request, question or plan,
the task list, a file preview. Work, memory saves, answered asks and errors are flat lines in the
column. `ChatCard` is a faint fill one step off the page with a hairline, the same in light and
dark, a 12px corner and 16px padding (12px under 640px), with no shadow (COL-25). Outside a chat
use [`Card`](/docs/components/card).

### Rows

A muted verb, the subject in the body ink (it truncates first), then quiet meta and the duration
right after it, never floated to the far edge. `onOpen` makes the row a button and `href` a link,
both on the hover layer.

<ComponentPreview name="chatRow" file="components/preview/chat-card.tsx" />

### Groups

`ChatGroup` folds work behind one summary line. The chevron turns and the rows slide open on the
chat motion (`duration-state` in, `duration-state-exit` out). While `live`, the summary leads with
the braille spinner, the turn's one moving thing. A hairline guide runs down the gutter.

## Accessibility

- `ChatCard` is a `section`; pass `as="div"` inside a list.
- A row that opens something is a button or a link whose name reads its words in order ("Opened
  Quote sheet").
- A group's summary is a disclosure button with `aria-expanded`; Enter and Space open and close it.

| Key                                 | Action                      |
| ----------------------------------- | --------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Open or close a group       |
| <kbd>Tab</kbd>                      | Move to the next row action |

## Usage

```tsx
import { EffectPill } from "@/components/ui/effect-pill";

<EffectPill effect="send" />;
```

Six effects, least reach first: `read`, `draft`, `change`, `send`, `remove`, `spend`. Reading and
drafting are quiet, a change is informational, sending and spending warn, and removing is
destructive. The word carries the meaning; the colour only repeats it.
[`PlanCard`](/docs/components/plan-card) gives every step one.

## Accessibility

- The pill is text, not a control. Its word is read in place, also when only the icon shows.
- The icon is decorative.

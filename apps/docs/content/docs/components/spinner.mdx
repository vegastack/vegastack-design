## Examples

### Customization

The spinner is a single lucide icon, so swapping the mark is a one-line edit to the component: the
`role`, the accessible name and the `size-4 animate-spin` recipe stay where they are. The second
mark below is `LoaderIcon` in place of the default `Loader2Icon`.

### Size

Use the `size-*` utility class to change the size of the spinner. It has no `size` prop — passing
`size`, `width` or `height` to a lucide component is not how this system sizes icons.

<ComponentPreview name="spinnerSize" file="components/preview/spinner.tsx" />

### Button

Add a spinner to a button to indicate a loading state. Place the spinner before the label with
`data-icon="inline-start"` for a start position, or after the label with `data-icon="inline-end"`
for an end position. For a pending submit that must keep its width, use the Button's own `loading`
prop instead.

## Accessibility

- The icon renders `role="status"` with `aria-label="Loading"`, so the wait is announced once
  without a live region of your own.
- When the spinner sits inside a control that already says it is busy — a Button with `loading`, an
  Item whose title reads "Processing payment…" — pass `aria-label={undefined}` so the state is not
  announced twice.
- The colour is `currentColor`: the spinner inherits the ink of whatever hosts it, so it never needs
  a contrast decision of its own.
- The rotation is `animate-spin`, one of the two sanctioned loader animations, and the global
  reduced-motion reset in `base.css` collapses it.

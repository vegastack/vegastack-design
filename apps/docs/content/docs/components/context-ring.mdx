## Usage

```tsx
import { ComposerMeta } from "@/components/ui/composer-meta";
import { ContextRing } from "@/components/ui/context-ring";

<ComposerMeta
  context={
    <ContextRing
      used={25_900}
      window={200_000}
      parts={[
        { id: "instructions", label: "Instructions and tools", tokens: 15_700 },
        { id: "memory", label: "Memory", tokens: 2_100 },
        { id: "conversation", label: "Conversation", tokens: 6_900 },
        { id: "tools", label: "Tool results", tokens: 1_200 },
      ]}
      onSummarize={summarize}
      summarizing={summarizing}
    />
  }
/>;
```

`used` is what the last request carried and `window` the working window of the model the chat runs
on, both in tokens. The ring sits at the end of [`ComposerMeta`](/docs/components/composer-meta),
the quiet line under the composer. It is still — it never spins — and shows nothing until the
chat's first answer measures it. Hover or focus opens [`ContextPanel`](/docs/components/context-panel)
after 150ms, so passing over it does nothing; a click toggles it. Tokens and shares only, never
money, so everyone who can read the chat may see it; pass `onSummarize` only to people who can send.
For upload or task progress use [`Progress`](/docs/components/progress); for what a run cost use
[`RunUsage`](/docs/components/run-usage).

### Summarize now

The panel ends with Summarize now. A returned promise, or `summarizing` from the host, keeps it
busy. When `used` drops, as it does after a summary, the ring says the new share once.

## Accessibility

- The ring is a button named with the share used, "Chat memory 26% used"; the share is also
  written beside it, so colour is never the only cue.
- Keyboard focus opens the panel after the same 150ms as hover, without moving focus into it;
  Enter toggles it and Escape closes it.
- When the share drops it is announced once through a polite region; growth is not announced.

| Key               | Action                          |
| ----------------- | ------------------------------- |
| <kbd>Tab</kbd>    | Focus the ring; the panel opens |
| <kbd>Enter</kbd>  | Toggle the panel                |
| <kbd>Escape</kbd> | Close it                        |

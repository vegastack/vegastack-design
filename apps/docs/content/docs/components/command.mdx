## Examples

### About

`Command` is [cmdk](https://github.com/pacocoursey/cmdk) — a headless palette engine that scores every item
against the query and unmounts the ones that do not match, rather than hiding them. Items register
themselves from the DOM, so a `CommandItem` written as a static child filters without any `items`
array; `CommandEmpty` renders when the engine's filtered count reaches zero, and `CommandSeparator`
hides itself while a search is active.

### Basic

`CommandDialog` puts the same palette inside a Dialog. It owns the dialog's `title` and
`description` — both rendered `sr-only` — so a ⌘K palette is named without visible chrome.

### Shortcuts

`CommandShortcut` is the trailing hint on a row. A row carrying one suppresses the check indicator,
so the shortcut and the check never compete for the same slot.

### Groups

`CommandGroup` takes a `heading` and `CommandSeparator` divides two of them. A group whose items all
score zero is hidden by the engine, and the separator beside it disappears with the search.

## Accessibility

- The input is a `role="combobox"` with `aria-expanded`, `aria-controls` and `aria-activedescendant`;
  the list is a `role="listbox"` of `role="option"` rows.
- <kbd>↑</kbd>/<kbd>↓</kbd> move the active row, <kbd>Home</kbd>/<kbd>End</kbd>
  jump to the first and last, and <kbd>Enter</kbd> activates. Navigation skips a
  `disabled` row rather than landing on it.
- Filtering is announced. cmdk ships no live region, so `Command` renders one polite `role="status"`
  region for its whole life and speaks the result count whenever the query changes (A11Y-3, A11Y-4).
- With zero results the list stops being a `listbox` and the empty message carries `role="status"`
  (A11Y-7, A11Y-3), so an empty palette is never a listbox holding a non-option child. Nothing about
  how you compose it changes: `CommandEmpty` still goes inside `CommandList`.
- Rows carry the hand cursor from the one global rule in `base.css` (INT-1); upstream's local
  `cursor-default` is removed.
- In the dialog form, give `CommandDialog` a `title` and `description` — they are the dialog's
  accessible name and description even though they are visually hidden.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/command.patch`. Every hunk:

- **INT-1** — `cursor-default` is removed from `CommandItem`, so a row shows the hand cursor the one
  global rule gives every `[role="option"]`.
- **A11Y-3, A11Y-4** — cmdk ships no live region, so filtering a palette to two results, or to none,
  is silent. `Command` now renders one `useAnnouncer` region for its whole life (A11Y-4: mounted
  empty, keyed by a sequence counter) and announces the result count politely whenever the search or
  the count changes (A11Y-3: `role="status"`, never `alert`). It reads the count through cmdk's own
  `useCommandState`, so the announcement is the engine's filtered total, not a second count.
- **A11Y-7, A11Y-3** — a list with no options is not a listbox. cmdk hard-codes `role="listbox"` on
  the list and `role="presentation"` on the empty slot, so an empty palette is a listbox whose only
  child is the empty message — a critical `aria-required-children` failure. `CommandList` removes
  the role while the filtered count is 0 and restores it above 0, which is A11Y-7's context-licensed
  role applied to the other end of the same relationship, and `CommandEmpty` puts `role="status"` on
  the message so the empty state is still announced. Upstream's public composition is untouched.
- **DOC-2** — `cn` is imported from `@vegastack/design`; our npm layer owns `cn`.
- **DOC-1** — prettier reflow plus the `registry-stamp.mjs` provenance header; no decision of their
  own.
- **A11Y-2** — `CommandInput` gains `min-h-6`. cmdk's input carries no height of its own, so it
  measures its line box — 20px inside the 32px `InputGroup`, under the 24px target floor. Its focus
  affordance needed the matching half in `input-group`: upstream names this slot `command-input`,
  so the group's text-entry border tint never saw it focus (FOC-3, in `input-group.patch`).

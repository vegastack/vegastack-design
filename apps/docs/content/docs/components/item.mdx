## Usage

```tsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item";

<Item>
  <ItemMedia variant="icon">
    <InboxIcon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>;
```

## Examples

### Composition

`ItemMedia`, `ItemContent` and `ItemActions` share one flex row; `ItemHeader` and `ItemFooter` take
a full basis, so they sit above and below that row inside the same item.

### Item vs Field

Use `Field` when you need to display a form input such as a checkbox, input, radio or select — it
owns the label association, the description and the error. Use `Item` when you only need to display
content: a title, a description and actions.

Use `ItemGroup` to group related items, and `ItemSeparator` to rule between them. The group renders

## Accessibility

- `Item` is a `div` by default and carries no role of its own — it is content, not a control. Pass
  `render` to make it an anchor or a button when the whole row is activatable.
- `ItemGroup` renders `role="list"`, which admits only `listitem` children. Give every `Item` inside
  one `role="listitem"`, and hide an `ItemSeparator` between two rows with `aria-hidden` — the list
  already conveys the separation, and an exposed `role="separator"` there is a critical
  `aria-required-children` failure.
- On `:focus-visible` the global 2px outline in `base.css` applies (FOC-1). The item's recipe
  carries no focus ring, no `ring-3` glow and no `outline-none` of its own (FOC-6).
- `ItemTitle` never clamps on the element that is also a flex container; wrap the text in an inner
  span when it has to truncate (LAY-11).
- An icon-only action inside `ItemActions` has no visible text — give it an `aria-label`.

## Deviations

Upstream's file plus `packages/ui/upstream/patches/item.patch`. Every hunk:

- **FOC-1, FOC-6** — `itemVariants` loses upstream's `outline-none`, `focus-visible:border-ring` and
  3px `focus-visible:ring-ring/50` glow, so the global 2px outline is what a focused item shows.
- **LAY-11** — `ItemTitle` loses `line-clamp-1`, which upstream sets on the same element as `flex`.
  Truncation goes on an inner span instead.
- **DOC-2** — `cn` is imported from `@vegastack/design`, and the file carries the registry
  provenance header.
- **API-16** — `"use client"` is added: `useRender` calls `React.useRef` internally, so the
  module throws on import in a React Server Component without the boundary.
- **A11Y-7** — `ItemGroup` licenses `role="listitem"` on the items inside it, through context, and
  hides the separator's rule from assistive tech. `role="list"` admits only `listitem` children, so
  upstream's own composition is a critical `aria-required-children` violation as shipped.

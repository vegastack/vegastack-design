Markdown in VegaStack has two surfaces and one typography. [`MarkdownView`](/docs/components/markdown-view)
renders a markdown string; [`TextEdit`](/docs/components/text-edit) with `format="markdown"` edits
one. Both wear the shared `prose` recipe from `@vegastack/design` (`proseClassName`), and `TextEdit`
resets ProseMirror's defaults, so a document sits at the same position whether it is being read or
edited. The recipe is the app's body text — `text-sm`, the body family and `foreground` ink for
paragraphs, lists, list markers, marks and quotes, headings on the app's type scale — so neither
surface has a separate "prose" look. Only inline code and code blocks are mono.

`TextEdit` is Notion-style: no border, no ground, no focus ring and no view mode. It rests looking
exactly like `MarkdownView`; click anywhere and type. Leaving the editor calls `onCommit` with the
new markdown when it changed; <kbd>Esc</kbd> reverts.

```tsx
import { MarkdownView } from "@/components/ui/markdown-view";
import { TextEdit } from "@/components/ui/text-edit";

// Editable: the editor is the view.
<TextEdit
  format="markdown"
  defaultValue={summary}
  onCommit={save}
  aria-label="Summary"
/>;

// Read-only elsewhere:
<MarkdownView>{summary}</MarkdownView>;
```

## Toolbar levels

`toolbar` picks a level, and the editor's schema follows it: a mark or node with no action is not
allowed, so markdown for it becomes plain text. Any heading action allows every heading level, so a
document with an `#` still round-trips.

| Level                  | Actions                                                                            |
| ---------------------- | ---------------------------------------------------------------------------------- |
| `minimal`              | bold, italic, link, bullet list                                                    |
| `standard` _(default)_ | minimal + H2, H3, ordered list, task list, blockquote, inline code                 |
| `full`                 | standard + strikethrough, code block, table, divider, undo, redo, clear formatting |
| an array               | any of `TextEditAction`, rendered in the fixed cluster order                       |

## Bubble menu

`bubbleMenu` (on by default) floats a toolbar over a text selection with heading, bold, italic,
inline code and link — whichever of them the toolbar allows. The link button opens the same link
popover as the toolbar: type a URL to add or update the link, or **Remove** it. Pasting a URL over a
selection links it without the popover.

## In-place editing

There is no mode to switch. The editor is transparent and borderless, so it takes the surface it
sits on and its text lands exactly where `MarkdownView` would put it. Focus shows the compact
formatting row under the text; there are no Save or Cancel buttons.

| Event                           | Result                                                                   |
| ------------------------------- | ------------------------------------------------------------------------ |
| Focus leaves the editor         | `onCommit(value)` — only when the document differs from when focus came. |
| <kbd>Esc</kbd>                  | Revert to the document focus found, blur, then `onRevert()`.             |
| <kbd>Mod</kbd> <kbd>Enter</kbd> | `onSubmit(value)` when set; otherwise commit and blur.                   |
| `autosave` idle gap             | `onCommit(value)` without leaving.                                       |

`onSave`, `onCancel`, `saveLabel`, `cancelLabel` and `variant` are deprecated: `onSave` and
`onCancel` alias `onCommit` and `onRevert`, the rest are ignored.

## Input rules

Type markdown and it becomes formatting as you go. Pasted plain-text markdown is parsed the same
way.

| Type             | Becomes           |
| ---------------- | ----------------- |
| `# ` … `###### ` | Heading           |
| `- ` or `* `     | Bullet list       |
| `1. `            | Ordered list      |
| `[ ] ` or `[x] ` | Task item         |
| `> `             | Blockquote        |
| ` ``` `          | Code block        |
| `---`            | Divider           |
| `**text**`       | **Bold**          |
| `_text_`         | _Italic_          |
| `~~text~~`       | ~~Strikethrough~~ |
| `` `text` ``     | Inline code       |

Each rule needs its action: `[ ] ` does nothing without `taskList`.

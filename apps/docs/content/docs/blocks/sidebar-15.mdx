## What it is

A left and right sidebar. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/sidebar-15
```

<RegistryInstallCallout />

This installs the block's own files plus the components it composes: `avatar`, `breadcrumb`, `calendar`, `collapsible`, `dropdown-menu`, `separator`, `sidebar`.

## What it is

10 chart **blocks** in the `line` family. Each is one `Card` wrapping a
`ChartContainer`, with its sample data inline — pull one, then point it at your own series.
They depend on `card` and `chart` and nothing else.

## Install

```npm
npx shadcn@latest add @vegastack/chart-line-default
```

<RegistryInstallCallout />

Every block on this page installs the same way; swap the name.

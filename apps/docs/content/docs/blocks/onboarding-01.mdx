## What it is

An onboarding page section — the checklist with its progress, beside a what-is-next card. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/onboarding-01
```

<RegistryInstallCallout />

This installs the block's own files plus the components it composes: `button`, `card`, `progress`.

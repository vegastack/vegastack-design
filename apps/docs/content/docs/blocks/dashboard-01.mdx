## What it is

A dashboard with sidebar, charts and data table. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/dashboard-01
```

<RegistryInstallCallout />

This installs the block's own files plus the components it composes: `avatar`, `badge`, `button`, `card`, `chart`, `checkbox`, `drawer`, `dropdown-menu`, `input`, `label`, `select`, `separator`, `sidebar`, `table`, `tabs`, `toggle-group`, `use-mobile`.

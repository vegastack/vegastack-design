## What it is

A sidebar in a popover. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/sidebar-10
```

<RegistryInstallCallout />

This installs the block's own files plus the components it composes: `breadcrumb`, `button`, `collapsible`, `dropdown-menu`, `popover`, `separator`, `sidebar`.

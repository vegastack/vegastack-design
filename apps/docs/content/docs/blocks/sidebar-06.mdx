## What it is

A sidebar with submenus as dropdowns. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/sidebar-06
```

<RegistryInstallCallout />

This installs the block's own files plus the components it composes: `breadcrumb`, `button`, `card`, `dropdown-menu`, `separator`, `sidebar`.

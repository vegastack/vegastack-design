## What it is

A login page with a muted background color. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/login-03
```

<RegistryInstallCallout />

This installs the block's own files plus the components it composes: `button`, `card`, `field`, `input`.

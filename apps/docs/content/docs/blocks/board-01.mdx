## What it is

A board page — a PageHeader over a FilterBar and Board, with lanes named by their count, cards that link to each task, and a No matches state. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

`BoardView` in `components/` holds the filters and the board; the page is the server-safe frame around it.

## Install

```npm
npx shadcn@latest add @vegastack/board-01
```

## Anatomy

- `AppShellPage size="full"` › `PageHeader` h1 "Tasks" with its "New task" action.
- `FilterBar` — search plus an Assignee facet (a radio menu), with the chosen assignee shown as a
  removable chip and "Clear filters" while anything is filtered.
- `Board` — each lane is a region named with its count ("Backlog, 3 tasks", via `countLabel`),
  each card is a link to its task (`getItemHref`) and is named for moves (`getItemLabel`), and an
  empty lane says so ("No tasks", or "No matching tasks" while filtering).
- **No matches** — when the filters hide every card, the board gives way to an `Empty` with "Clear
  filters".

## Filters and moves

The filters narrow what each lane **shows**; a move always lands in the full lane, which is why
`onMove` updates the unfiltered columns. Space on a focused card lifts it into keyboard move mode;
Enter follows its link.

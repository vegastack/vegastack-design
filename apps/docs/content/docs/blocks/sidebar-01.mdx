## What it is

A simple sidebar with navigation grouped by section. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/sidebar-01
```

<RegistryInstallCallout />

This installs the block's own files plus the components it composes: `breadcrumb`, `dropdown-menu`, `label`, `separator`, `sidebar`.

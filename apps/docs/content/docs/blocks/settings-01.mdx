## What it is

A settings page — PageHeader over grouped SettingsRow sections whose fields autosave (text after a short debounce, pickers and switches at once, each with a quiet inline status), and a delete confirmed in an AlertDialog. It follows the [settings save model](/docs/foundations/interaction-patterns#settings-save-model): no save bar; explicit Discard / Save only for drafts that must apply together. It is a **block**: you pull it once with `shadcn add`, and then you own it —
nothing re-pulls it and no integrity hash tracks your edits, unlike the components it composes.

## Install

```npm
npx shadcn@latest add @vegastack/settings-01
```

<RegistryInstallCallout />

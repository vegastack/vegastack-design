## What it is

The Share surface for one record, page or meeting. Every row, level and link comes in through
props and every change goes out through a callback, so the same dialog serves tasks, meetings and
pages. It is a `ResponsiveDialog` — a `Dialog` (size `md`, 512px) from 768px up and a bottom sheet
below it — titled "Share", with two line tabs: **Share** and **Publish**. Close it with × or
Escape; there is no Done button. Both tab panels stay mounted in one grid cell (the inactive one invisible and inert) and the
footer keeps its box on either tab, so switching tabs never changes the dialog's or the sheet's
height. It is a **block**: you pull it once with `shadcn add`,
and then you own it. `ShareDemo` wires it to sample state.

### Invite mode

The invite row is `PeopleInput`, the level for the whole batch (`PermissionMenu variant="outline"`)
and **Invite**. Once a chip is chosen the tab shows **Notify people** (on by default) and an
optional message, with Cancel in the footer. `onInvite` receives
`{ invitees, level, notify, message }`; the chips clear when it resolves, and stay for a retry when
it resolves `false` or rejects.

<ComponentPreview name="share01Invite" />

`defaultInvitees` is reactive: when it changes (compared by id), the chips are replaced with it, so
a "Share with Priya" prompt can open the mounted dialog with Priya already chosen. Chips the viewer
adds or removes afterwards stay until the prop changes again.

```tsx
<ShareDialog
  open={open}
  onOpenChange={setOpen}
  defaultInvitees={suggested ? [suggested] : []}
  {...rest}
/>
```

### Publish

**Copying never publishes.** The Share tab's footer is **Copy link** — the item's own link, which
only people with access can open. Publishing lives in the Publish tab: a "Publish to the web"
switch, off by default, is the only control that calls `onCreatePublicLink`. While published: the
public URL, **Copy public link**, a Reset button (its tooltip says the current link stops working),
an Expires select (Never, 1 day, 7 days, 30 days) and **Stop publishing**, which — like turning the
switch off — asks for confirmation before calling `onStopPublicLink`. A viewer who cannot manage
sees the URL and Copy public link while it is published, and "Not published" otherwise. Pass
`defaultTab="publish"` when the dialog opens from a "Published" indicator. While published, the
Share tab also carries a one-line notice — a globe, "Published to the web" and a **Manage** link
that switches to the Publish tab.

### Read-only viewer

`canManage={false}`: no invite row, every level as text, space access as text, and on the Publish
tab the public link to copy (or "Not published").

<ComponentPreview name="share01ReadOnly" />

### My space

When the item's space is personal (`generalAccess.space.access === "personal"`), the space row reads
"My space · Only you and the people above", with no mode or level to change.

<ComponentPreview name="share01MySpace" />

### A space the viewer cannot see

Pass `generalAccess.space: null` with `spaceHint` — `{ kind: "personal", ownerName }` or
`{ kind: "private" }` — and the row is a plain statement, "In Priya's My space" (person-with-lock)
or "In a private space" (lock), with no mode select and no level. The hint names a kind of space,
never the space.

<ComponentPreview name="share01HiddenSpace" />

### Fixed space access level

`generalLevelReadOnly`: the space's level shows as text while a manager can still switch between
"Everyone in ‹space›" and "Only people invited" — for when the space, not the item, owns that
level.

```tsx
<ShareDialog generalAccess={general} generalLevelReadOnly {...rest} />
```

## Anatomy

- **Tabs**: `Tabs variant="line"` — Share, Publish (a small globe while published). Without
  `publicLinkAvailable` there is no Publish tab and no tab list.
- **Invite row**: `PeopleInput` with the host's `search`, `PermissionMenu variant="outline"` for
  the batch, and Invite (`loading` while `onInvite` runs).
- **Invite mode**: `Checkbox` "Notify people", `Textarea`, footer Cancel.
- **People with access**: `Item` rows — `PersonAvatar` (people and teams), the name with "(you)", a
  muted reason ("Creator", "Assignee", "Manager of Priya", "via Sales team"), and
  `PermissionMenu variant="chip"`. A built-in (`readOnly`) row is `locked`, with `lockedReason`
  (default "Set by role: ‹reason›") in its tooltip; `onRemove` adds Remove access. `loading` shows
  skeleton rows.
- **Space access**: `IconGlyph`, a ghost `Select` ("Everyone in ‹space›" / "Only people
  invited") with a muted hint, and the space's level chip (text when `generalLevelReadOnly`); a
  personal space reads "My space · Only you and the people above", and a space the viewer cannot
  see reads from `spaceHint`.
- **Published notice** (Share tab, while published): a globe, "Published to the web" and Manage.
- **Publish tab**: the "Publish to the web" `Switch`; while published, `InputGroup` with the URL
  and a Reset button in a `Tooltip`, Copy public link, an Expires `Select`, and Stop publishing
  (confirmed in an `AlertDialog`). `publicLinkPending` holds these controls while a change runs.
- **Footer** (Share tab): "Only people with access can open it" and Copy link (`linkUrl`). The note
  (`footerNote`, e.g. "Admins can view this space.") sits at the end of the tab. Every string is
  in `labels`.

---
title: Icons
description: Three sanctioned sources — lucide (functional), thesvg (brand), lucide-animated (motion).
---

Icons come from exactly **three sanctioned sources**, each with a wrapper convention in `@vegastack/design/icons`:

- **`Icon`** — functional UI icons from `lucide-react` (every icon). Size tokens `xs/sm/md/lg`
  (14/16/20/24px), fixed stroke width, `currentColor`, `aria-hidden` unless labeled.
- **`BrandIcon`** — brand/logo icons from `thesvg` (every brand). `variant` = `color` (brand colors),
  `mono` (inherits `currentColor`), or `light` / `dark` / `wordmark`.
- **`AnimatedIcon`** — motion icons from `lucide-animated`, **mirrored into the VegaStack registry**
  (439 icons). Add any with `shadcn add @vegastack/icon-<name>`, then wrap with `AnimatedIcon` for the same
  size tokens + a11y; the icon animates on hover, or via its `startAnimation()` / `stopAnimation()`
  handle. `motion` is pulled in only when you add one — never in the base install.

```tsx
import { Icon } from '@vegastack/design/icons';
import { Check } from 'lucide-react';

<Icon as={Check} size="sm" aria-label="Done" />;
```

```tsx
// Animated — after `shadcn add @vegastack/icon-activity`
'use client';
import { AnimatedIcon } from '@vegastack/design/icons';
import { ActivityIcon } from '@/components/ui/icons/activity';

<AnimatedIcon as={ActivityIcon} size="md" aria-label="Activity" />;
```

For app-wide reduced-motion, wrap your tree once in Motion's
`<MotionConfig reducedMotion="user">` — animations then honor `prefers-reduced-motion` automatically.

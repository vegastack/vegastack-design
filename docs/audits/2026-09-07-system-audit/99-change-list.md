## Doctrine amendments (`design.md`) — collected

Each lands with its issue; listed here so the whole set is visible.

1. **Surfaces** — the ladder (`surface-1/2/3`), hover = `surface-2`, pressed = `surface-3`/`--alpha-pressed`, alpha borders, `card` = page in light, the sidebar reuses the ladder (F1).
2. **Hover geometry** — a hover wash is inset ≥4px from any container hairline and inherits the container's inner radius; a pressed step exists on every control (F1, N1).
3. **Button** — `variant × tone`; `cta` is the only marketing variant; no glass, no lit finish; sizes `xs·sm·md·lg` (F2).
4. **Focus** — two grammars only: the 2px outline, and the text-entry border tint _with_ a forced-colours fallback; rings inside overflow containers are inset (F1, Fo1, T1).
5. **Type** — form labels are 12px `text-label-sm`; list rows are 14/500 + 12; `text-xs` is mono-only; `font-medium` only inside `text-label*` (Fo1, C1, G1).
6. **Spacing** — the 4/8/12/16 ladder with the single sanctioned 6px (icon-to-label at `sm`); control padding derived from height; container tiers `p-2/3/4/6` (04 §3).
7. **Motion** — overlays per D11 (measured Vercel/Linear); docked controls 150 in / 100 out, no scale; icon swaps instant; reduced motion is global, never restated (O1, M2, Di1).
8. **Live regions** — `status` by default, `alert` only for destructive/warning after mount; one announcer hook (C1, T2).
9. **Media** — theme-invariant scrim/ink tokens; controls keep the standard ring (M1).
10. **Tables** — cells wrap; `nowrap` is a column decision; scroll containers are named regions (T1).
11. **Data loss** — responsive revelation merges, never hides silently (T1).
12. **Docs canon** — the section order and required content per component class; agents read the same pages (Do1).
13. **Sanctioned engines** — add `react-day-picker` (calendar) and `next-themes` (theme) with their one-file isolation (D1).
14. **Icons** — the factory owns the controller; icons are data (I1).

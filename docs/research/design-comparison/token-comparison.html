3 · Colour ramps — status, accent & AI/agent

One value per status can't do every job: a solid Delete button needs a bright fill, error helper text on a white page needs a dark-enough readable version, and an alert background needs a soft tint. So a designer builds a small functional ramp per status. Two rules make it coherent: (1) the solid fill is theme-independent — one brand identity in both light & dark, so they're never misaligned; (2) every fill carries WHITE on-fill text (uniform — red, green, orange, blue, purple all match), so hover/active simply darken away from the white and contrast only ever rises. Green & orange are deepened to make white text clear AA (bright amber can't carry white — yellow is too luminous — so warning is a deep orange). Only subtle (soft bg) and text (readable colour) adapt per theme. Every shade gate-verified.

Action & AI/agent ramps — VegaStack's chromatic identity (NEW)

A grayscale-only system has no identity and no way to signal "this is the AI." An agentic-enterprise product needs two accents beyond status: action (blue) for interactive surfaces — links, selection, active states, info (focus is a neutral ring, NOT this blue) — and agent (purple) for AI / agent moments (generative output, agent actions), so an agent surface is instantly distinct from an ordinary control. Gate-verified & in-gamut.

Focus state (your directive): no rings. The chunky Tailwind focus ring (ring-2/outline) is removed everywhere, and mouse clicks show nothing (:focus-visible only). Keyboard focus instead uses a border/background colour shift — ring-free, the same language you approved for hover, just a step stronger so focus ≠ hover. This keeps us WCAG 2.4.7 / enterprise-VPAT compliant for keyboard users without a single halo. (Going to literally zero focus indicator would fail enterprise accessibility procurement — flagged.)

4 · Typography

Today there are no size/weight/line-height tokens — components use raw Tailwind (text-sm, font-semibold). Proposed: a named, compact scale rendered live in Geist (our shipped font).

Base size: 14 px (revised from 13px)

Earlier we'd locked 13px (Aster purism); revised to 14px body — more readable, the shadcn/Vercel default, and it pairs cleanly with the new 12px small. Rendered against 13 and 16 so the choice is visible.

5 · Radius

Current = one base 0.625rem + calc(). Proposed = an explicit 4-step scale (last is rounded-full). Boxes render the real radius.

6 · Elevation

Flat by default. Cards, inputs, panels, sidebar — hairline border, no shadow. Only true overlays (dropdown, tooltip, popover, menu, select) get one subtle soft shadow so they read as floating. No multi-tier / heavy shadows, no dramatic modal drop — the scrim does that work. One shadow token, used sparingly.
